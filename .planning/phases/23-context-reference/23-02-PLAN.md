## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer → IPC → ai-manager | 引用标签页内容经 IPC 传递到主进程 |
| webview guest → renderer | executeJavaScript 从 guest 页面提取内容 |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-23-03 | Tampering | IPC referencedTabs 伪造 | medium | mitigate | 主进程验证 referencedTabs 数组结构，不信任渲染进程传入的 content 为可信内容 |
| T-23-04 | Elevation of Privilege | webview executeJavaScript 注入 | medium | mitigate | 执行脚本为硬编码 IIFE，不接受外部输入拼接；内容截断限制 token 消耗 |
| T-23-05 | Information Disclosure | 跨容器标签页内容泄露 | low | accept | 用户决策 D-13 明确允许跨容器引用，每个标签页标注容器来源（D-14） |
</threat_model>
