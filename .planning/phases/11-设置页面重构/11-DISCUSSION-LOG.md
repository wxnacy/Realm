## 左侧边栏导航样式

### 布局方式

| Option | Description | Selected |
|--------|-------------|----------|
| 固定边栏 | 边栏始终可见，类似 Chrome/Firefox 设置页。简单直接，无需管理折叠状态。 | ✓ |
| 可折叠边栏 | 边栏可以折叠/展开，折叠时只显示图标。节省空间但增加交互复杂度。 | |
| 悬停展开边栏 | 鼠标悬停时边栏才出现，类似 VS Code 的自动隐藏侧边栏。最大化内容区域。 | |

**User's choice:** 固定边栏 (推荐)
**Notes:** 无

### 导航项样式

| Option | Description | Selected |
|--------|-------------|----------|
| 纯文字导航项 | 仅文字标签，简洁清爽。类似 Firefox 设置页风格。 | |
| 图标 + 文字 | 图标 + 文字标签，视觉层次更丰富。类似 Chrome 设置页风格。 | ✓ |
| 图标优先 + 悬停文字 | 默认只显示图标，鼠标悬停时显示文字。类似 VS Code 侧边栏。 | |

**User's choice:** 图标 + 文字
**Notes:** 无

### 选中状态

| Option | Description | Selected |
|--------|-------------|----------|
| 背景高亮条 | 选中项背景变为高亮色，类似 Chrome 设置页的圆角高亮条。 | ✓ |
| 左侧竖线指示器 | 选中项左侧显示竖线指示器，类似 VS Code 侧边栏。 | |
| 文字变色 | 选中项文字变为强调色（如蓝色），背景不变。最简设计。 | |

**User's choice:** 背景高亮条
**Notes:** 无

### 边栏宽度和标题

| Option | Description | Selected |
|--------|-------------|----------|
| 标准宽度 + 标题 | 边栏宽度约 200-240px，与 Chrome 设置页类似。导航项上方有"设置"标题。 | ✓ |
| 紧凑宽度 + 无标题 | 边栏宽度约 160-180px，紧凑设计。无标题，直接显示导航项。 | |
| 你来决定 | 你来决定边栏宽度和是否需要标题。 | |

**User's choice:** 标准宽度 + 标题
**Notes:** 无

## 分配规则编辑体验

### 规则展示方式

| Option | Description | Selected |
|--------|-------------|----------|
| 表格/列表视图 | 每条规则一行，显示域名、目标容器、匹配类型。类似当前模态框的列表形式，但更宽敞。 | ✓ |
| 卡片视图 | 每条规则一个卡片，显示完整信息。更视觉化但占用更多空间。 | |
| 紧凑表格 | 紧凑的表格布局，信息密度更高。类似数据库管理工具的风格。 | |

**User's choice:** 表格/列表视图 (推荐)
**Notes:** 无

### 编辑交互方式

| Option | Description | Selected |
|--------|-------------|----------|
| 行内编辑 | 点击规则行直接进入编辑模式，字段变为可编辑输入框。快速但可能误触。 | |
| 展开式编辑面板 | 点击规则行弹出编辑面板（在规则下方展开或右侧弹出）。更清晰的编辑体验。 | ✓ |
| 编辑弹窗 | 点击编辑按钮弹出模态框编辑。与当前行为一致，但与"去弹窗化"的目标冲突。 | |

**User's choice:** 展开式编辑面板
**Notes:** 无

### 拖拽排序实现

| Option | Description | Selected |
|--------|-------------|----------|
| HTML5 原生拖拽 | 使用 HTML5 原生拖拽 API，无需额外依赖。视觉反馈可能不如专用库流畅。 | ✓ |
| SortableJS 库 | 使用 SortableJS 等轻量库，拖拽体验更流畅，支持触摸设备。增加约 10KB 依赖。 | |
| 上/下箭头按钮 | 不用拖拽，改用上下箭头按钮调整顺序。更简单但操作效率较低。 | |

**User's choice:** HTML5 原生拖拽 (推荐)
**Notes:** 无

### 启用/禁用交互

| Option | Description | Selected |
|--------|-------------|----------|
| 行内开关按钮 | 每条规则右侧显示开关按钮（toggle），点击立即切换启用/禁用状态。直观且符合现代 UI 习惯。 | ✓ |
| 批量操作栏 | 规则列表上方有批量操作栏，选中规则后批量启用/禁用。适合大量规则管理。 | |
| 复选框 + 灰色样式 | 禁用的规则显示为灰色/半透明，点击规则行左侧的复选框切换状态。 | |

**User's choice:** 行内开关按钮 (推荐)
**Notes:** 无

## 快捷键设置交互

### 快捷键展示方式

| Option | Description | Selected |
|--------|-------------|----------|
| 分组展示 | 按功能分组：标签页操作、导航操作、书签操作等。每组有标题分隔。 | ✓ |
| 平铺列表 | 所有快捷键平铺展示，按操作名称字母/拼音排序。简单但缺乏层次。 | |
| 双栏分组 | 左侧分组导航，右侧显示对应组的快捷键。类似 IDE 快捷键设置。 | |

**User's choice:** 分组展示 (推荐)
**Notes:** 无

### 按键捕获 UI

| Option | Description | Selected |
|--------|-------------|----------|
| 点击即捕获 | 点击快捷键显示区域后，区域变为"请按下快捷键..."的捕获状态。按下组合键后立即显示并保存。类似 VS Code 快捷键设置。 | ✓ |
| 弹窗捕获 | 点击编辑按钮弹出小对话框，在对话框中捕获快捷键。更明确但多一步操作。 | |
| 文本输入 | 直接在输入框中输入快捷键文本。灵活但容易输入错误格式。 | |

**User's choice:** 点击即捕获 (推荐)
**Notes:** 无

### 冲突处理方式

| Option | Description | Selected |
|--------|-------------|----------|
| 警告 + 允许覆盖 | 捕获到冲突的快捷键时，显示警告提示"该快捷键已被 [操作名] 使用"，但允许强制覆盖。 | ✓ |
| 自动替换 | 捕获到冲突的快捷键时，自动取消旧操作的快捷键，新操作生效。 | |
| 拒绝 + 提示清除 | 捕获到冲突的快捷键时，拒绝设置并提示用户先清除冲突的快捷键。 | |

**User's choice:** 警告 + 允许覆盖 (推荐)
**Notes:** 无

### 重置功能

| Option | Description | Selected |
|--------|-------------|----------|
| 单个重置 + 全部重置 | 每个快捷键右侧有重置按钮（仅在修改过时显示），页面底部有"重置全部快捷键"按钮。 | ✓ |
| 仅全部重置 | 只有页面底部的"重置全部快捷键"按钮。简单但粒度粗。 | |
| 不需要重置 | 不需要重置功能，用户可以手动修改回默认值。 | |

**User's choice:** 单个重置 + 全部重置 (推荐)
**Notes:** 无

## 通用设置页面内容

### 设置项布局

| Option | Description | Selected |
|--------|-------------|----------|
| 分组展示 | 设置项按功能分组，每组有标题。如"浏览器"、"历史记录"、"外观"等。类似 Chrome 设置页。 | ✓ |
| 平铺列表 | 所有设置项平铺展示，简单直接。适合设置项较少的场景。 | |
| 基本/高级分层 | 设置项分为基本设置和高级设置，高级设置默认折叠。 | |

**User's choice:** 分组展示 (推荐)
**Notes:** 无

### 设置项内容

| Option | Description | Selected |
|--------|-------------|----------|
| 仅迁移现有设置 | 仅迁移现有设置（默认浏览器引导、历史保留天数），不新增设置项。保持范围可控。 | |
| 迁移 + 新增常用设置 | 在迁移基础上新增一些实用设置，如：启动时行为、新标签页设置、主题切换等。 | |
| 你来决定 | 你来决定哪些设置需要新增。 | |

**User's choice:** 迁移现有的，默认浏览器/历史记录/默认容器/启动
**Notes:** 用户明确指定了要迁移的设置项：默认浏览器、历史记录、默认容器、启动行为

### 设置项交互

| Option | Description | Selected |
|--------|-------------|----------|
| 即时生效 | 设置项修改后立即生效并自动保存，无需点击保存按钮。类似 Chrome 设置页。 | ✓ |
| 需点击保存 | 设置项修改后需要点击"保存"按钮才能生效。防止误操作但多一步。 | |
| 混合模式 | 部分设置即时生效（如开关类），部分需要保存（如输入框类）。 | |

**User's choice:** 即时生效 (推荐)
**Notes:** 无

### 关于页面

| Option | Description | Selected |
|--------|-------------|----------|
| 底部版本号 + 关于页 | 边栏底部显示应用版本号，点击可查看详细信息（版本、更新日志、许可证等）。 | ✓ |
| 通用页底部版本信息 | 通用设置页面底部显示版本信息，不需要单独的关于页面。 | |
| 不需要版本信息 | 不需要显示版本信息。 | |

**User's choice:** 底部版本号 + 关于页
**Notes:** 无
