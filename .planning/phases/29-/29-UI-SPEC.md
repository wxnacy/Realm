## Interaction Contract

### 1. Sidebar Navigation

**Element:** `<div class="sidebar-item" data-page="multimedia">`

- SVG icon: Play-circle or film icon (18x18, stroke-based, `stroke="currentColor"`, `stroke-width="2"`)
- Label: `<span>多媒体</span>`
- Position: After "AI 助手" sidebar item, before "关于"
- Click behavior: calls `switchSettingsPage('multimedia')`, follows existing pattern
- Active state: `background: rgba(59, 130, 246, 0.15)`, `border-left-color: var(--accent-color)`, `color: var(--text-primary)`, icon color: `var(--accent-color)`

### 2. Multimedia Settings Section

**Element:** `<section id="settings-multimedia" class="settings-section">`

- `display: none` by default (JS toggled like other sections)
- Page title: `<h1 class="settings-page-title">多媒体</h1>`
- Contains two settings groups (see below)

### 3. Toggle Switch (功能开关)

**HTML pattern (div-based, matching devMode toggle):**

```html
<div class="settings-group">
  <div class="settings-item">
    <div class="setting-info">
      <span class="setting-label">多媒体播放器</span>
      <span class="setting-description">开启后可检测网页中的视频资源并播放</span>
    </div>
    <label class="toggle-switch">
      <div class="toggle-track" id="mediaPlayerToggle">
        <div class="toggle-thumb"></div>
      </div>
    </label>
  </div>
</div>
```

**Behavior:**
- Default state: OFF (`.toggle-track` without `.active` class)
- Click toggles `.active` class on `.toggle-track`
- Saves via `settings.mediaPlayer.enabled` to electron-store
- Instant effect (no restart required): toggles MediaSniffer on/off, clears/hides media panel
- Uses div-based toggle (same as devMode) for consistency with devMode pattern

### 4. Domain Whitelist (白名单配置)

**Shown when:** toggle is ON (`.multimedia-content.disabled` class removed)

**HTML structure:**

```html
<div class="settings-group multimedia-content disabled" id="mediaPlayerSection">
  <h3 class="settings-group-title">域名白名单</h3>
  <p class="setting-description" style="margin-bottom: 12px;">
    白名单为空时探测所有域名，添加域名后仅探测白名单中的域名（自动包含子域名）
  </p>
  <div class="whitelist-input-area">
    <input type="text" id="whitelistDomainInput" class="text-input"
      placeholder="输入域名，如 example.com">
    <button class="btn btn-primary btn-sm" id="addWhitelistDomainBtn">添加域名</button>
  </div>
  <div class="whitelist-tags" id="whitelistTags"></div>
  <div class="whitelist-hint" id="whitelistHint">所有域名都进行探测</div>
</div>
```

**Tag chip structure (per domain):**

```html
<span class="whitelist-tag">
  <span class="whitelist-tag-text">example.com</span>
  <button class="whitelist-tag-remove" data-domain="example.com" title="移除">
    <svg width="12" height="12" viewBox="0 0 16 16" fill="none">
      <path d="M4 4L12 12M4 12L12 4" stroke="currentColor" stroke-width="1.5" stroke-linecap="round"/>
    </svg>
  </button>
</span>
```

**Interactions:**

| Action | Behavior |
|--------|----------|
| Type domain + Enter | Validates format, checks duplicates, adds to whitelist, saves to `settings.mediaPlayer.whitelist` array, renders tag chip |
| Type domain + click "添加域名" | Same as Enter |
| Click x on tag chip | Removes domain from whitelist, saves, removes tag chip from DOM |
| Empty whitelist | Show hint text "所有域名都进行探测" in `.whitelist-hint`; hide `.whitelist-tags` container |
| Non-empty whitelist | Hide hint text; show tag chips in `.whitelist-tags` |

**Input validation:**
- Empty input: show toast "请输入域名"
- Contains spaces or invalid chars (`/[^\w.\-]/`): show toast "域名格式不合法", highlight input border red 2s
- Duplicate: show toast "域名已存在", highlight input border red 2s
- Valid: add tag, clear input, show toast "已添加域名: {domain}"

### 5. Disabled State

When toggle is OFF:
- `.multimedia-content` gets `.disabled` class
- CSS: `opacity: 0.5; pointer-events: none;` (follows `.devmode-content.disabled` pattern)
- MediaSniffer stops (webRequest callback returns early)
- All container media lists cleared
- Media panel and toolbar media button hidden
- Already-open player windows continue playing until manually closed

## Data Contract

### electron-store Schema

```javascript
// settings.mediaPlayer
{
  enabled: false,          // boolean, default: false
  whitelist: []            // string[], default: []
}
```

### API Endpoints (to be added in main.js HTTP server)

| Endpoint | Method | Purpose |
|----------|--------|---------|
| `/api/settings/get` (extended) | GET | Returns settings including `mediaPlayer: { enabled, whitelist }` |
| `/api/settings/update` (extended) | POST | Accepts `mediaPlayer.enabled` or `mediaPlayer.whitelist` |

### IPC Channels (new)

| Channel | Direction | Purpose |
|---------|-----------|---------|
| `media:set-enabled` | renderer -> main | Toggle MediaSniffer on/off |
| `media:clear-all` | renderer -> main | Clear all container media lists |

## Accessibility Notes

- Toggle switch: uses `div`-based pattern (matching devMode). The `.toggle-track` div is keyboard-focusable via `tabindex="0"` and responds to Enter/Space to toggle (if implemented; follow devMode pattern).
- Tag chip delete buttons: `title="移除"` tooltip, `aria-label` recommended for screen readers.
- Input validation: toast notifications provide feedback; input border color change is visual-only.
- Disabled state: `pointer-events: none` prevents interaction; `opacity: 0.5` provides visual feedback.
