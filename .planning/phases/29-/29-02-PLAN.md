在 media-sniffer.js 中：

1. 新增 clearAll() 方法：
   - 清空 this.mediaMap（所有容器的媒体列表）
   - 清空 this.dedupSets（所有去重集合）
   - 清空 this.pendingByWcId（所有待处理条目）
   - 不重置 debugState 计数器（诊断用途保留）

在 main.js 中：

2. 在 webRequest 回调入口处新增 isDomainWhitelisted 辅助函数（per D-06/D-07）：
   - 函数签名：function isDomainWhitelisted(url, whitelist)
   - 如果 whitelist 为空数组，返回 true（空白名单 = 全部允许）
   - 使用 new URL(url).hostname 提取请求域名
   - 遍历 whitelist，匹配条件：hostname === domain || hostname.endsWith('.' + domain)
   - 解析失败（无效 URL）时返回 false
   - 此函数放在回调外部，作为纯工具函数

3. 修改 ses.webRequest.onResponseStarted 回调（per D-09）：
   - 在回调开头读取开关状态：`const enabled = configStore.get('settings.mediaPlayer.enabled', false);`
   - 如果 enabled 为 false，直接 return（早返，不处理任何嗅探）
   - 如果 enabled 为 true，读取白名单：`const whitelist = configStore.get('settings.mediaPlayer.whitelist', []);`
   - 调用 isDomainWhitelisted(details.url, whitelist) 检查域名
   - 如果域名不在白名单中，直接 return（不嗅探）
   - 如果域名在白名单中，调用 mediaSniffer.handleNetworkResponse(details)
   - 注意：每次回调都实时读取，不缓存开关状态和白名单（确保即时生效）

4. 确保 settings API 的 get 路由返回 mediaPlayer 默认值：
   - 在 handleSettingsApi 的 'get' 路由中，确保 settings 对象包含 mediaPlayer 字段
   - 默认值：{ enabled: false, whitelist: [] }
