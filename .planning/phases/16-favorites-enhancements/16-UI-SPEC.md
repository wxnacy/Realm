## Spacing Scale

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | 拖拽手柄与文字间距、选中指示器内边距 |
| sm | 8px | 插入指示线偏移、列表项内紧凑间距 |

## Interaction Patterns

### 拖拽排序（D-01 ~ D-07）

#### 基本拖拽流程

```
触发：鼠标按住收藏项/文件夹行任意位置（整行可拖，D-05）

┌─ 内容区 ─────────────────────────────────────┐
│ 📁 所有书签 > 开发 > 前端                      │
│                                               │
│ ┌───────────────────────────────────────────┐ │
│ │ ≡ GitHub                           [fav] │ │  ← 鼠标按下，整行可拖
│ │ ≡ MDN Web Docs                     [fav] │ │     cursor: move (D-05)
│ │ 📁 React 学习                              │ │
│ │ ≡ TypeScript Handbook                [fav] │ │
│ └───────────────────────────────────────────┘ │
│                                               │
│ ┌─ 拖拽中 ──────────────────────────────────┐ │
│ │                                           │ │
│ │   ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄   │ │  ← 蓝色插入指示线 (D-07)
│ │ ≡ MDN Web Docs                     [fav] │ │     2px 高，#3B82F6
│ │   ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄   │ │
│ │ 📁 React 学习                              │ │  ← 如果悬停在文件夹上
│ │   ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^     │ │     背景高亮 (D-06)
│ │ ≡ TypeScript Handbook                [fav] │ │     --drag-hover-bg
│ │                                           │ │
│ └───────────────────────────────────────────┘ │
└───────────────────────────────────────────────┘
```

#### 拖拽视觉反馈规则

| 状态 | 视觉表现 | CSS |
|------|----------|-----|
| 拖拽中（源项） | 半透明，opacity 0.4 | `.favorite-item.dragging { opacity: var(--dragging-opacity); }` |
| 悬停在两行之间 | 蓝色水平插入线，2px 高 | `.favorite-item.drag-over-top/bottom` 伪元素 |
| 悬停在文件夹上 | 文件夹行背景高亮 + 左边框蓝色 | `.folder-item.drag-over-folder { background: var(--drag-hover-bg); border-left: 3px solid var(--accent-color); }` |
| 拖到空白区域 | 取消操作，无视觉变化 | — |

#### 混合排序规则（D-02）

```
文件夹在前，收藏项在后（同类型内按 sort_order 排序）：

┌──────────────────────────────────────────┐
│ 📁 前端开发                    (文件夹区) │  ← 文件夹始终在前
│ 📁 后端开发                              │
│ 📁 工具                                  │
│ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─  │  ← 视觉分隔线（可选）
│ ≡ GitHub                           [fav] │  ← 收藏项在后
│ ≡ MDN Web Docs                     [fav] │
│ ≡ TypeScript Handbook              [fav] │
└──────────────────────────────────────────┘

拖拽排序规则：
- 文件夹只能排序到文件夹区域（不能拖到收藏项后面变成"收藏项"）
- 收藏项只能排序到收藏项区域
- 同类型内自由排序
```

#### 跨文件夹移动（D-03）

```
拖拽到文件夹上 = 移入该文件夹（不是排序到文件夹旁边）

交互流程：
1. 拖拽收藏项悬停在文件夹行上
2. 文件夹行高亮（--drag-hover-bg）
3. 悬停 500ms 后自动展开文件夹（可选，Claude's Discretion）
4. 松开鼠标 = 调用 moveFavorites API
5. 刷新当前文件夹内容
6. Toast: "已移动到目标文件夹"
```

#### 文件夹嵌套拖拽（D-03，复用循环引用检测）

```
文件夹可以拖到另一个文件夹里变成子文件夹：
- 拖拽文件夹 A 悬停在文件夹 B 上 → 高亮 B
- 松开 → 调用 moveFolder API（复用 Phase 14 循环引用检测）
- 如果 B 是 A 的子文件夹 → 拒绝操作，Toast 提示"无法移动到自身子文件夹"
```

### 多选批量操作（D-08 ~ D-11）

#### 多选交互（D-08）

```
键盘修饰键：

Cmd/Ctrl + 点击：
┌──────────────────────────────────────────┐
│ ☑ GitHub                           [fav] │  ← 点击选中
│ ☑ MDN Web Docs                     [fav] │  ← Cmd+点击选中
│   TypeScript Handbook                [fav] │  ← 未选中
│ ☑ React 文档                       [fav] │  ← Cmd+点击选中
└──────────────────────────────────────────┘
选中项样式：左侧蓝色边框 3px + 淡蓝背景 --selected-bg

Shift + 点击（范围选择）：
┌──────────────────────────────────────────┐
│ ☑ GitHub                           [fav] │  ← 先点击此项
│ ☑ MDN Web Docs                     [fav] │  ← Shift+点击最后一项
│ ☑ TypeScript Handbook              [fav] │  ← 中间所有项自动选中
│ ☑ React 文档                       [fav] │
└──────────────────────────────────────────┘

点击空白区域 = 取消所有选中
```

#### 多选视觉反馈

| 状态 | 视觉表现 | CSS |
|------|----------|-----|
| 选中项 | 左边框 3px solid var(--accent-color) + 背景 var(--selected-bg) | `.favorite-item.selected` |
| 全选 checkbox | 内容区顶部工具栏，indeterminate 状态（部分选中） | 已有 `selectAllCheckbox` 元素 |
| 选中计数 | "已选择 {count} 项" 文字显示 | 已有 `selectedCount` 元素 |

#### 批量操作工具栏（D-09, D-11）

```
位置：内容区底部固定栏（仅在有选中项时显示）

┌─ 内容区 ─────────────────────────────────────┐
│                                               │
│  [收藏项列表...]                               │
│                                               │
│ ┌─ 批量操作栏 ──────────────────────────────┐ │
│ │ 已选择 3 项   [剪切] [复制] [移动到...] [删除] [✕] │ │
│ └───────────────────────────────────────────┘ │
└───────────────────────────────────────────────┘

样式：
- 背景: var(--bg-secondary)
- 上边框: 1px solid var(--border-color)
- 高度: 48px
- 内边距: 0 16px
- 按钮: 与现有工具栏按钮样式一致
- 删除按钮: var(--danger-color) 文字色
```

#### 右键菜单自适应（D-09）

```
单选状态（右键未选中项）：
├─ 打开
├─ 在新标签页中打开
├─ ─────────
├─ 编辑
├─ 剪切        (Cmd+X)
├─ 复制        (Cmd+C)
├─ ─────────
├─ 删除        (Delete)
└─ 属性

多选状态（右键已选中项或选中区域）：
├─ 在新标签页中打开选中项
├─ ─────────
├─ 剪切选中项        (Cmd+X)
├─ 复制选中项        (Cmd+C)
├─ 移动选中项到...
├─ ─────────
├─ 删除选中项        (Delete)   ← 文字显示 "删除 {count} 项"
└─ 取消选择
```

### 拖拽 + 多选联动（D-10）

```
多选状态下拖拽其中一个选中项：
- 所有选中项一起移动
- 拖拽预览显示选中项数量（如 "3 项"）
- 保持选中项的相对顺序不变
- 插入指示线显示在目标位置
- 松开后批量调用排序 API

视觉：
- 拖拽预览：半透明叠加层，显示选中项数量文字
- 源位置：所有选中项变为半透明（opacity: 0.4）
- 目标位置：蓝色插入指示线
```

### 排序持久化（D-12, D-13）

```
技术方案：fractional-indexing

初始化（D-13）：
- 首次加载时，检查 sort_order 是否为 null
- 如果为 null，按 created_at 升序分配 fractional key
- 分配后立即写入数据库

拖拽后保存（D-04）：
- 拖拽结束 → 立即调用批量排序更新 API
- 无需用户确认
- API 失败时 Toast 提示"排序保存失败"，UI 回滚到拖拽前状态

fractional key 生成规则（D-12）：
- 拖到两个项目之间：generateKeyBetween(before.sortOrder, after.sortOrder)
- 拖到列表开头：generateKeyBetween(null, first.sortOrder)
- 拖到列表末尾：generateKeyBetween(last.sortOrder, null)
- 批量移动：为每个项目依次生成 key，保持相对顺序
```
