<task type="auto">
  <name>Task 2: 新增批量排序更新 API 并确保排序查询</name>
  <files>favorites-manager.js, main.js</files>
  <action>
1. 在 favorites-manager.js 中新增 `batchUpdateSort(items)` 函数：
   - 参数 items: Array<{id: number, sort_order: string}>
   - 使用事务包裹所有更新：`db.transaction(() => { ... })()`
   - 对每条 item 执行 `UPDATE favorites SET sort_order = ? WHERE id = ?`
   - 返回更新数量

2. 在 favorites-manager.js 中新增 `batchUpdateFolderSort(folders)` 函数：
   - 参数 folders: Array<{id: number, sort_order: string}>
   - 同样使用事务包裹
   - 对每条 folder 执行 `UPDATE favorite_folders SET sort_order = ? WHERE id = ?`
   - 返回更新数量

3. 将 batchUpdateSort 和 batchUpdateFolderSort 加入 module.exports

4. 在 main.js 的 `/api/favorites/` 路由处理器中新增两个路由：
   - `update-batch-sort` (POST): 接收 `{ items: [{id, sort_order}] }`，调用 `favoritesManager.batchUpdateSort(items)`
   - `update-batch-folder-sort` (POST): 接收 `{ folders: [{id, sort_order}] }`，调用 `favoritesManager.batchUpdateFolderSort(folders)`
