<task type="auto">
  <name>Task 1: 实现多选交互机制</name>
  <files>src/favorites-page.js</files>
  <action>
1. 确认 state 对象中已有 `selectedIds: new Set()`（第 34 行已存在）和 `lastClickedId` 变量。
   如无 `lastClickedId`，在 state 对象中添加 `lastClickedId: null`。

2. 实现 `handleItemClick(e, itemEl, itemId)` 函数（per D-08）：
   - 判断修饰键：
     * `e.metaKey || e.ctrlKey`：切换选中模式
       - 调用 `toggleItemSelection(itemId)`
       - 更新 `state.lastClickedId = itemId`
     * `e.shiftKey && state.lastClickedId !== null`：范围选择模式
       - 调用 `selectRange(state.lastClickedId, itemId)`
     * 普通点击：
       - 如果 `state.selectedIds.size > 0 && !state.selectedIds.has(itemId)`：清除所有选中
       - 更新 `state.lastClickedId = itemId`
   - 调用 `updateSelectionUI()` 刷新选中状态显示

3. 实现 `toggleItemSelection(itemId)` 函数：
   - 如果 `state.selectedIds.has(itemId)`：`state.selectedIds.delete(itemId)`
   - 否则：`state.selectedIds.add(itemId)`

4. 实现 `selectRange(startId, endId)` 函数：
   - 调用 `getAllVisibleItemIds()` 获取当前可见的所有项 ID（包括文件夹和收藏项，按 DOM 顺序）
   - 找到 startId 和 endId 在数组中的索引
   - 选中两者之间的所有项（含两端）：`state.selectedIds = new Set(rangeIds)`

5. 实现 `getAllVisibleItemIds()` 函数：
   - 查询 DOM 中所有 `.favorite-item[data-id]` 和 `.folder-tree-item[data-id]` 元素
   - 按 DOM 顺序提取 data-id，返回 ID 数组

6. 实现 `updateSelectionUI()` 函数：
   - 遍历所有收藏项和文件夹行元素
   - 如果元素的 data-id 在 `state.selectedIds` 中，添加 `.selected` CSS 类
   - 否则移除 `.selected` CSS 类
   - 更新全选 checkbox 状态（如果已存在该功能）

7. 在 `renderFavoriteItem()` 和 `renderFolderTree()` 中：
   - 为每个行元素添加 click 事件监听，调用 `handleItemClick(e, itemEl, itemId)`
   - 确保 `e.preventDefault()` 阻止文本选中

8. 在 `renderFavorites()` 或 `loadFavorites()` 结束时调用 `state.selectedIds.clear()` 和 `updateSelectionUI()`（刷新列表时清除选中状态）

9. 在键盘事件中添加 Escape 键处理：
   - 按 Escape 清除所有选中：`state.selectedIds.clear(); updateSelectionUI();`

<task type="auto">
  <name>Task 2: 实现右键菜单自适应和批量操作</name>
  <files>src/favorites-page.js, src/styles/main.css</files>
  <action>
1. 修改现有的右键菜单函数（或新建 `showContextMenu(e, itemEl, itemId)` 函数）：
   - 右键点击时，如果目标项不在 `state.selectedIds` 中：
     * 清除所有选中：`state.selectedIds.clear()`
     * 选中右键点击的项：`state.selectedIds.add(itemId)`
     * 调用 `updateSelectionUI()` 刷新显示
   - 根据 `state.selectedIds.size` 动态生成菜单项（per D-09）：

   a. **多选状态（selectedIds.size > 1）**：
   - 显示批量操作菜单：
     * `删除 ${count} 项` → 调用 `handleBatchDelete()`
     * `移动 ${count} 项到...` → 调用 `showMoveToFolderDialog()`
     * 分隔线
     * `剪切 ${count} 项` → 调用 `handleBatchCut()`
     * `复制 ${count} 项` → 调用 `handleBatchCopy()`
     * `粘贴` → 调用 `handlePaste()`（如果有剪贴板内容）
     * 分隔线
     * `取消选择` → 调用 `clearSelection()`

   b. **单选状态（selectedIds.size === 1）**：
   - 显示单个项的操作菜单：
     * 收藏项：打开 / 在新标签页打开 / 编辑 / 剪切 / 复制 / 删除
     * 文件夹：重命名 / 删除 / 添加书签 / 添加文件夹
   - 保留现有的菜单项结构

2. 实现 `handleBatchDelete()` 函数（per D-11 批量删除）：
   - 获取 `state.selectedIds` 中的所有 ID
   - 显示确认对话框（复用现有的 batchDelete 模态框）
   - 确认后调用 `favoritesApi('delete-batch', { ids: [...state.selectedIds] })`
   - 清除选中状态并刷新列表

3. 实现 `showMoveToFolderDialog()` 函数（per D-11 批量移动）：
   - 显示文件夹选择对话框（复用或扩展现有的移动对话框）
   - 选择目标文件夹后调用 `favoritesApi('move-favorites', { ids: [...state.selectedIds], folderId: targetFolderId })`
   - 清除选中状态并刷新列表

4. 实现剪切/复制/粘贴功能（per D-11 批量剪切/复制/粘贴）：
   - 扩展现有的剪贴板机制（Phase 15 已有基础实现）
   - `handleBatchCut()`：将选中项 ID 存入剪贴板，标记为 'cut' 模式
   - `handleBatchCopy()`：将选中项 ID 存入剪贴板，标记为 'copy' 模式
   - `handlePaste()`：从剪贴板读取，执行移动（cut）或复制（copy）操作
   - 剪贴板数据结构：`{ ids: number[], mode: 'cut'|'copy', sourceFolderId: number }`

5. 实现批量拖拽移动（per D-10）：
   - 修改 Plan 2 中的 `dragstart` 事件处理：
     * 如果拖拽源项在 `state.selectedIds` 中，将所有选中项一起拖拽
     * 设置 `e.dataTransfer.setData` 包含所有选中项 ID
     * 创建拖拽预览显示选中项数量
   - 修改 `drop` 事件处理：
     * 如果是批量拖拽，使用 `batchUpdateSort` 为所有选中项生成新的排序键
     * 保持选中项的相对顺序不变

6. 在 main.css 中添加选中状态样式：
   ```css
   .favorite-item.selected,
   .folder-tree-item.selected {
     background-color: rgba(59, 130, 246, 0.2);
     border-left: 2px solid #3B82F6;
   }
   .favorite-item.selected:hover,
   .folder-tree-item.selected:hover {
     background-color: rgba(59, 130, 246, 0.3);
   }
   ```
