## Components

### C-01: Download Dropdown Panel (`download-panel`)

**Location:** Fixed position, anchored below the download button (same positioning as `.media-panel`).

**Structure:**
```html
<div class="download-panel hidden" id="downloadPanel">
  <!-- 头部 -->
  <div class="download-panel-header">
    <span class="download-panel-title">下载</span>
    <div class="download-panel-header-actions">
      <!-- 批量操作：全部暂停/恢复（仅在有活跃下载时显示） -->
      <button class="btn-icon download-panel-pause-all" id="downloadPauseAllBtn" title="全部暂停">
        <!-- Lucide pause icon 14x14 -->
      </button>
      <button class="btn-icon download-panel-close-btn" id="downloadPanelCloseBtn" title="关闭">
        <!-- Lucide x icon 14x14 -->
      </button>
    </div>
  </div>

  <!-- 下载列表（滚动区域） -->
  <div class="download-panel-list" id="downloadPanelList">
    <!-- JS 动态渲染下载项，最近 N 条（最多 10 条） -->
  </div>

  <!-- 底部操作栏 -->
  <div class="download-panel-footer">
    <button class="download-panel-clear-btn" id="downloadClearBtn">清空所有记录</button>
    <button class="download-panel-view-all" id="downloadViewAllBtn">查看全部</button>
  </div>
</div>
```

**Behavior:**
- Click download button: toggle panel open/close (D-04)
- Click outside panel: close panel (same as `.media-panel` pattern)
- ESC key: close panel
- Panel shows max 10 most recent downloads (D-02)
- Bottom "查看全部" button navigates to `realm://downloads` in current tab (D-01)
- "清空所有记录" triggers delete confirmation modal (D-16)
- "全部暂停/恢复" only visible when there are active downloads (D-14)

**Sizing:** Width 380px, max-height 480px. Padding 0. Border-radius 8px. z-index 9998 (same as media-panel).

**States:**
1. **Has downloads:** Scrollable list of download items
2. **Empty:** Empty state message (D-03)

### C-02: Download List Item (`download-item`)

**Structure:**
```html
<div class="download-item" data-id="{downloadId}" data-state="{completed|in_progress|interrupted|paused}">
  <!-- 文件类型图标 -->
  <div class="download-item-icon">
    <!-- Lucide icon based on MIME type: file-text, image, video, music, archive, file -->
  </div>

  <!-- 文件信息 -->
  <div class="download-item-info">
    <div class="download-item-name">{filename}</div>
    <div class="download-item-meta">
      <span class="download-item-size">{size}</span>
      <span class="download-item-separator">·</span>
      <span class="download-item-time">{relative_time}</span>
      <span class="download-item-status"></span> <!-- 状态文本：下载中/已暂停/失败 -->
    </div>
    <!-- 进行中的下载：进度条 -->
    <div class="download-item-progress">
      <div class="download-item-progress-bar" style="width: {percent}%"></div>
    </div>
  </div>

  <!-- 操作按钮（hover 时显示） -->
  <div class="download-item-actions">
    <!-- 进行中/暂停/中断：暂停/恢复按钮 -->
    <button class="btn-icon download-item-pause-btn" title="暂停">
      <!-- Lucide pause icon -->
    </button>
    <button class="btn-icon download-item-resume-btn" title="恢复" style="display:none">
      <!-- Lucide play icon -->
    </button>
    <!-- 已完成：打开文件 + Finder -->
    <button class="btn-icon download-item-open-btn" title="打开文件">
      <!-- Lucide external-link icon -->
    </button>
    <button class="btn-icon download-item-folder-btn" title="在 Finder 中显示">
      <!-- Lucide folder-open icon -->
    </button>
    <!-- 通用：删除 -->
    <button class="btn-icon download-item-delete-btn" title="删除">
      <!-- Lucide trash-2 icon -->
    </button>
  </div>
</div>
```

**State-specific display (D-08, D-10):**

| State | Icon Tint | Status Text | Progress Bar | Actions Visible |
|-------|-----------|-------------|--------------|-----------------|
| `in_progress` | normal | "下载中 · {speed}" | visible, accent fill | pause, delete |
| `paused` | normal | "已暂停" | visible, muted fill | resume, delete |
| `interrupted` | `--text-muted` | "下载失败" | visible, danger fill | resume (if canResume), delete |
| `completed` | normal | "" (no status text) | hidden | open, folder, delete |

**Hover behavior (D-07):**
- Action buttons hidden by default, appear on row hover
- Row hover background: `var(--bg-hover)`
- Action icon color: `var(--text-muted)`, hover: `var(--text-primary)`
- Delete button hover: `var(--danger-color)`

**Progress bar (D-08):**
- Height: 3px
- Border-radius: 2px
- Fill color (in_progress): `var(--accent-color)`
- Fill color (paused): `var(--text-muted)` at 50% opacity
- Fill color (interrupted): `var(--danger-color)` at 50% opacity
- Transition: `width 0.3s ease`

**File type icons (D-09):**

| MIME Pattern | Lucide Icon | Color |
|--------------|-------------|-------|
| `application/pdf` | `file-text` | `#EF4444` |
| `image/*` | `image` | `#10B981` |
| `video/*` | `video` | `#8B5CF6` |
| `audio/*` | `music` | `#F59E0B` |
| `application/zip`, `application/x-*compress*` | `archive` | `#6366F1` |
| `text/*` | `file-text` | `#3B82F6` |
| default | `file` | `--text-muted` |

## Interaction Specifications

### Panel Toggle (D-04)

- Click download button: toggle `hidden` class on `.download-panel`
- Click outside (document mousedown): close panel if target is not inside panel
- ESC key: close panel
- Same interaction model as existing `.media-panel`

### Pause/Resume (D-11, D-12, D-13, D-14)

**Single item:**
- Pause button visible when `state === 'in_progress'`
- Resume button visible when `state === 'paused'` or `state === 'interrupted'`
- Click pause: call `window.realmAPI.downloadAPI.pauseDownload(id)`, button switches to resume
- Click resume: call `window.realmAPI.downloadAPI.resumeDownload(id)`, button switches to pause
- If `canResume === false`: resume silently calls re-download (no error shown to user)

**Batch (D-14):**
- "全部暂停" button in panel header, only visible when active downloads > 0
- Click: pause all active downloads, button text changes to "全部恢复"
- Click again: resume all paused downloads

### Delete Flow (D-15, D-17)

1. Click delete icon on list item
2. If download is `in_progress`: first cancel download via `window.realmAPI.downloadAPI.cancelDownload(id)`
3. Show C-04 modal with filename
4. User chooses: checkbox "同时删除本地文件"
5. Click "删除": execute deletion, close modal, remove item from list with fade-out animation (200ms)
6. Click "取消": close modal, no action

### Clear All Flow (D-16)

1. Click "清空所有记录" in panel footer
2. Show C-05 modal
3. Click "清空所有": delete all records, close modal, show empty state
4. Click "取消": close modal, no action

### Multi-select (D-18)

1. Cmd+Click on item: toggle selection (add/remove from selection set)
2. When 2+ items selected: show batch action bar at panel top
3. Batch delete: show C-04 modal with plural text
4. ESC or click deselect: exit multi-select mode

### Real-time Updates

- Listen to IPC events: `download:started`, `download:progress`, `download:completed`, `download:failed`, `download:cancelled`
- Panel open: update list in real-time (insert new items at top, update progress bars)
- Panel closed: queue updates, refresh list on next open
- Progress bar update interval: 500ms (matches Phase 30 tooltip pattern)

## Accessibility

- Panel: `role="dialog"`, `aria-label="下载面板"`
- List items: `role="listitem"`, `aria-label="{filename} - {status}"`
- Action buttons: `aria-label` matching `title` attribute
- Progress bars: `role="progressbar"`, `aria-valuenow`, `aria-valuemin="0"`, `aria-valuemax="100"`
- Modal: standard `<dialog>` element (native focus trap and ESC handling)
- Multi-select: `aria-selected="true/false"` on selected items
- Empty state: `role="status"`, `aria-live="polite"`
