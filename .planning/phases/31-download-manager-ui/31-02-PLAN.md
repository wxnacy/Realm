**src/renderer.js — 下载面板交互逻辑（约 400-500 行新增）：**

1. **修改 initDownloads 中的下载按钮点击处理**（约 L5461-5463）：
   - 将现有的 console.log 替换为调用 `toggleDownloadPanel()`
   - 点击时清除 tooltip 定时器（避免面板和 tooltip 冲突，per RESEARCH.md Pitfall 4）

2. **新增 toggleDownloadPanel()**：
   - 参考 toggleMediaPanel()（L5844）的 toggle 模式
   - 切换 `#downloadPanel` 的 hidden 类和 `#downloadBtn` 的 active 类
   - 打开时调用 `loadDownloadPanelList()` 刷新列表
   - 打开时禁用 tooltip 显示逻辑
   - 关闭时恢复 tooltip 逻辑

3. **新增 loadDownloadPanelList()**：
   - 调用 `window.downloadAPI.getDownloads()` 或新增的全局查询 API（通过 IPC `download:list-all`，limit=10）
   - 渲染列表到 `#downloadPanelList`
   - 无数据时显示 `#downloadEmptyState`

4. **新增 renderDownloadPanelList(downloads)**（参考 UI-SPEC C-02 列表项结构）：
   - 每条记录渲染：文件类型图标（getFileTypeIcon）+ 文件名 + 大小 + 时间 + 状态文本 + 操作按钮
   - 进行中的下载显示进度条（accent 填充）和速度信息
   - 暂停的下载显示进度条（muted 填充）和"已暂停"状态
   - 中断的下载显示进度条（danger 填充）和"下载失败"状态
   - 已完成的下载不显示进度条
   - 操作按钮：进行中→暂停+删除；暂停/中断→恢复+删除；完成→打开+Finder+删除

5. **新增 getFileTypeIcon(mimeType)**：
   - 根据 MIME 类型返回 Lucide SVG 图标字符串
   - 映射表：pdf→file-text(#EF4444), image→image(#10B981), video→video(#8B5CF6), audio→music(#F59E0B), zip→archive(#6366F1), text→file-text(#3B82F6), default→file(--text-muted)

6. **新增操作处理函数**：
   - `handlePauseDownload(downloadId)` — 调用 downloadAPI.pauseDownload，更新按钮状态
   - `handleResumeDownload(downloadId)` — 调用 downloadAPI.resumeDownload，更新按钮状态
   - `handleOpenFile(filePath)` — 调用 downloadAPI.openFile
   - `handleShowInFolder(filePath)` — 调用 downloadAPI.showInFolder
   - `handleDeleteDownload(downloadId, filename, isInProgress)` — 如果进行中先 cancelDownload，然后显示 #downloadDeleteModal，确认后调用 download:delete-record
   - `handleClearAllDownloads()` — 显示 #downloadClearModal，确认后调用 download:clear-all

7. **批量操作（per D-14, D-18）**：
   - `handlePauseAll()` — 遍历所有进行中的下载，逐个 pauseDownload
   - `handleResumeAll()` — 遍历所有暂停的下载，逐个 resumeDownload
   - Cmd+Click 多选模式：维护 selectedIds Set，选中 2+ 时显示 #downloadBatchBar
   - 批量删除：显示确认弹窗（"确定要删除选中的 N 条记录吗？"）

8. **实时更新（per UI-SPEC Real-time Updates）**：
   - 在现有 handleDownloadStarted/handleDownloadProgress/handleDownloadCompleted 中添加面板列表更新逻辑
   - 面板打开时：实时更新进度条、插入新下载到列表顶部
   - 面板关闭时：标记 dirty 标志，下次打开时刷新

9. **外部点击关闭和 ESC 关闭**：
   - 在现有 document mousedown 监听中添加 downloadPanel 的关闭逻辑（参考 media-panel 模式）
