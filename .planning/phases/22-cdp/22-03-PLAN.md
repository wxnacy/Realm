在 main.js 中添加 webview 销毁时的 CDP 清理逻辑（per D-03：用完即卸）：

1. 在 main.js 中找到 webview 事件监听的位置（通常在 createTab 或类似函数中）

2. 添加 webview 的 'destroyed' 事件监听：
```javascript
webview.addEventListener('destroyed', () => {
  const webContentsId = webview.getWebContentsId();
  if (webContentsId) {
    cdpManager.detachForAI(webContentsId);
    console.log(`[Realm] webview 销毁，清理 CDP 调试器: ${webContentsId}`);
  }
});
```

3. 确保 cdp-manager 模块已正确导入：
```javascript
const cdpManager = require('./cdp-manager');
```

4. 如果 main.js 中已有 webview 事件监听（如 'did-start-navigation'、'did-finish-load' 等），
   在同一位置添加 'destroyed' 事件监听

5. 注意：webview 的 'destroyed' 事件在 webview 被移除或页面导航时触发
