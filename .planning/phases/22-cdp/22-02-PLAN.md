2. execute 函数实现逻辑：
   a. 获取 tabId：params.tabId || tabManager.getActiveTab()?.id
   b. 验证 tab 存在，不存在抛出错误 '标签页不存在'
   c. 调用 cdpManager.attachForAI(tab.webContentsId, ['Runtime'])，失败则抛出错误
   d. 在 try/finally 块中执行：
      - 构建链接提取脚本（per D-08 过滤规则）：
        ```javascript
        const extractScript = `
          (function() {
            const links = Array.from(document.querySelectorAll('a[href]'))
              .map(a => {
                try {
                  const url = new URL(a.href, window.location.origin);
                  return {
                    url: url.href,
                    text: (a.textContent || '').trim().substring(0, 200)
                  };
                } catch {
                  return null;
                }
              })
              .filter(link => {
                if (!link) return false;
                // 仅保留 http/https 协议
                if (!link.url.startsWith('http://') && !link.url.startsWith('https://')) {
                  return false;
                }
                // 过滤锚点链接
                if (link.url.includes('#') &&
                    link.url.split('#')[0] === window.location.href.split('#')[0]) {
                  return false;
                }
                // 过滤空文本链接
                if (!link.text) return false;
                return true;
              });
            // URL 去重
            const seen = new Set();
            const uniqueLinks = links.filter(link => {
              if (seen.has(link.url)) return false;
              seen.add(link.url);
              return true;
            });
            return JSON.stringify({
              total: uniqueLinks.length,
              links: uniqueLinks
            });
          })()
        `;
        ```
      - 调用 cdpManager.executeCommand(tab.webContentsId, 'Runtime.evaluate', {expression: extractScript, returnByValue: true})
      - 解析返回的 JSON 字符串
      - 返回 {content: [{type: 'text', text: JSON.stringify(data, null, 2)}], details: {totalLinks: data.total}}
   e. finally 块中调用 cdpManager.detachForAI(tab.webContentsId)

```javascript

  name: 'open_link',
  label: '打开链接',

  parameters: {

        type: 'string',

        type: 'string',

      },
      newTab: {
        type: 'boolean',
        description: '是否在新标签页中打开（可选，默认 true）'
      }
    },
    required: ['url']
  },
  execute: async (toolCallId, params) => { ... }
}
```

2. execute 函数实现逻辑：
   a. 解构参数：const { url, newTab = true } = params;
   b. 验证 URL：
      - 检查 url 存在且以 http:// 或 https:// 开头
      - 不合法则抛出错误 '无效的 URL，仅支持 http/https 协议'
   c. 获取容器 ID（per D-10）：
      - const containerId = params.containerId || windowManager.getCurrentContainer(windowManager.getMainWindow()?.id)
      - 如果 containerId 为空，使用 'default' 作为兜底
   d. 验证容器存在：
      - 通过 this.configStore.get('containers', []) 获取容器列表
      - 查找匹配的容器，不存在则抛出错误 '指定容器不存在或已删除'
   e. 根据 newTab 参数执行不同操作（per D-11）：
      - newTab === true（默认）：
        - 调用 tabManager.createTab(containerId, url) 创建新标签页
        - 记录 tab 对象
      - newTab === false：
        - 获取当前活跃标签页 tabManager.getActiveTab()
        - 不存在活跃标签页则抛出错误 '没有活跃的标签页'
        - 通过 webContents.fromId(tab.webContentsId) 获取 webContents
        - 检查 wc.isDestroyed()，已销毁抛出错误 '标签页已关闭'
        - 调用 wc.loadURL(url) 导航到目标 URL
        - 更新 tab 对象的 url 属性
   f. 返回结果：
