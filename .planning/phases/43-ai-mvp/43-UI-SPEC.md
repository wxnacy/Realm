## 本阶段 UI 表面（3 处）

1. **设置页「AI 记忆」子区域** — 嵌入 `settings-ai-assistant` section（「网络搜索」子区域之后，用户已确认不加侧边栏项）。复用「网络搜索」的 `settings-group` + `settings-group-header` 模式
2. **容器删除确认文案补充** — 沿用 container-manager 现有确认链路（主窗口原生 `<dialog>` + `showModal()`，遵循 AGENTS.md 弹框居中约定）
3. **AI 工具卡片（既有，零新设计）** — `memory` / `memory_read` 工具调用经 renderer 现有工具卡片展示，不新增卡片样式

### 「AI 记忆」子区域结构

```
settings-group.search-config-section 模式
├─ settings-group-header: <h2>「AI 记忆」</h2>
└─ settings-group-content
   ├─ Tab 栏（3 个 tab，用户已确认 Tab 切换）：
   │   「用户画像」｜「全局记忆」｜「容器记忆」
   ├─ 容器下拉（仅「容器记忆」tab 显示，class="settings-select"）
   ├─ textarea（monospace，min-height 200px，显示含 [Mn] 编号的原始文本）
   ├─ 状态行：字数统计「1320 / 2200」+ 生效时机 hint（ai-form-hint 类）
   └─ 操作行：<button class="btn btn-primary">「保存记忆」</button>
```

**视觉主锚点**：textarea 记忆编辑区是「AI 记忆」子区域的主要视觉锚点（最大元素）；Tab 栏为次级导航，CTA 为动作锚点。强调层级依此排列，执行时勿将 CTA 或 tab 栏做成视觉核心。

**CSP 约束（realm://settings，`style-src 'self'`）：**
- 元素初始隐藏（如容器下拉、非当前 tab 的编辑区）必须走 CSS 类规则，markup 内禁止 `style="display:none"`
- 显隐切换用 JS CSSOM（`el.style.display = 'flex'/'block'/'none'`），不要依赖 `''` 回落
- Tab 非激活态初始隐藏建议 tab 面板各自一个 CSS 类 + `.active` 规则控制

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Tab 项内边距、图标与文字间距 |
| sm | 8px | 状态行内部间距、textarea 内边距增量 |

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--bg-primary)`（暗 `#1a1a1a` / 亮 `#ffffff`） | 设置页背景 |
| Secondary (30%) | `var(--bg-secondary)` / `var(--bg-tertiary)` | settings-group 卡片、textarea 底色、tab 栏底 |
| Accent (10%) | `var(--accent-color)` `#3B82F6` | 见下方 reserved list |
| Destructive | `var(--danger-color)` `#EF4444` | 字数超限计数变色、删除确认框中的「AI 记忆将一并删除」提示 |
| Semantic success | `var(--success-color)` `#10B981` | 保存成功反馈（2s 后消失，不弹框） |

Accent reserved for（仅限以下元素）:
- 「保存记忆」主按钮（`btn btn-primary` 既有样式）
- 当前激活 tab 的高亮下划线/文字色
- 容器下拉 focus 边框

除此之外一律用中性色。威胁扫描/超限等警示用 `--danger-color`，不用 accent。

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | 「保存记忆」（显式保存，D-12；点击才写盘，无自动保存） |
| Tab 标签 | 「用户画像」/「全局记忆」/「容器记忆」（对应 USER.md / MEMORY.md / memories/<id>.md） |
| 字数统计 | 「1320 / 2200」格式；用户画像 tab 上限 1375，全局与容器 tab 上限 2200（D-07/D-08） |
| 超限状态 | 计数变 `--danger-color` + 保存按钮 disabled + hint：「超出字符上限，请精简内容后再保存」 |
| 生效时机 hint（用户画像/全局 tab） | 「保存后将在新会话生效」（D-04 冻结快照语义） |
| 生效时机 hint（容器 tab） | 「容器记忆即时生效，AI 通过 memory_read 按需读取」 |
| Empty state（容器 tab，文件不存在） | hint：「该容器暂无记忆，AI 首次写入后在此显示」（与 D-05 memory_read 空态文案呼应） |
| Empty state（用户画像/全局首次为空） | hint：「暂无内容，AI 写入记忆后在此显示」 |
| 保存成功 | 「已保存」（状态行内 `--success-color` 文字，2 秒后消失） |
| 保存失败（HTTP 错误） | 「保存失败：{原因}，请重试」（`--danger-color`，与 `ai-model-error` 样式一致） |
| Destructive confirmation | 删除容器：现有确认文案后追加「该容器的 AI 记忆将一并删除」（D-05；确认方式沿用现有原生 dialog，不新增二次确认） |

### 工具结果文案（AI-facing，经既有工具卡片可见）

| 场景 | Copy |
|------|------|
| 记忆写满 | 「记忆已达字符上限（{2200/1375}），请先整理旧记忆（用 replace 或 remove）再添加新条目」（D-07） |

| error | 保存失败（textarea/状态行/按钮）+ 取数失败（tab/下拉） | ✅ explicit | 状态行渲染「保存失败：{原因}，请重试」，textarea 内容不丢失；取数失败沿用同一状态行错误文案 |

| overflow / long-text / zero-one-many | 容器下拉原生行为（E2）、工具卡片列表（E7） | ⛔ dismissed | 原生 `select` 控件自处理溢出与长文本；卡片列表沿用既有滚动与多条展示行为 |
