创建 credential-manager.js 模块，遵循 download-manager.js 的模式（延迟加载 better-sqlite3、WAL 模式、shared history.db）。

模块导出以下函数：

1. initDatabase() — 初始化数据库连接，创建 credentials 表：
   - 表结构：id (INTEGER PK AUTOINCREMENT), container_id (TEXT NOT NULL), url (TEXT NOT NULL), origin (TEXT NOT NULL), username (TEXT NOT NULL), encrypted_password (BLOB NOT NULL), never_save (INTEGER DEFAULT 0), created_at (INTEGER), updated_at (INTEGER)
   - 索引：idx_credentials_container_id, idx_credentials_origin
   - UNIQUE 约束：(container_id, origin) — 同一容器同一 origin 只保存一个凭据（per D-10）

2. async saveCredential(containerId, url, origin, username, password) — per D-04, AF-02：
   - 调用 safeStorage.isAsyncEncryptionAvailable() 检查加密可用性
   - 不可用时返回 { success: false, error: 'safeStorage 加密不可用' }，拒绝存储
   - 可用时调用 safeStorage.encryptStringAsync(password) 加密
   - INSERT OR REPLACE 到 credentials 表（per D-10: 同一 origin 最后一个覆盖）

3. async getCredential(containerId, origin) — per AF-03：
   - 查询 credentials 表 WHERE container_id = ? AND origin = ? AND never_save = 0
   - 如果找到，调用 safeStorage.decryptStringAsync(encrypted_password) 解密
   - 检查 shouldReEncrypt 标志，必要时重新加密（密钥轮转懒更新）
   - 返回 { username, password } 或 null

4. markNeverSave(containerId, origin) — per D-07：
   - INSERT OR REPLACE 凭据记录，设置 never_save = 1，encrypted_password 为空 Buffer

5. isNeverSave(containerId, origin) — 检查是否在永不保存列表：
   - 查询 never_save = 1 的记录，返回 boolean

6. deleteCredential(containerId, origin) — 删除凭据记录

所有函数遵循项目规范：function 关键字定义、JSDoc 注释、console.error 错误日志、[Realm] 前缀。

关键实现细节（per 32-RESEARCH.md Pattern 1 & Pattern 2）：
- safeStorage 使用异步 API（encryptStringAsync/decryptStringAsync），不使用已废弃的同步版本
- 密码字段使用 BLOB 类型存储加密后的 Buffer
- 数据库路径与 download-manager.js 共享 history.db

在 ipc-handlers.js 中添加 credential:* IPC 通道（per 32-RESEARCH.md Code Examples）：

   const credentialManager = require('./credential-manager');

2. 在 registerHandlers() 函数内，download:* 通道之后添加 credential:* 命名空间：

   ipcMain.handle('credential:save', async (event, data) => {
     assertTrustedSender(event);
     // data: { containerId, url, origin, username, password }
     return await credentialManager.saveCredential(data.containerId, data.url, data.origin, data.username, data.password);
   });

   ipcMain.handle('credential:get', async (event, { containerId, origin }) => {
     assertTrustedSender(event);
     return await credentialManager.getCredential(containerId, origin);
   });

   ipcMain.handle('credential:never-save', async (event, { containerId, origin }) => {
     assertTrustedSender(event);
     return credentialManager.markNeverSave(containerId, origin);
   });

   ipcMain.handle('credential:is-never-save', async (event, { containerId, origin }) => {
     assertTrustedSender(event);
     return credentialManager.isNeverSave(containerId, origin);
   });

   ipcMain.handle('credential:delete', async (event, { containerId, origin }) => {
     assertTrustedSender(event);
     return credentialManager.deleteCredential(containerId, origin);
   });

   - 顶部添加 require：const credentialManager = require('./credential-manager');
