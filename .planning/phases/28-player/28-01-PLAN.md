<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| renderer → main (media:play) | 渲染进程传递 url 和 containerId，主进程需校验参数类型 |
| main → player (media:play-url) | 主进程发送媒体数据到播放器窗口，数据来源可信 |
| player → main (player:toggle-fullscreen) | 播放器窗口请求全屏切换，主进程校验发送者 |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-28-01 | Tampering | media:play IPC | medium | mitigate | assertTrustedSender(event) 校验发送者；参数类型检查 url 为 string、containerId 为 string |
| T-28-02 | Tampering | player:toggle-fullscreen IPC | low | accept | 播放器窗口通过 contextBridge 暴露的 API 调用，已受 contextIsolation 保护 |
