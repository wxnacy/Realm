**src/player.js — 新建文件，实现完整播放器逻辑**

模块结构（使用 IIFE 或顶层函数，不使用 ES module import — Electron preload 环境限制）：

**1. 格式检测与库初始化（per D-05, D-06, D-07, D-08, D-09, D-10）**

`detectFormat(url)` 函数：
- 解析 URL pathname，匹配后缀（不区分大小写）
- `.m3u8` → `'hls'`
- `.flv` → `'mpegts'`
- `.ts` → `'mpegts'`
- `.mpd` → `'dash'`
- `.mp4` → `'native'`
- `.webm` → `'native'`
- 其他 → `'unknown'`

`initPlayer(url)` 异步函数：
- 维护模块级变量 `currentEngine = null`（当前播放库实例）
- 调用前先 destroy 旧实例（`if (currentEngine) { currentEngine.destroy(); currentEngine = null; }`）（per Pitfall 2）
- 按格式分支：
  - `'hls'`: `const Hls = window.Hls || (await import('hls.js')).default`；检查 `Hls.isSupported()`；创建 `new Hls({ enableWorker: true })`（CSP 已配置 worker-src），调用 `hls.loadSource(url); hls.attachMedia(video)`；返回 `{ engine: hls, destroy: () => hls.destroy() }`
  - `'mpegts'`: `const mpegts = window.mpegts || (await import('mpegts.js')).default`；检查 `mpegts.isSupported()`；调用 `mpegts.createPlayer({ type: 'flv', url })`；`player.attachMediaElement(video); player.load(); player.play()`；返回 `{ engine: player, destroy: () => { player.unload(); player.detachMediaElement(); player.destroy(); } }`
  - `'dash'`: `const dashjs = window.dashjs || (await import('dashjs')).default`；`const player = dashjs.MediaPlayer().create()`；`player.initialize(video, url, true)`；返回 `{ engine: player, destroy: () => player.reset() }`
  - `'native'`: `video.src = url; video.play()`；返回 `{ engine: null, destroy: () => { video.src = ''; video.load(); } }`
  - `'unknown'`: 显示错误提示 "无法播放 — 不支持的视频格式"，不加载任何库

**2. IPC 数据接收（per Plan 1 的 playerAPI）**

调用 `window.playerAPI.onPlayUrl((data) => { ... })` 接收主进程发送的 `{ url, mediaList, containerId }`：
- 存储 `state.mediaList = data.mediaList || []`
- 存储 `state.containerId = data.containerId`
- 存储 `state.currentUrl = data.url`
- 更新窗口标题为 URL 末段文件名
- 调用 `initPlayer(data.url)` 初始化播放
- 更新播放列表按钮状态（上一个/下一个 disabled）

**3. 控制栏 UI（per D-01, D-02, D-03, D-05, D-11, D-15, D-17, D-18）**

播放/暂停：
- 点击播放按钮：`video.paused ? video.play() : video.pause()`
- 视频 play 事件：更新按钮图标为 pause，隐藏播放覆盖
- 视频 pause 事件：更新按钮图标为 play，显示播放覆盖
- 视频 ended 事件：显示播放覆盖，尝试播放列表下一个

进度条（per D-11, D-15）：
- `timeupdate` 事件：更新进度条位置和时间显示
- 进度条 click：跳转到点击位置 `video.currentTime = (clickX / trackWidth) * video.duration`
- 进度条 mousedown + mousemove：拖拽模式，实时更新 `video.currentTime`
- 进度条 mouseover：显示时间预览气泡，位置跟随鼠标
- 时间显示格式（per D-18）：`HH:MM:SS`，不足 1 小时不显示小时位
- 拖拽实时预览（per D-15）：拖拽时 `video.currentTime` 跟随更新，视频画面实时跳转到拖拽位置；悬停时显示时间预览气泡

缓冲进度：
- `progress` 事件：更新缓冲条宽度 `video.buffered.end(video.buffered.length-1) / video.duration`

音量（per D-12, PLAYER-07）：
- 音量滑块 input 事件：`video.volume = slider.value`
- 音量按钮 click：`video.muted = !video.muted`，切换图标（volume-high/volume-mute）
- 音量变化事件：更新滑块位置和图标（volume-high > 0.5, volume-low > 0, volume-mute = 0）

倍速（per D-17, PLAYER-08）：
- 倍速按钮 click：切换倍速菜单显示/隐藏
- 菜单项 click：`video.playbackRate = parseFloat(value)`，更新按钮文字为当前倍速 + "x"，关闭菜单
- 可选值：0.5, 1, 1.5, 2
- 当前选项高亮 #3B82F6

全屏（per D-12, D-13, PLAYER-09）：
- 全屏按钮 click 或 F 键：调用 `window.playerAPI.toggleFullscreen()`
- 双击视频区域（per D-13）：使用 300ms 延迟区分单击和双击
  - `click` 事件：设置 `clickTimer = setTimeout(() => { /* 单击播放/暂停 */ }, 300)`
  - `dblclick` 事件：`clearTimeout(clickTimer)` 取消单击，调用 `window.playerAPI.toggleFullscreen()`
  - 这样单击播放/暂停不会在双击时误触发
- 全屏状态变化：监听 `document fullscreenchange` 事件，更新按钮图标

画中画（per D-14）：
- 如果 `video.requestPictureInPicture` 不存在，隐藏 PiP 按钮
- PiP 按钮 click：使用 try-catch 包裹 `video.requestPictureInPicture()`，catch 中 console.error 记录错误
- 监听 `video.addEventListener('enterpictureinpicture', ...)`：更新 PiP 按钮图标为退出态
- 监听 `video.addEventListener('leavepictureinpicture', ...)`：恢复 PiP 按钮图标为进入态
- `document.pictureInPictureElement` 判断当前状态：若已在 PiP 则调用 `document.exitPictureInPicture()`

**4. 控制栏自动隐藏（per D-03, Pattern 3）**

- `hideTimer` 变量管理定时器
- `mousemove` 事件：显示控制栏 + 标题栏（opacity 1），清除定时器，设置 3 秒后隐藏
- `mouseleave` 事件：立即隐藏（如果视频在播放）
- 视频 pause 时：始终显示控制栏，清除隐藏定时器
- 视频 play 时：设置 3 秒后隐藏定时器
- 隐藏时：仅保留进度条细线（高度 3px，rgba(255,255,255,0.2)）
- 全屏模式鼠标移至屏幕底部：触发显示

**5. 键盘快捷键（per D-12）**

`document.addEventListener('keydown', ...)`：
- 忽略 `e.target.tagName === 'INPUT'` 的情况
- `Space` → `e.preventDefault(); video.paused ? video.play() : video.pause()`
- `ArrowLeft` → `e.preventDefault(); video.currentTime = Math.max(0, video.currentTime - 5)`
- `ArrowRight` → `e.preventDefault(); video.currentTime = Math.min(video.duration, video.currentTime + 5)`
- `ArrowUp` → `e.preventDefault(); video.volume = Math.min(1, video.volume + 0.05)`
- `ArrowDown` → `e.preventDefault(); video.volume = Math.max(0, video.volume - 0.05)`
- `f` / `F` → `window.playerAPI.toggleFullscreen()`
- `m` / `M` → `video.muted = !video.muted`

**6. 播放列表（per D-16）**

- 上一个/下一个按钮：在 `state.mediaList` 中查找当前 URL 的 index，切换到相邻项
- 上一个按钮在 index === 0 时 disabled（opacity 0.3）
- 下一个按钮在 index === mediaList.length - 1 时 disabled
- 切换时：先 destroy 当前引擎（per Pitfall 2），调用 `initPlayer(newUrl)`
- 视频 ended 事件：自动播放下一个（如果有）

**7. 资源释放（per D-21, PLAYER-10）**

`window.addEventListener('beforeunload', ...)`：
- 调用 `currentEngine.destroy()`（如果存在）
- 设置 `video.src = ''; video.load()` 释放原生资源
- 清除所有定时器

- 标题栏悬停时显示图标（默认只显示圆点）
