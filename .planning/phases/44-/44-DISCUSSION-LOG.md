## 前置：方案定稿（命令前讨论，2026-09-06）

方案骨架在 /gsd-phase 之前已通过两轮 AskUserQuestion 定稿并记入 ROADMAP Goal：
- 范围只在独立播放器（webview 保持直连不做缓存）——用户明确要求记住
- 独立窗口统一走 proxy（localhost 加载 + token 注入）
- mux.js 纯 JS 转 mp4（不用 ffmpeg）；产物弹框选目录
- 录制 = 显式后台任务（注册表/并发上限/去重/重试/退出确认/关窗提示）
- realm://tasks 任务页 + 设置页多媒体分区入口
- 观看历史双层设计，续播 key = origin+pathname

## 录制独立性（用户追加提问）

**User's question:** 直播录制过程中，点击播放/暂停有影响吗？刷新呢？

**Answer:** 录制任务在主进程独立追分片，不经播放器 video/hls.js 实例——播放/暂停/刷新/切视频均无影响。

| Option | Description | Selected |
|--------|-------------|----------|
| 完全独立 | 播放状态完全解耦，红点可点停止 | ✓ |
| 暂停联动 | 暂停播放时录制也暂停（会丢分片） | |

**User's choice:** 完全独立
