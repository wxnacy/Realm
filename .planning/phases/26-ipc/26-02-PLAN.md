  <action>
    **1. 修改 `ipc-handlers.js` — 注册 media:* IPC 通道：**

    在 registerHandlers() 函数中（参考现有 favorites:*, script:* 通道注册模式），添加以下通道（per IPC-01~04）：

    - `ipcMain.handle('media:get-list', (event) => {...})`：调用 `assertTrustedSender(event)`，通过 `windowManager.getMainWindow()` 和 `windowContainerMap.get(win.id)` 获取当前容器 ID，返回 `mediaSniffer.getMediaList(containerId)`（per IPC-01）
    - `ipcMain.handle('media:play', async (event, url) => {...})`：调用 `assertTrustedSender(event)`，创建新的 BrowserWindow（width:800, height:600, webPreferences 包含 preload），加载 `src/player.html`，通过 `playerWin.webContents.send('media:play-url', url)` 传入视频 URL，返回 `{ success: true }`（per IPC-02）
    - `ipcMain.handle('media:copy-url', (event, url) => {...})`：调用 `assertTrustedSender(event)`，使用 `require('electron').clipboard.writeText(url)` 复制到剪贴板，返回 `{ success: true }`（per IPC-03）
    - `ipcMain.handle('media:clear-list', (event) => {...})`：调用 `assertTrustedSender(event)`，获取当前容器 ID，调用 `mediaSniffer.clearMediaList(containerId)`，返回 `{ success: true }`（per IPC-04）
    - `ipcMain.handle('media:report-detected', (event, containerId, videos) => {...})`：调用 `assertTrustedSender(event)`，调用 `mediaSniffer.handleScriptDetected(containerId, videos)` 将脚本注入检测到的视频数据传入 MediaSniffer，返回 `{ success: true }`。此通道是 Plan 01 脚本注入检测结果从渲染进程回传到主进程 MediaSniffer 的唯一桥梁。

    文件顶部需要 require media-sniffer 模块（Plan 01 创建）。

    **2. 修改 `src/preload.js` — 暴露 mediaAPI：**

    在现有 `contextBridge.exposeInMainWorld('realmAPI', {...})` 调用中，添加媒体相关方法（或创建独立的 `contextBridge.exposeInMainWorld('mediaAPI', {...})` 调用，per IPC-05）。推荐合并到 realmAPI 中保持一致性，但如果 mediaAPI 语义独立也可以单独暴露。

    采用合并到 realmAPI 的方案（与现有模式一致），添加以下方法：
    - `getMediaList: () => ipcRenderer.invoke('media:get-list')`
    - `playMedia: (url) => ipcRenderer.invoke('media:play', url)`
    - `copyMediaUrl: (url) => ipcRenderer.invoke('media:copy-url', url)`
    - `clearMediaList: () => ipcRenderer.invoke('media:clear-list')`
    - `reportMediaDetected: (containerId, videos) => ipcRenderer.invoke('media:report-detected', containerId, videos)` — 脚本注入检测结果上报通道
    - `onMediaListUpdate: (callback) => { const handler = (event, data) => callback(data); ipcRenderer.on('media:list-updated', handler); return () => ipcRenderer.removeListener('media:list-updated', handler); }`（per D-09 返回清理函数）

    如果选择独立 mediaAPI，则在 preload.js 中添加第二个 `contextBridge.exposeInMainWorld('mediaAPI', {...})` 调用。
