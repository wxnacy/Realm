## Components

### C-01: Download Button (`download-btn`)

**Location:** `toolbar-right`, positioned between `mediaPanelBtn` and `aiPanelBtn` (D-16: right of URL input, with other nav buttons).

**Structure:**
```html
<button class="btn-icon download-btn" id="downloadBtn" title="下载管理">
  <!-- Default state: download arrow icon -->
  <svg class="download-icon-default" width="18" height="18" viewBox="0 0 24 24"
       fill="none" stroke="currentColor" stroke-width="2">
    <path d="M21 15v4a2 2 0 0 1-2 2H5a2 2 0 0 1-2-2v-4"/>
    <polyline points="7 10 12 15 17 10"/>
    <line x1="12" y1="15" x2="12" y2="3"/>
  </svg>
  <!-- Active state: circular progress ring (hidden by default) -->
  <svg class="download-progress-ring" width="28" height="28" viewBox="0 0 28 28"
       style="display:none">
    <circle cx="14" cy="14" r="12" fill="none" stroke="var(--bg-tertiary)"
            stroke-width="2.5"/>
    <circle cx="14" cy="14" r="12" fill="none" stroke="var(--accent-color)"
            stroke-width="2.5" stroke-dasharray="75.4" stroke-dashoffset="75.4"
            stroke-linecap="round" transform="rotate(-90 14 14)"
            class="download-progress-fill"/>
  </svg>
  <!-- Completion state: green checkmark (hidden by default) -->
  <svg class="download-icon-done" width="18" height="18" viewBox="0 0 24 24"
       fill="none" stroke="var(--success-color)" stroke-width="2.5"
       stroke-linecap="round" stroke-linejoin="round" style="display:none">
    <polyline points="20 6 9 17 4 12"/>
  </svg>
  <!-- Badge: active download count (hidden by default) -->
  <span class="download-badge hidden" id="downloadBadge">0</span>
</button>
```

**States:**
1. **Idle** (no downloads, no history): Default download icon, no badge. Always visible (D-15).
2. **Idle with history**: Default download icon, no badge.
3. **Active download(s)**: Circular progress ring visible, default icon hidden. Badge shows active count (D-08, D-14).
4. **Multiple active downloads**: Progress ring shows aggregate progress (weighted by file size). Badge shows count.
5. **All downloads complete**: Green checkmark icon replaces progress ring. Badge hidden. Checkmark auto-reverts to default icon after 3 seconds (D-07).

**Sizing:** 32x32px (standard `btn-icon`). Progress ring is 28x28px centered within. SVG icons are 18x18px (existing pattern).

**Interaction:**
- Click: Opens download panel (Phase 31). In Phase 30, click is a no-op (panel not yet implemented).
- Hover: Shows custom download tooltip (C-02) with active download details.

### C-02: Download Progress Tooltip (`download-tooltip`)

**Position:** Fixed, anchored below the download button. Appears on button hover when there are active downloads.

**Structure:**
```html
<div class="download-tooltip" id="downloadTooltip">
  <!-- Repeated per active download (max 3 visible, "+N more" for overflow) -->
  <div class="download-tooltip-item">
    <div class="download-tooltip-name">filename.ext</div>
    <div class="download-tooltip-detail">
      <span class="download-tooltip-size">12.5 MB / 50 MB</span>
      <span class="download-tooltip-separator">·</span>
      <span class="download-tooltip-speed">2.3 MB/s</span>
      <span class="download-tooltip-separator">·</span>
      <span class="download-tooltip-eta">剩余 16s</span>
    </div>
    <div class="download-tooltip-progress">
      <div class="download-tooltip-progress-bar" style="width: 25%"></div>
    </div>
  </div>
</div>
```

**Behavior:**
- Appears on hover with 200ms delay (prevents flicker on quick mouse passes).
- Disappears on mouse leave with 100ms delay.
- Shows max 3 active downloads; if more, shows "+N more" link.
- When no active downloads: tooltip does not appear (hover shows native `title` attribute only).
- Updates in real-time while visible (speed, progress, ETA refresh every 500ms).

**Sizing:** Min-width 260px, max-width 340px. Padding 12px 16px. Border-radius 8px.

### C-03: Download Badge (`download-badge`)

**Pattern:** Identical to existing `media-badge` (source: `src/styles/main.css:5952`).

**Position:** Absolute, top: -4px, right: -4px (overlaps button corner).

**Sizing:** Min-width 16px, height 16px, border-radius 8px, font-size 10px, padding 0 4px.

**Color:** Background `var(--danger-color)` (#EF4444), text white.

**Behavior:** Hidden when count is 0. Shows count when >= 1. Max display "9+" for counts > 9.

## Interaction Specifications

### Progress Ring Animation

- **Stroke-dashoffset** transitions from `75.4` (0%) to `0` (100%).
- CSS transition: `stroke-dashoffset 0.3s ease` for smooth progress updates.
- Progress updates arrive via IPC every 500ms from main process.
- For multiple downloads: ring shows weighted aggregate progress (sum of bytes downloaded / sum of total bytes).

### Tooltip Positioning

- Anchored to download button bottom-center.
- Offset: top = button bottom + 4px.
- Horizontal: centered on button, clamped to viewport edges (min 8px from screen edge).
- z-index: matches existing floating panels (e.g., `media-panel` at z-index 1000).

### Badge Animation

- Scale-in on first appearance: `transform: scale(0) -> scale(1)` over 150ms ease-out.
- Number change: instant update (no animation, matches `media-badge` behavior).
- Hide: instant `display: none` via `.hidden` class.

### Completion Auto-Revert

- Green checkmark shows for 3 seconds after last active download completes.
- After 3s, crossfade to default download icon (opacity transition 200ms).
- If new download starts during completion display, immediately switch to progress ring.

## Accessibility

- Download button: `role="button"`, `aria-label="下载管理"` (idle) or `aria-label="下载管理 - N 个下载中"` (active).
- Progress ring: `role="progressbar"`, `aria-valuenow="{percent}"`, `aria-valuemin="0"`, `aria-valuemax="100"`.
- Badge: `aria-label="{N} 个活跃下载"` (screen reader context).
- Tooltip: `role="tooltip"`, `aria-hidden="true"` when hidden.
- All interactive elements maintain existing keyboard navigation pattern (tab order follows DOM order in `toolbar-right`).
