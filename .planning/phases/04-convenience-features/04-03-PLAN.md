## Tasks

### Task 1: 后端增强 — assignment-rules.js + ipc-handlers.js + preload.js

**Files:** `assignment-rules.js`, `ipc-handlers.js`, `src/preload.js`

**Read First:**
- `assignment-rules.js` — 现有规则 CRUD
- `ipc-handlers.js` — 现有 IPC 处理器
- `src/preload.js` — 现有 API 暴露

**Action:**

**assignment-rules.js 新增函数：**

1. 新增 `reorderRules(orderedIds)` 函数：
   - 参数：`orderedIds` — 规则 ID 的有序数组
   - 验证：所有 ID 必须存在于 rules Map 中
   - 实现：按照 orderedIds 顺序重建 rules Map（Map 保持插入顺序）
   - 调用 `saveRules()` 持久化
   - 返回 `true`

2. 新增 `exportRules()` 函数：
   - 返回 `{ rules: Array.from(rules.values()), exportedAt: Date.now() }`

3. 新增 `importRules(rulesData)` 函数：
   - 参数：`rulesData` — 解析后的规则数组
   - 验证每条规则必须有 `containerId` 和 `pattern`
   - 调用 `createRule()` 逐条创建（复用现有验证逻辑）
   - 返回 `{ success: true, count: imported }` 或 `{ success: false, message: '...' }`

4. 新增 `reorderRules` 到 module.exports

**ipc-handlers.js 新增处理器：**

1. 新增 `rule:reorder` 处理器：
   - 参数：`orderedIds`（规则 ID 数组）
   - 调用 `assignmentRules.reorderRules(orderedIds)`
   - 返回 `{ success: true }`

2. 新增 `rule:export` 处理器：
   - 使用 `dialog.showSaveDialog` 选择保存路径
   - 默认文件名：`realm-rules-${Date.now()}.json`
   - 使用 `fs.writeFileSync` 写入 JSON
   - 返回 `{ success: true, count: rules.length }`

3. 新增 `rule:import` 处理器：
   - 使用 `dialog.showOpenDialog` 选择文件
   - 使用 `fs.readFileSync` 读取 JSON
   - 验证格式（必须包含 `rules` 数组）
   - 调用 `assignmentRules.importRules(data.rules)`
   - 返回 `{ success: true, count: imported }`

**src/preload.js 新增 API：**

1. 新增 `reorderRules: (orderedIds) => ipcRenderer.invoke('rule:reorder', orderedIds)`
2. 新增 `exportRules: () => ipcRenderer.invoke('rule:export')`
3. 新增 `importRules: () => ipcRenderer.invoke('rule:import')`

**Verify:**
```bash

# 期望: >= 3 (函数定义 + 导出 + 调用)
grep -c "rule:reorder" ipc-handlers.js
# 期望: >= 1
grep -c "reorderRules" src/preload.js
# 期望: >= 1
```

**Done:**
- assignment-rules.js 支持 reorderRules/exportRules/importRules
- ipc-handlers.js 新增 rule:reorder/rule:export/rule:import 处理器
- preload.js 暴露 reorderRules/exportRules/importRules API

### Task 2: 前端 UI — Toggle Switch + Drag-Drop + Import/Export

**Files:** `src/renderer.js`, `src/styles/main.css`, `src/index.html`

**Read First:**
- `src/renderer.js` — 现有规则管理 UI（renderRulesList, showRulesModal 等）
- `src/styles/main.css` — 现有样式
- `src/index.html` — 现有模态框结构
- `.planning/phases/04-convenience-features/04-UI-SPEC.md` — UI 设计规范

**Action:**

**src/styles/main.css 新增样式：**

1. Toggle Switch 样式（per UI-SPEC）：
   - `.toggle-switch` — 容器，cursor: pointer
   - `.toggle-track` — 36px 宽, 20px 高, 圆角 10px, 背景 `--bg-tertiary`
   - `.toggle-track.active` — 背景 `--accent-color`
   - `.toggle-thumb` — 16px 圆形, 白色, 绝对定位
   - `.toggle-track:not(.active) .toggle-thumb` — left 2px
   - `.toggle-track.active .toggle-thumb` — left 18px
   - 过渡动画 0.2s ease

2. Drag Handle 样式：
   - `.drag-handle` — cursor grab, color `--text-muted`, 6px 宽
   - `.rule-item.dragging` — opacity 0.5
   - `.rule-item.drag-over-top` — border-top 2px solid `--accent-color`
   - `.rule-item.drag-over-bottom` — border-bottom 2px solid `--accent-color`

3. Rules Actions 样式：
   - `.rules-actions` — flex, gap 8px, margin-top 12px

**src/index.html 修改：**

1. 在规则模态框的 `.rule-form` 下方添加 `.rules-actions` 区域：
   - `<button class="btn btn-secondary" id="importRulesBtn">导入规则</button>`
   - `<button class="btn btn-secondary" id="exportRulesBtn">导出规则</button>`

**src/renderer.js 修改：**

1. 在 `elements` 对象中添加：
   - `importRulesBtn: document.getElementById('importRulesBtn')`
   - `exportRulesBtn: document.getElementById('exportRulesBtn')`

2. 重写 `renderRulesList(rules)` 函数：
   - 为每个规则项添加 `draggable="true"` 属性
   - 添加 drag handle（`⋮⋮` 图标，class `drag-handle`）
   - 将 toggle 按钮替换为 toggle switch 组件：
     ```
     .toggle-switch
       .toggle-track (class 'active' if rule.enabled)
         .toggle-thumb
     ```
   - 绑定 toggle 点击事件：调用 `window.realmAPI.updateRule(rule.id, { enabled: !rule.enabled })` 后刷新列表
   - 绑定拖拽事件（dragstart, dragover, drop, dragend）

3. 实现拖拽排序逻辑：
   - `dragstart`：设置 `draggedItem`，添加 `dragging` class，`e.dataTransfer.effectAllowed = 'move'`
   - `dragover`：`e.preventDefault()`，计算鼠标位置决定插入目标的上方或下方，添加 drag-over 指示线
   - `drop`：`e.preventDefault()`，移动 DOM 节点
   - `dragend`：移除所有 drag 相关 class，收集新顺序，调用 `window.realmAPI.reorderRules(newOrder)`
   - 使用 `e.dataTransfer.setData('text/plain', ruleId)` 传递被拖拽项 ID

4. 实现导入/导出逻辑：
   - `importRulesBtn` 点击：调用 `window.realmAPI.importRules()`，成功后刷新列表并 Toast
   - `exportRulesBtn` 点击：调用 `window.realmAPI.exportRules()`，成功后 Toast

5. 在 `setupEventListeners()` 中绑定导入/导出按钮事件

**Done:**
