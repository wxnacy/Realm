# Plan 04-02: 快捷键重构 — globalShortcut → Menu Accelerator

## Objective

将快捷键从全局注册（globalShortcut）重构为应用内生效（Menu accelerator），确保快捷键仅在应用窗口获得焦点时生效，避免与系统快捷键冲突。

**Purpose:** D-05/D-06/D-07 明确要求快捷键改为应用内生效，不使用 globalShortcut。当前实现使用 globalShortcut 全局注册，会与系统快捷键冲突。

**Output:** 重构后的 shortcut-manager.js + 更新的 main.js 集成

## Execution Context

@.planning/PROJECT.md
@.planning/ROADMAP.md

## Tasks

### Task 1: 重构 shortcut-manager.js — Menu Accelerator 实现

**Files:** `shortcut-manager.js`

**Read First:**
- `shortcut-manager.js` — 现有实现
- `main.js` — 集成方式

**Action:**

重写 shortcut-manager.js，将核心注册机制从 `globalShortcut` 改为 `Menu` accelerator：

1. 移除 `const { globalShortcut } = require('electron')` 导入
2. 添加 `const { Menu, MenuItem } = require('electron')` 导入
3. 保留 `DEFAULT_SHORTCUTS` 常量和 `getShortcuts()` / `getShortcut()` / `setShortcut()` 函数不变
4. 重写 `registerShortcuts(window)` 函数：
   - 使用 `Menu.buildFromTemplate()` 构建隐藏菜单模板
   - 每个菜单项对应一个快捷键操作，设置 `visible: false`
   - 菜单项的 `click` 回调发送 `shortcut:triggered` IPC 到渲染进程
   - 使用 `Menu.setApplicationMenu(menu)` 设置应用菜单
   - 保存 window 引用以便后续重建菜单
5. 移除 `unregisterAll()` 函数（Menu accelerator 不需要手动注销）
6. 新增 `rebuildMenu(window)` 函数：当快捷键配置变更时重建菜单
7. 更新导出：移除 `unregisterAll`，新增 `rebuildMenu`

**关键实现细节：**
- 菜单模板格式：`[{ label: '_shortcuts', visible: false, submenu: [...items] }]`
- 每个 item：`{ label: action, accelerator: accelerator, visible: false, click: () => { ... } }`
- Menu.setApplicationMenu 会替换整个应用菜单，需要保留 macOS 应用菜单项（如果存在）

**Verify:**
```bash
grep -c "globalShortcut" shortcut-manager.js
# 期望: 0
grep -c "Menu" shortcut-manager.js
# 期望: >= 3
```

**Done:**
- shortcut-manager.js 不再使用 globalShortcut
- 使用 Menu.accelerator 注册快捷键
- 快捷键变更后可通过 rebuildMenu 热更新

### Task 2: 更新 main.js 和 ipc-handlers.js 集成

**Files:** `main.js`, `ipc-handlers.js`

**Read First:**
- `main.js` — 现有 shortcutManager 集成
- `ipc-handlers.js` — shortcut:set 处理器

**Action:**

**main.js 修改：**
1. 在 `app.whenReady()` 中，调用 `shortcutManager.registerShortcuts(mainWindow)` 时传入窗口参数（已有）
2. 移除 `app.on('will-quit')` 中的 `shortcutManager.unregisterAll()` 调用（Menu accelerator 不需要手动注销）
3. 确保 `shortcutManager.registerShortcuts(window)` 在窗口创建后调用

**ipc-handlers.js 修改：**
1. 在 `shortcut:set` 处理器中，设置快捷键后调用 `shortcutManager.rebuildMenu(window)` 热更新菜单
2. 获取 mainWindow 引用：`const win = windowManager.getMainWindow()`
3. 调用 `shortcutManager.rebuildMenu(win)` 确保快捷键立即生效

**Verify:**
```bash
grep -c "unregisterAll" main.js
# 期望: 0
grep -c "rebuildMenu" ipc-handlers.js
# 期望: >= 1
```

**Done:**
- main.js 不再调用 unregisterAll
- ipc-handlers.js 在设置快捷键后调用 rebuildMenu
- 快捷键设置后无需重启即可生效
