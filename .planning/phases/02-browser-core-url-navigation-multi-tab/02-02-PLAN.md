<task type="auto">
  <name>Task 1: Webview 管理器 + URL 标准化 + 安全配置</name>
  <files>src/renderer.js</files>
  <action>
在 src/renderer.js 中实现 WebviewManager 和 URL 处理逻辑。

1. **URL 标准化函数 normalizeUrl(input)**（在 renderer.js 顶部添加）：
   - input = input.trim()
   - 如果以 /^https?:\/\// 开头，直接返回
   - 如果匹配 /^[\w-]+(\.[\w-]+)+/（看起来像域名），返回 `https://${input}`
   - 否则当作搜索查询：`https://www.google.com/search?q=${encodeURIComponent(input)}`
   - 使用 URL 构造函数做基本验证，捕获异常时返回搜索 URL

2. **Webview 安全配置常量**（D-03）：
   ```
   const WEBVIEW_ATTRIBUTES = {
     nodeintegration: 'false',
     disablewebsecurity: 'false',
     allowpopups: 'false',
     webpreferences: 'contextIsolation=yes'
   };
   ```

3. **Webview 管理**（在 state 中添加 webviews: Map<tabId, webviewElement>）：

   **createWebviewForTab(tabId, containerId, url):**
   - 创建 webview 元素
   - 设置 src：如果有 url 则使用，否则 'about:blank'
   - 设置 partition：`persist:container-${containerId}`（D-01, 容器隔离）
   - 应用 WEBVIEW_ATTRIBUTES 安全配置
   - 样式：position absolute, top 0, left 0, width 100%, height 100%
   - 初始 visibility: 'hidden'
   - 插入 .browser-view 容器
   - state.webviews.set(tabId, webview)
   - 绑定 webview 事件（见下方）
   - 返回 webview

   **showWebview(tabId):**
   - state.webviews.forEach((wv, id) => {
       wv.style.visibility = id === tabId ? 'visible' : 'hidden';
     })

   **destroyWebview(tabId):**
   - 获取 webview = state.webviews.get(tabId)
   - 如果存在，调用 webview.remove()
   - state.webviews.delete(tabId)

4. **webview 事件绑定**（在 createWebviewForTab 中调用）：

   **did-navigate / did-navigate-in-page：**
   - 更新 state.tabs.get(tabId).url = e.url
   - 如果是活动 Tab，更新 URL 输入框 value

   **did-start-loading：**
   - 添加 .loading 类到 #reloadBtn（切换为停止图标）
   - 显示加载进度条（.loading-bar）

   **did-stop-loading：**
   - 移除 .loading 类（切换回刷新图标）
   - 隐藏加载进度条

   **page-title-updated：**
   - 调用 updateTabTitle(tabId, e.title)

   **new-window（拦截新窗口请求）：**
   - e.preventDefault()
   - 在当前容器创建新 Tab，URL 为 e.url

   **did-fail-load：**
   - 显示错误页面（简单的错误提示 DOM）

5. **修改 createTab 函数**（集成 webview）：
   - 在 createTab 末尾调用 createWebviewForTab(tabId, containerId, url)
   - 如果 url 不为空且不是 about:blank，调用 webview.loadURL(normalizeUrl(url))

6. **修改 switchTab 函数**（集成 webview 切换）：
   - 调用 showWebview(tabId) 切换 webview 可见性
   - 如果没有对应 webview，隐藏新标签页并显示 webview 区域

7. **修改 closeTab 函数**（集成 webview 销毁）：
   - 在关闭 Tab 时调用 destroyWebview(tabId)（D-08）

8. **XSS 防护**：
   - 所有动态文本使用 textContent
   - URL 经过 normalizeUrl 处理后才传给 webview

<task type="auto">
  <name>Task 2: URL 导航控件 + 加载动画 + 前进后退刷新</name>
  <files>src/renderer.js, src/index.html, src/styles/main.css</files>
  <action>
实现工具栏中的 URL 导航交互和加载状态 UI。

1. **URL 输入框导航**（D-10, D-11）：
   - 在 setupEventListeners 中为 #urlInput 添加 keydown 监听
   - Enter 键触发：
     - 获取输入值，调用 normalizeUrl(value)
     - 获取当前活动 Tab 的 webview
     - 调用 webview.loadURL(normalizedUrl)
     - 更新 state.tabs.get(activeTabId).url
   - 输入框聚焦时全选文本（select()）

2. **地址栏 URL 同步**：
   - 当 webview 触发 did-navigate 或 did-navigate-in-page 时
   - 如果是活动 Tab，更新 #urlInput.value = e.url
   - 使用 updateTabTitle 同步更新 Tab 标题

3. **前进/后退按钮**（BROW-02）：
   - 修改 #backBtn 的 click 事件：
     - 获取当前活动 Tab 的 webview
     - 调用 webview.goBack()
   - 修改 #forwardBtn 的 click 事件：
     - 调用 webview.goForward()
   - 按钮禁用状态：
     - webview.canGoBack() === false 时，#backBtn 添加 disabled 属性
     - webview.canGoForward() === false 时，#forwardBtn 添加 disabled 属性
   - 在 webview 的 did-navigate 事件中更新按钮状态

4. **刷新/停止按钮**（D-13）：
   - 修改 #reloadBtn 的 click 事件：
     - 如果当前正在加载（.loading 类存在），调用 webview.stop()
     - 否则调用 webview.reload()
   - 图标切换：
     - 加载中：显示停止图标（×），通过 .loading 类控制
     - 加载完成：显示刷新图标（沿用现有 SVG）
   - 在 did-start-loading 和 did-stop-loading 事件中切换

5. **加载进度条**（D-13）：
   - 在 index.html 中添加 .loading-bar 元素（位于 .toolbar 底部或 .url-bar 内部）
   - CSS 动画：
     - 默认 opacity: 0
     - 加载中：opacity: 1, animation: loading-progress 2s ease-in-out infinite
     - 加载完成：opacity: 0, transition 200ms
   - 在 did-start-loading 时显示
   - 在 did-stop-loading 时隐藏

6. **容器指示器更新**：
   - 切换 Tab 时，更新容器指示器显示当前 Tab 所属容器的信息
   - 容器颜色点和名称与当前 Tab 的容器对应

7. **新标签页搜索框集成**：
   - .new-tab-search 的 Enter 键：
     - 获取输入值，调用 createTab(state.currentContainer, value)
     - 该 Tab 的 webview 会自动加载 normalizeUrl(value)
     - 隐藏新标签页

8. **安全检查**：
   - 确认所有 webview 创建时使用 WEBVIEW_ATTRIBUTES
   - 确认 URL 经过 normalizeUrl 处理
   - 确认所有动态文本使用 textContent
