# Phase 2 — UI Design Contract

> Visual and interaction contract for Phase 2: Browser Core - URL Navigation + Multi-Tab. Generated by gsd-ui-researcher.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none |
| Icon library | inline SVG (already established in Phase 1) |
| Font | -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif |

**Phase 2 不引入新的设计系统工具。** 沿用 Phase 1 建立的 CSS 自定义属性和深色主题体系。所有新增组件必须使用现有 CSS 变量。

---

## Spacing Scale

基于 Phase 1 已建立的间距体系，标准化为 4 的倍数：

| Token | Value | 用途 |
|-------|-------|------|
| xs | 4px | 图标内边距、紧凑间距 |
| sm | 8px | 元素间距、按钮内边距 |
| md | 16px | 默认元素间距、容器内边距 |
| lg | 24px | 区域内边距、对话框内边距 |
| xl | 32px | 布局间距 |
| 2xl | 48px | 工具栏高度 |
| 3xl | 64px | 页面级间距 |

**Phase 2 特殊间距：**
- Tab 栏高度：36px（紧凑设计，节省垂直空间）
- Tab 最小宽度：120px
- Tab 最大宽度：240px
- Tab 关闭按钮尺寸：16px
- 容器颜色指示线高度：3px
- webview 区域：占满剩余空间（flex: 1）

**例外：** Phase 1 中 container-item 的 10px gap 和 12px padding 保留不变（向后兼容）。

## Typography

|------|------|------|------|------|

| Heading | 18px | 600 | 1.3 | 对话框标题、区域标题 |
| Display | 32px | 600 | 1.2 | 欢迎页面标题 |

**Phase 2 特殊字号：**
- Tab 标题：13px / weight 400 / line-height 1.3（紧凑设计）
- URL 输入框：13px / weight 400（沿用 Phase 1 的 .url-input）
- 新标签页标题：24px / weight 600

## Color

基于 Phase 1 CSS 自定义属性，确认 60/30/10 色彩分配：

| 角色 | 值 | 用途 |
|------|-------|------|
| Dominant (60%) | #1a1a1a (--bg-primary) | 页面背景、webview 区域背景 |
| Secondary (30%) | #2a2a2a (--bg-secondary) | 侧边栏、工具栏、Tab 栏、卡片 |
| Accent (10%) | #3B82F6 (--accent-color) | 仅限下方明确列出的元素 |
| Destructive | #EF4444 (--danger-color) | 仅限破坏性操作（关闭 Tab 确认等） |

**Accent 保留给以下元素（严格限定）：**
- Tab 容器颜色指示线（使用容器自身颜色，非 accent）
- URL 输入框聚焦边框
- 主要按钮背景（.btn-primary）
- 加载进度条颜色
- 新标签页中当前容器高亮

**容器颜色指示线不使用 accent-color。** 每个 Tab 的顶部细线使用该 Tab 所属容器的 `container.color` 值（来自 Phase 1 的颜色选择器：#3B82F6, #10B981, #F59E0B, #EF4444, #8B5CF6, #EC4899, #6366F1, #F97316）。

## 组件清单

Phase 2 新增和修改的 UI 组件：

### 新增组件

#### 1. Tab 栏 (.tab-bar)
**位置：** 主内容区顶部，在工具栏之上
**结构：**
```
.tab-bar
  .tab-list
    .tab (可多个)
      .tab-color-line (3px, 容器颜色)
      .tab-content
        .tab-title (13px, 省略号截断)
      .tab-close (悬停显示, 16px)
  .tab-scroll-left (溢出时显示)
  .tab-scroll-right (溢出时显示)
```

**样式规格：**
- 高度：36px
- 背景色：var(--bg-secondary) (#2a2a2a)
- 底部边框：1px solid var(--border-color)
- 内边距：0 8px
- Tab 间距：2px
- Tab 圆角：8px 8px 0 0（仅顶部圆角）

**Tab 状态：**
- 默认：背景透明，文字 var(--text-secondary)
- 悬停：背景 var(--bg-hover) (#404040)
- 活动：背景 var(--bg-primary) (#1a1a1a)，文字 var(--text-primary)，无底部边框（与工具栏融合）

**溢出处理（D-14）：**
- Tab 最小宽度：120px
- Tab 最大宽度：240px
- 超出时显示左右滚动箭头按钮
- 滚动箭头：24px 宽，背景 var(--bg-secondary)，hover 时 var(--bg-hover)

#### 2. Tab 项 (.tab)
**结构：**
```html
<div class="tab active">
  <div class="tab-color-line" style="background: #3B82F6"></div>
  <div class="tab-content">
    <span class="tab-title">GitHub - Where the world builds...</span>
  </div>
  <button class="tab-close" title="关闭标签页">
    <svg>...</svg>
  </button>
</div>
```

**样式规格：**
- 高度：33px（36px 栏高 - 3px 颜色线）
- 最小宽度：120px
- 最大宽度：240px
- 内边距：0 12px
- 显示：flex, align-items: center, gap: 8px
- 圆角：8px 8px 0 0

**容器颜色线（D-15）：**
- 高度：3px
- 宽度：100%
- 位置：Tab 顶部
- 颜色：容器的 color 属性值
- 活动 Tab：颜色线始终可见
- 非活动 Tab：颜色线始终可见（区分容器）

**关闭按钮（D-16）：**
- 尺寸：16px
- 默认：opacity: 0，不占空间（使用 position: absolute）
- 悬停 Tab：opacity: 1
- 按钮悬停：背景 var(--bg-tertiary)，颜色 var(--text-primary)
- SVG 图标：12px

**标题截断（D-17）：**
- 字号：13px
- 字重：400
- 行高：1.3
- 截断：white-space: nowrap; overflow: hidden; text-overflow: ellipsis
- 悬停提示：title 属性显示完整标题

#### 3. 新标签页 (.new-tab-page)
**位置：** webview 区域内，无 Tab 或新建 Tab 时显示
**结构：**
```
.new-tab-page
  .new-tab-content
    h1 "新标签页"
    .new-tab-search
      input (搜索或输入网址...)
    .new-tab-containers
      h2 "快速访问"
      .container-shortcuts
        .container-shortcut (可多个)
          .shortcut-icon (容器 emoji)
          .shortcut-name (容器名称)
```

**样式规格：**
- 布局：flex, 居中对齐
- 背景色：var(--bg-primary)
- 标题：24px, weight 600, color var(--text-primary)
- 搜索框：max-width 500px, 高度 40px, 圆角 20px, 背景 var(--bg-secondary), 边框 1px solid var(--border-color)
- 搜索框聚焦：border-color var(--accent-color)
- 容器快捷入口：grid 布局, gap 16px, 每项 80px 宽
- 快捷入口图标：40px 圆角方块, 背景 var(--bg-secondary), 悬停 var(--bg-hover)
- 快捷入口名称：12px, color var(--text-secondary), 居中

#### 4. 加载进度条 (.loading-bar)
**位置：** URL 输入框下方或工具栏底部
**样式规格：**
- 高度：2px
- 颜色：var(--accent-color)
- 动画：从 0% 到 90% 缓慢增长，完成时快速到 100% 并消失
- 动画时长：加载中持续增长，完成时 200ms 消失
- 使用 CSS @keyframes 实现

### 修改组件

#### 5. 工具栏 (.toolbar)
**修改内容：**
- 刷新按钮（#reloadBtn）需要支持刷新/停止图标切换
- 加载中：显示停止图标（×）
- 加载完成：显示刷新图标（沿用现有 SVG）
- 切换方式：通过 CSS 类控制（.loading 状态）

#### 6. 浏览器视图区域 (.browser-view)
**修改内容：**
- 需要容纳多个 webview 实例
- webview 使用 show/hide 切换（D-06 决策）
- webview 需要占满整个区域（position: absolute, 100% 宽高）
- webview 需要配置：nodeintegration="false", disablewebsecurity

## 状态设计

### Tab 状态机
```
创建 → 活动 (active)
活动 → 非活动 (inactive)
非活动 → 活动 (active)
活动/非活动 → 关闭 (closed → 销毁)
```

### UI 状态矩阵

| 状态 | Tab 栏 | 工具栏 | webview 区域 |
|------|--------|--------|--------------|
| 无 Tab（欢迎页） | 不显示 | 禁用导航按钮 | 显示欢迎页面 |
| 有 Tab，活动 | 显示所有 Tab，活动 Tab 高亮 | 启用导航按钮 | 显示当前 Tab 的 webview |
| 有 Tab，非活动 | 显示所有 Tab | - | 隐藏非活动 webview |
| 加载中 | 显示所有 Tab | 刷新按钮变停止按钮 | 显示加载进度条 |
| Tab 溢出 | 显示滚动箭头 | - | 正常显示 |

## 交互规格

### Tab 交互

**创建 Tab：**
- 触发：点击容器快捷入口、在新标签页输入 URL、从容器面板切换容器
- 动画：无（直接插入 DOM）
- 位置：Tab 列表末尾
- 自动切换到新创建的 Tab

**切换 Tab：**
- 触发：点击 Tab
- 动画：无（直接显示/隐藏 webview）
- 工具栏更新：URL 输入框显示当前 Tab 的 URL，容器指示器更新

**关闭 Tab（D-08）：**
- 触发：点击关闭按钮
- 动画：无（直接移除 DOM）
- 行为：销毁 webview，释放内存
- 关闭活动 Tab：自动切换到相邻 Tab（右侧优先，无右侧则左侧）
- 关闭最后一个 Tab：显示欢迎页面

**Tab 溢出（D-14）：**
- 当 Tab 总宽度超过栏宽度时
- 显示左右滚动箭头
- 点击箭头滚动 Tab 列表
- 滚动距离：100px

**Tab 回收（D-07）：**
- 超过上限时（默认 20 个 Tab）
- 自动关闭最久未使用的非活动 Tab
- 显示 Toast 提示："已自动关闭最久未使用的标签页以释放资源"

### URL 导航交互

**输入 URL（D-10, D-11）：**
- 触发：在 URL 输入框输入后按 Enter 键
- 自动补全：如果缺少协议，自动添加 https://
- 无效 URL：显示错误页面（"无法访问该网址"）
- 导航后：URL 输入框显示当前页面 URL

**前进/后退（BROW-02）：**
- 后退按钮：webview.goBack()
- 前进按钮：webview.goForward()
- 按钮状态：不可用时 disabled（无历史记录时）

**刷新/停止（D-13）：**
- 刷新：webview.reload()
- 停止：webview.stop()
- 图标切换：加载中显示停止图标，加载完成显示刷新图标

**加载动画（D-13）：**
- 位置：URL 输入框下方
- 样式：2px 高度的进度条，颜色 var(--accent-color)
- 动画：从左到右增长，完成时消失

## 安全规格

### webview 安全配置（D-03）
```html
<webview
  src="about:blank"
  partition="persist:container-{containerId}"
  nodeintegration="false"
  disablewebsecurity="false"
  allowpopups="false"
  webpreferences="contextIsolation=yes"
></webview>
```

### XSS 防护
- Tab 标题：使用 textContent 设置，不使用 innerHTML
- URL 输入：验证和清理后传递给 webview
- 新标签页：使用 DOM API 动态生成，不使用 innerHTML
