  <name>Task 1 (Gap 2 / Test 8b): .toolbar 添加 position: relative 修复进度条定位</name>
  <files>src/styles/main.css</files>
  <action>
    在 src/styles/main.css 行 183-192 的 .toolbar 规则内添加一行声明：position: relative。

    原因（来自 debug session progress-bar-wrong-position）：.loading-bar（main.css:1003-1012）为 position: absolute; bottom: 0; left: 0; width: 100%，但 .toolbar、.main-content（175-180）、body（48-55）均为默认 position: static，没有任何祖先建立包含块，绝对定位回退到 viewport，导致进度条钉在整个窗口左下角（即左侧边栏下方）。.toolbar 变为定位祖先后，进度条即锚定到工具栏底部边缘（URL 输入框正下方）。

    注意：
    - 只动 .toolbar 这一条规则，不要改 .loading-bar 本身、不要加 top/bottom 偏移——bottom: 0 在工具栏定位后即为正确位置。
    - 无 JS/HTML 变更。
    - .toolbar 上有 -webkit-app-region: drag（行 191），position: relative 不影响拖拽区域行为。
  </action>
  <verify>
    <automated>awk '/^\.toolbar \{/,/^\}/' src/styles/main.css | grep -q 'position: relative' && echo PASS</automated>
  </verify>
  <done>
    .toolbar 规则包含 position: relative；加载页面时 2px 蓝色进度条沿工具栏底部边缘（URL 输入框正下方）显示并在加载完成后自动消失——满足 UAT Test 8b 预期（"URL 输入框下方出现 2px 蓝色加载进度条，加载完成后自动消失"），不再出现在侧边栏下方。
