## Phase Goal

**As a** 用户, **I want to** 在同一窗口内通过多 Tab 管理不同容器的浏览会话, **so that** 我可以在不同容器间快速切换，同时保持各容器的独立性。

<task type="auto">
  <name>Task 2: Tab 管理 UI 逻辑（渲染进程本地状态）</name>
  <files>src/renderer.js</files>
  <action>
在 src/renderer.js 中实现纯渲染进程的 Tab 管理逻辑。所有 Tab 状态存储在渲染进程本地（后续 Plan 03 会集成主进程持久化）。

1. **Tab 数据结构**（在 state 对象中添加）：
   - state.tabs: Map<tabId, { id, containerId, title, url, element }>
   - state.activeTabId: string | null
   - state.tabCounter: number（用于生成 tabId）

2. **常量**：
   - TAB_MAX_COUNT: 20（D-07: Tab 上限）
   - TAB_RECYCLE_MESSAGE: '已自动关闭最久未使用的标签页以释放资源'

3. **核心函数**（在 renderer.js 中添加）：

   **createTab(containerId, url = null):**
   - 生成 tabId: `tab-${++state.tabCounter}`
   - 如果 tabs.size >= TAB_MAX_COUNT，调用 recycleOldestTab()
   - 创建 Tab DOM 元素：
     - .tab 容器
     - .tab-color-line（颜色从 getContainerColor(containerId) 获取）
     - .tab-content > .tab-title（textContent = '新标签页'）
     - .tab-close 按钮（SVG × 图标）
   - 添加到 .tab-list 末尾
   - 设置 state.tabs.set(tabId, tabData)
   - 调用 switchTab(tabId)
   - 返回 tabId

   **switchTab(tabId):**
   - 如果 tabId === state.activeTabId，return
   - 更新所有 Tab 的 .active 类（移除旧的，添加新的）
   - 更新 state.activeTabId
   - 更新 URL 输入框显示（state.tabs.get(tabId).url || '')
   - 更新容器指示器（当前 Tab 对应的容器）
   - 如果有 webview 容器（.browser-view），切换 webview 可见性（后续 Plan 02 添加）
   - 如果 url 为空，显示新标签页；否则隐藏新标签页
   - 更新导航按钮状态（后续 Plan 02 添加）

   **closeTab(tabId):**
   - 如果 tabs.size === 1，关闭后显示新标签页，清空 URL 栏
   - 获取 Tab 索引，确定切换目标：右侧 Tab > 左侧 Tab
   - 从 DOM 移除 Tab 元素
   - 从 state.tabs 删除
   - 如果关闭的是活动 Tab，调用 switchTab(相邻tabId)
   - 如果没有 Tab 了，显示新标签页

   **recycleOldestTab():**
   - 找到 lastActiveAt 最小的非活动 Tab
   - 如果没有非活动 Tab，return（不回收）
   - 调用 closeTab(oldestTabId)
   - 显示 Toast 提示（使用简单的 DOM 提示，3 秒后自动消失）

   **getContainerColor(containerId):**
   - 从 window.realmAPI.getContainers() 获取容器列表
   - 找到对应容器，返回 container.color
   - 默认返回 '#6B7280'（灰色）

   **updateTabTitle(tabId, title):**
   - 更新 state.tabs.get(tabId).title = title
   - 更新 Tab DOM 的 .tab-title textContent
   - 设置 title 属性（悬停显示完整标题，D-17）

   **renderContainerShortcuts():**
   - 获取所有容器，为每个容器生成快捷入口
   - 点击快捷入口：调用 createTab(containerId)
   - 使用 textContent 设置容器名称（XSS 防护）

4. **事件绑定**（在 setupEventListeners 中添加）：
   - .tab-list 的 click 事件委托：
     - 点击 .tab-close：调用 closeTab(tabId)
     - 点击 .tab：调用 switchTab(tabId)
   - .tab-new-btn 的 click：调用 createTab(当前容器ID)
   - .new-tab-search 的 keydown Enter：调用 createTab(当前容器ID, 输入的URL)
   - 容器面板选择容器后：创建新 Tab（修改现有 container:switch 逻辑）

5. **容器面板集成**：
   - 修改现有的容器切换逻辑（renderer.js 中的 container:switch 处理）
   - 切换容器时，调用 createTab(selectedContainerId)
   - 更新 state.currentContainer

6. **初始化**：
   - 页面加载完成后调用 renderContainerShortcuts()
   - 默认不创建 Tab，显示新标签页
