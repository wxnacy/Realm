<task type="auto">
  <name>Task 1: 主进程 Tab 管理模块 tab-manager.js</name>
  <files>tab-manager.js</files>
  <action>
创建主进程 Tab 管理模块，与 Phase 1 的 container-manager.js 架构一致（模块导出函数，不互相 require）。

1. **Tab 数据模型**（D-05: 轻量级）：
   ```
   {
     id: string,          // tab-1, tab-2, ...
     containerId: string, // 容器 ID
     url: string,         // 当前 URL
     title: string,       // 页面标题
     createdAt: number,   // 创建时间戳
     lastActiveAt: number // 最后活跃时间戳
   }
   ```

2. **模块结构**（仿照 container-manager.js）：
   ```
   const { app } = require('electron');
   const Store = require('electron-store');

   const store = new Store({ name: 'tabs' });
   const tabs = new Map();
   let activeTabId = null;
   let tabCounter = 0;

   const TAB_MAX_COUNT = 20; // D-07
   ```

3. **导出函数**：

   **initTabs():**
   - 从 electron-store 读取上次保存的 Tab 列表
   - 恢复 tabs Map
   - 恢复 tabCounter
   - 如果没有保存的 Tab，tabs 为空
   - 日志：`[Realm] Tab 管理器初始化，恢复 ${tabs.size} 个 Tab`

   **getTabs():**
   - 返回 Array.from(tabs.values())

   **getTab(tabId):**
   - 返回 tabs.get(tabId) || null

   **getActiveTab():**
   - 返回 activeTabId ? tabs.get(activeTabId) : null

   **createTab(containerId, url = ''):**
   - 生成 tabId: `tab-${++tabCounter}`
   - 如果 tabs.size >= TAB_MAX_COUNT，调用 recycleOldestTab()
   - 创建 tab 对象：{ id, containerId, url, title: '新标签页', createdAt: Date.now(), lastActiveAt: Date.now() }
   - tabs.set(tabId, tab)
   - activeTabId = tabId
   - saveTabs()
   - 返回 tab

   **switchTab(tabId):**
   - 如果 !tabs.has(tabId)，返回 false
   - 更新 activeTabId = tabId
   - 更新 tab.lastActiveAt = Date.now()
   - saveTabs()
   - 返回 true

   **updateTab(tabId, updates):**
   - 获取 tab = tabs.get(tabId)
   - 如果不存在，返回 false
   - 合并 updates（url, title, lastActiveAt）
   - saveTabs()
   - 返回 true

   **closeTab(tabId):**
   - 如果 !tabs.has(tabId)，返回 false
   - tabs.delete(tabId)
   - 如果关闭的是活动 Tab：
     - 获取 tab 数组，找到被关闭 Tab 的索引
     - 切换到右侧 Tab，无右侧则左侧，无 Tab 则 null
     - activeTabId = 相邻tabId || null
   - saveTabs()
   - 返回 { closedTabId: tabId, newActiveTabId: activeTabId }

   **recycleOldestTab():**
   - 从 tabs 中找到 lastActiveAt 最小的非活动 Tab
   - 如果没有非活动 Tab，return null（不回收）
   - 调用 closeTab(oldestTabId)
   - 返回 { recycledTabId: oldestTabId, message: '已自动关闭最久未使用的标签页以释放资源' }

   **saveTabs():**
   - 将 tabs Map 转为数组，存入 electron-store
   - 同时保存 tabCounter 和 activeTabId

   **日志规范**：
   - 所有日志使用 `[Realm]` 前缀
   - createTab: `[Realm] Tab 创建: ${tabId} (容器: ${containerId})`
   - closeTab: `[Realm] Tab 关闭: ${tabId}`
   - recycleOldestTab: `[Realm] Tab 回收: ${tabId} (最久未使用)`

4. **XSS 防护**：
   - Tab 数据模型中不存储 HTML 内容
   - 所有文本字段使用字符串类型

<task type="auto">
  <name>Task 2: IPC 处理器 + Preload API + 渲染进程集成</name>
  <files>ipc-handlers.js, src/preload.js, src/renderer.js</files>
  <action>
将 Tab 管理通过 IPC 暴露给渲染进程，修改渲染进程使用主进程 Tab API。

1. **ipc-handlers.js 新增 Tab 处理器**（仿照 container: 格式）：

   在 registerHandlers 函数中添加：
   ```
   // Tab 管理
   ipcMain.handle('tab:list', async () => { return tabManager.getTabs(); });
   ipcMain.handle('tab:create', async (e, containerId, url) => { return tabManager.createTab(containerId, url); });
   ipcMain.handle('tab:switch', async (e, tabId) => { return tabManager.switchTab(tabId); });
   ipcMain.handle('tab:update', async (e, tabId, updates) => { return tabManager.updateTab(tabId, updates); });
   ipcMain.handle('tab:close', async (e, tabId) => { return tabManager.closeTab(tabId); });
   ipcMain.handle('tab:get-active', async () => { return tabManager.getActiveTab(); });
   ```

   顶部引入 tab-manager：
   ```
   const tabManager = require('./tab-manager');
   ```

2. **src/preload.js 新增 Tab API**：

   在 contextBridge.exposeInMainWorld('realmAPI', {...}) 中添加：
   ```
   // Tab 管理
   getTabs: () => ipcRenderer.invoke('tab:list'),
   createTab: (containerId, url) => ipcRenderer.invoke('tab:create', containerId, url),
   switchTab: (tabId) => ipcRenderer.invoke('tab:switch', tabId),
   updateTab: (tabId, updates) => ipcRenderer.invoke('tab:update', tabId, updates),
   closeTab: (tabId) => ipcRenderer.invoke('tab:close', tabId),
   getActiveTab: () => ipcRenderer.invoke('tab:get-active'),
   ```

3. **src/renderer.js 修改**（集成主进程 Tab API）：

   **修改 createTab 函数**：
   - 移除本地 tabCounter 和 state.tabs 逻辑
   - 改为调用 `const tab = await window.realmAPI.createTab(containerId, url)`
   - 使用返回的 tab.id 作为 tabId
   - 保留 DOM 创建逻辑（Tab UI 由渲染进程管理）
   - 将 tab 数据存储在 state.tabs 中（渲染进程缓存）

   **修改 switchTab 函数**：
   - 调用 `await window.realmAPI.switchTab(tabId)`
   - 保留 UI 更新逻辑

   **修改 closeTab 函数**：
   - 调用 `const result = await window.realmAPI.closeTab(tabId)`
   - 使用 result.newActiveTabId 确定切换目标
   - 调用 destroyWebview(tabId)
   - 保留 DOM 清理逻辑

   **修改 updateTabTitle 函数**：
   - 调用 `await window.realmAPI.updateTab(tabId, { title })`

   **初始化逻辑**：
   - 页面加载完成后调用 `const tabs = await window.realmAPI.getTabs()`
   - 如果有保存的 Tab，为每个 Tab 创建 DOM 元素和 webview
   - 调用 `const activeTab = await window.realmAPI.getActiveTab()`
   - 如果有活动 Tab，switchTab(activeTab.id)
   - 如果没有保存的 Tab，显示新标签页

   **容器切换集成**：
   - 容器面板切换容器时，调用 createTab(selectedContainerId)

4. **main.js 修改**：
   - 在 app.whenReady() 中调用 `tabManager.initTabs()`
   - 确保 Tab 管理器在应用启动时初始化

5. **日志规范**：
   - IPC 处理器日志使用 `[Realm]` 前缀
   - 错误使用 console.error
