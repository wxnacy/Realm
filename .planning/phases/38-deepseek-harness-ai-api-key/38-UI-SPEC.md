## Interaction Specifications

### 供应商 CRUD 流程

1. **添加内置供应商**：点击"添加内置供应商" → 弹窗展示 38 个内置提供商 → 搜索过滤 → 选择 → 添加到左侧列表 → 右侧自动切换到新供应商编辑表单 → 填写 API Key → 保存

2. **添加自定义供应商**：点击"添加自定义供应商" → 左侧列表新增"未命名供应商"项 → 右侧展开编辑表单（提供商名称可编辑、baseURL 输入、协议选择、API Key） → 填写 → 保存

3. **编辑供应商**：点击左侧列表项 → 右侧加载该供应商配置 → 修改 → 保存

4. **删除供应商**：点击"删除供应商" → 确认弹窗 → 确认后硬删除（清除所有配置）→ 左侧列表移除该项 → 右侧清空或切换到列表第一项

### 模型检测流程

1. 用户填写 API Key → 点击"检测模型"
2. 按钮变为"检测中..." + disabled
3. 成功：模型列表区域渲染检测到的模型标签
4. 失败：模型列表区域显示错误信息 + 重试按钮

### 环境变量检测流程

1. 打开供应商编辑表单时，自动检测约定环境变量名
2. 检测到：API Key 输入框下方显示绿色提示"检测到环境变量 XXX，已自动使用"，输入框显示掩码值
3. 未检测到：无提示，用户手动输入
4. 用户可修改环境变量名字段，修改后重新检测

### 模型选择器交互

1. 点击模型按钮 → 展开下拉框
2. 点击模型项 → 选中 → 更新按钮文字 → 关闭下拉框 → 激活对应供应商
3. 点击外部 → 关闭下拉框
4. 键盘：ArrowUp/Down 导航，Enter 选择，Esc 关闭

### 新对话按钮

1. 点击"新对话" → 清空聊天消息列表 → 重置对话状态
2. 无二次确认（deferred idea from CONTEXT.md，采用直接清空）
