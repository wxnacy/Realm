    - getCredentialById(credentialId) 返回解密后的 username + password（展开详情用）

    - GET /api/credentials/search?containerId=xxx&keyword=xxx 返回搜索结果
    - POST /api/credentials/delete 接收 {containerId, origin} 删除单条
    - POST /api/credentials/batch-delete 接收 {containerId, origins} 批量删除

       - listCredentials(containerId): SELECT id, container_id, url, origin, username, created_at, updated_at FROM credentials WHERE container_id = ? AND never_save = 0 ORDER BY updated_at DESC
       - searchCredentials(containerId, keyword): 同上但加 WHERE (origin LIKE '%keyword%' OR username LIKE '%keyword%')
       - batchDelete(containerId, origins): DELETE FROM credentials WHERE container_id = ? AND origin IN (?,?,...), 返回 {success, deleted}
       - getCredentialById(credentialId): SELECT id, username, encrypted_password FROM credentials WHERE id = ?, 解密后返回 {username, password}，支持密钥轮转懒更新（参考现有 getCredential 函数的 shouldReEncrypt 逻辑）

       - 函数位于 handleDownloadsApi 附近（约 main.js:1340 之后）
       - token 鉴权：reqUrl.searchParams.get('token') !== REALM_TOKEN 时返回 403
       - 路由：list(GET), search(GET), delete(POST), batch-delete(POST), get-by-id(POST)
       - 每个路由调用 credential-manager.js 对应函数
    3. 在 realmServer 路由分发中注册（约 main.js:1550 附近，downloads 之后）：
       - if (reqPath.startsWith('/api/credentials/')) { handleCredentialsApi(req, res, reqUrl); return; }

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-33-01 | Tampering | /api/credentials/* HTTP API | high | mitigate | REALM_TOKEN 鉴权（随机 UUID），所有 HTTP 端点校验 token |
| T-33-02 | Information Disclosure | 凭据密码明文传输 | medium | mitigate | 密码默认遮罩显示，仅展开详情时解密传输，列表不返回密码 |
| T-33-03 | Tampering | 凭据表格 innerHTML XSS | high | mitigate | DOM 构建 + textContent 渲染（WR-13 模式） |
