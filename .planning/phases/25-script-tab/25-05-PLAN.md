1. **src/preload.js**：在现有 realmAPI 对象中添加：
   - `tabReorder: (tabOrder) => ipcRenderer.invoke('tab:reorder', tabOrder)`

2. **main.js**：在现有 IPC 处理器区域添加：

   `ipcMain.handle('tab:reorder', (event, tabOrder) => { ... })`

   tabOrder 格式：`{ groups: [{ name: string, tabIds: string[] }] }`

   重排逻辑：
   - a. 校验 tabOrder 格式
   - b. 获取所有标签页数据（tabManager.getTabs()）
   - c. 验证所有 tabId 是否存在
   - d. 构建新的标签页顺序：按 groups 数组顺序排列 tabIds，未分组的标签追加到末尾
   - e. 通知渲染进程按新顺序重排标签栏 DOM

   **标签栏 DOM 重排**：由于标签栏由渲染进程管理（src/renderer.js 中的 renderTabBar），主进程需要通过 IPC 通知渲染进程执行 DOM 重排。方案：
   - 方案 A：主进程通过 `event.sender.send('tab:reordered', newOrder)` 推送新顺序，渲染进程收到后重排 DOM
   - 方案 B：tab:reorder 直接返回新顺序，渲染进程在调用后自行重排

   采用方案 A：
   - main.js 的 tab:reorder 处理器计算新顺序后，通过 `event.sender.send('tab:reordered', { groups, flatOrder })` 推送到渲染进程
   - 返回 `{ success: true, groupCount: groups.length, tabCount: totalTabs }`

3. **src/renderer.js**：添加标签栏重排逻辑：

   - 注册 `window.realmAPI.onTabReordered` 监听（在 preload 中添加对应的 on 方法）
   - 或者在 tab:reorder 的 invoke 返回后直接执行重排

   重排逻辑：
   - 获取标签栏容器 DOM（.tabs-container 或类似选择器）
   - 按 flatOrder 顺序重新排列标签页 DOM 元素
   - 在分组之间插入 .tab-group-divider-line 分隔线（`height: 1px`, `background: var(--border-color)`, `margin: 4px 8px`）

   preload.js 中额外添加：
   - `onTabReordered: (callback) => ipcRenderer.on('tab:reordered', (event, data) => callback(data))`
  </action>
