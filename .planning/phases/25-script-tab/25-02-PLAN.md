  <action>
在 src/renderer.js 中新增以下函数（放在 renderConfirmationCard 函数之后）：

1. **getActionLabel(action)**：操作类型到中文标签的映射函数。映射表：navigate→'导航', click→'点击', type→'输入', scroll→'滚动', wait→'等待', select→'选择', check→'勾选', uncheck→'取消勾选', focus→'聚焦', blur→'失焦', submit→'提交', keydown→'按下按键', keyup→'松开按键'。未知操作返回 action 原值。

2. **renderScriptPreviewCard(script)**：脚本预览卡片主渲染函数。参数 script 为 `{ name, description, steps, containerId }` 对象。
   - 克隆 script-preview-template 模板
   - 填充 script-card-name 和 script-card-desc
   - 遍历 script.steps 渲染步骤列表（调用 renderScriptStepItem）
   - 绑定"执行脚本"按钮：收集当前步骤数据，通过 `window.realmAPI.sendToAI({ type: 'script:execute', script })` 发送到主进程
   - 绑定"取消"按钮：移除卡片
   - 绑定"+ 添加步骤"按钮：在步骤列表末尾追加空白步骤（action: 'click', target: ''），自动展开编辑模式
   - 返回组装好的卡片 DOM 元素

3. **renderScriptStepItem(step, index)**：单个步骤项渲染。
   - 创建 .script-step-item 容器，设置 draggable="true"
   - 拖拽手柄 .step-drag-handle（6点 SVG 图标）
   - 序号 .step-number（显示 index+1）
   - 步骤内容区：.step-action-label（操作类型标签，使用 getActionLabel）、.step-target（目标描述）、.step-params（参数值，折叠状态）
   - 操作按钮组 .step-actions：编辑按钮（点击展开编辑器）、删除按钮（点击移除步骤并重新编号）
   - 拖拽事件：dragstart 设置 dataTransfer 和 dragging 类，dragover 阻止默认并添加 drag-over 类指示插入位置，dragend 清除状态

4. **renderStepEditor(step, index, onSave)**：步骤内联编辑器。
   - 创建 .step-editor 容器
   - 操作类型选择器：下拉框列出所有支持的操作类型（navigate/click/type/scroll/wait/select/check/uncheck/focus/blur/submit/keydown/keyup）
   - 目标输入框：.step-target-input，值为 step.target
   - 参数输入框（条件显示）：当 action 为 type/select/keydown 时显示，输入 step.options 中的值
   - 保存按钮：收集编辑器数据，调用 onSave(updatedStep) 回调
   - 取消按钮：关闭编辑器

5. **拖拽排序逻辑**：
   - 使用现有拖拽模式（参考项目中的拖拽实现）
   - dragstart：记录拖拽起始索引
   - dragover：计算插入位置（鼠标在目标元素上半部=前插，下半部=后插），显示插入指示线
   - drop：重新排列 steps 数组，重新渲染步骤列表并更新序号
   - dragend：清除所有拖拽状态

6. **步骤重新编号**：步骤增删拖拽后，更新所有 .step-number 的文本为当前索引+1。

注意：脚本预览卡片在 AI 聊天消息中的挂载点，需要在处理 AI 工具返回的 generate_script 结果时调用 renderScriptPreviewCard 并将返回的 DOM 元素追加到对应的 .ai-message-ai 容器中。此挂载逻辑在处理 AI 响应的流程中添加（检测 toolName === 'generate_script' 时调用渲染函数）。
