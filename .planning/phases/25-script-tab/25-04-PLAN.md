  <action>
在 ai-manager.js 的 `_buildRealmTools()` 方法中，紧接在 `generate_script` 工具定义之后添加 `suggest_tab_groups` 工具。

1. **工具定义**：
   - name: 'suggest_tab_groups'
   - label: '标签分组建议'
   - description: '分析当前标签页并生成智能分组建议，按主题或域名对标签页进行分组'
   - parameters:
     - strategy (string, optional, enum: ['domain', 'semantic', 'mixed']): 分组策略，默认 'semantic'
     - containerId (string, optional): 仅分析指定容器的标签页，默认分析所有容器

2. **execute 函数**：`async (toolCallId, params) => { ... }`
   - 获取当前所有标签页：`const tabs = tabManager.getTabs();`
   - 如果 tabs 为空，返回 `{ content: [{ type: 'text', text: JSON.stringify({ groups: [], message: '当前没有打开的标签页' }) }] }`
   - 按 containerId 过滤（如果指定）
   - 根据 strategy 参数分组：
     - 'domain'：按 URL 域名分组，相同域名的标签页归为一组。组名为域名（如 "github.com"）
     - 'semantic'：AI 根据页面标题和 URL 进行语义分析，按主题分组（如"新闻"、"社交媒体"、"工作"、"开发工具"）
     - 'mixed'：先按域名分组，再对域名数量 >= 3 的组进行语义细分

   注意：suggest_tab_groups 工具的 execute 函数负责构造分组数据。对于 'semantic' 模式，AI 模型会基于 tabs 的 title 和 url 进行分组判断。execute 函数应将 tabs 数据作为结构化信息返回，供 AI 参考分组。

   **实现方式**：execute 函数将标签页数据格式化后返回给 AI，AI 自行分组后将结果结构化返回。execute 函数可以：
   - 返回标签页列表（带 title、url、containerId），AI 根据语义分组
   - 或者 execute 函数内部实现简单分组逻辑（domain 模式），semantic 模式交给 AI

   推荐方案：execute 函数实现 domain 分组的基础逻辑，semantic 分组由 AI 自行判断。execute 函数返回标签页数据 + 基础 domain 分组结果，AI 可以在此基础上调整。

3. **返回格式**：
   ```json
   {
     "content": [{ "type": "text", "text": "<分组建议 JSON>" }],
     "details": { "totalTabs": N, "groupCount": M, "strategy": "semantic" }
   }
   ```

   分组建议 JSON 结构：
   ```json
   {
     "groups": [
       {
         "name": "工作相关",
         "tabs": [
           { "id": "tab-1", "title": "GitHub", "url": "https://github.com", "containerId": "work", "faviconUrl": "..." }
         ]
       }
     ],
     "ungrouped": []
   }
   ```

4. **在系统提示词中添加说明**：在 REALM_SYSTEM_PROMPT 的"你的能力"部分添加：
   `- suggest_tab_groups: 分析当前标签页并生成智能分组建议。支持按域名、语义或混合策略分组。当用户说"整理标签页"、"帮我分组标签页"、"归类标签页"时使用此工具。`
