<task type="auto">
  <name>Task 1: Tab 拖拽排序基础实现</name>
  <files>src/renderer.js, src/styles/main.css</files>
  <action>
实现窗口内 Tab 拖拽排序功能（per MW-04, D-25, D-29）：

1. 在 src/renderer.js 的 Tab 渲染函数中，为每个 Tab 元素添加 HTML5 DnD 事件（per D-25）：
   - dragstart: 设置 e.dataTransfer.effectAllowed = 'move'，使用 e.dataTransfer.setData('text/plain', tabId) 存储 tabId
   - dragover: 计算插入位置（使用 e.clientY 和 Tab 元素的 getBoundingClientRect()），调用 e.preventDefault() 允许 drop
   - drop: 获取拖拽的 tabId，执行排序，更新 Tab 顺序
   - dragend: 清理状态，移除所有 drag-over 样式

2. 插入位置指示器（per D-29）：
   - 创建独立的 DOM 元素作为指示器（class: 'tab-drag-indicator'）
   - 垂直线显示在两个 Tab 之间（Chrome 风格）
   - 指示器宽度 2px，高度与 Tab 栏相同，使用容器主题色
   - 指示器位置跟随鼠标在 Tab 栏内的位置

3. Tab 顺序更新逻辑：
   - 获取拖拽的 tabId 和目标位置
   - 更新本地 state.tabs 数组顺序
   - 调用 window.realmAPI.reorderTabs(orderedIds) 同步到主进程

4. 添加 IPC 通道 'tab:reorder'（如果不存在）：
   - 主进程：接收新顺序，更新 tabManager 中的 Tab 顺序
   - 广播 'tab:reordered' 事件到所有窗口（如果需要多窗口同步）

5. CSS 样式（src/styles/main.css）：
   - .tab-drag-indicator: position absolute, width 2px, background var(--accent-color), pointer-events none, z-index 100, transition left 0.1s ease
   - .tab.dragging: opacity 0.5
   - .tab.drag-over: background rgba(255, 255, 255, 0.1)
  </action>

<task type="auto">
  <name>Task 2: Tab 拖拽排序优化</name>
  <files>src/renderer.js</files>
  <action>
优化 Tab 拖拽排序的体验和性能：

1. 拖拽预览优化（src/renderer.js setupTabDragEvents 函数）：
   - 在 dragstart handler 中，使用 e.dataTransfer.setDragImage(tabElement, offsetX, offsetY) 设置自定义拖拽预览
   - 创建离屏 canvas 或 cloneNode 副本作为预览，显示 favicon + 标题

2. 边界处理（src/renderer.js dragover handler）：
   - dragover 时检查 e.target 是否在 .tab-bar 内（document.querySelector('.tab-bar').contains(e.target)）
   - 如果不在 Tab 栏内，调用 hideInsertIndicator() 并 return
   - 如果拖拽目标是自身（draggingTab === tabElement），调用 hideInsertIndicator() 并 return
   - 在 dragstart handler 中注册 keydown 监听器，Escape 键触发 dragend 事件取消拖拽

3. 性能优化（src/renderer.js showInsertIndicator 函数）：
   - showInsertIndicator 内部用 requestAnimationFrame 包裹 DOM 更新，避免同一帧多次重排
   - 指示器位置更新时直接修改 style.left，不重新创建 DOM 元素
   - dragover handler 中使用节流（throttle 16ms），限制每秒最多更新 60 次

4. 无障碍支持（src/renderer.js Tab 渲染函数）：
   - Tab 元素保持 role="tab" 和 aria-selected 属性不变
   - dragstart 时设置 tabElement.setAttribute('aria-grabbed', 'true')
   - dragend 时设置 tabElement.setAttribute('aria-grabbed', 'false')
   - Tab 栏容器设置 aria-dropeffect="move"

5. 状态管理（src/renderer.js）：
   - dragstart 时设置 state.isDragging = true
   - dragend 时设置 state.isDragging = false
   - state.isDragging 为 true 时，contextmenu handler 中调用 e.preventDefault() 禁用右键菜单
