<task type="auto">
  <name>Task 1: 窗口位置持久化</name>
  <files>window-manager.js, main.js</files>
  <action>
实现窗口位置和大小的持久化恢复（per MW-11, D-32, D-33, D-34）：

1. 在 window-manager.js 中创建 windowBoundsStore（electron-store 实例，name: 'window-bounds'）

2. 实现 saveWindowBounds(windowId, containerId) 函数：
   - 获取 BrowserWindow 的 getBounds() 和 isMaximized()
   - 获取所在显示器信息：screen.getDisplayMatching(bounds)
   - 保存到 store，key 格式：`container-${containerId}`
   - 保存属性（per D-32）：{ x, y, width, height, isMaximized, displayId }

3. 实现 restoreWindowBounds(containerId) 函数：
   - 从 store 读取 `container-${containerId}` 的记录
   - 越界检测（per D-34）：使用 screen.getDisplayMatching(bounds) 检查是否在任何显示器范围内
   - 越界时居中到主显示器：screen.getPrimaryDisplay()
   - 返回 { bounds, isMaximized } 或 null（无记录）

4. 修改 createMainWindow() 函数：
   - 调用 restoreWindowBounds(containerId) 获取恢复的位置
   - 如果有恢复数据，使用 win.setBounds() 和 win.maximize() 恢复
   - 如果无恢复数据，使用默认位置

5. 在 main.js 中添加窗口事件监听：
   - BrowserWindow.on('moved') → saveWindowBounds(windowId, containerId)
   - BrowserWindow.on('resized') → saveWindowBounds(windowId, containerId)
   - app.on('before-quit') → 保存所有窗口状态

6. 导出新函数供 main.js 调用
  </action>
  <verify>
    <automated>启动应用，移动窗口到非默认位置，关闭并重启，验证位置恢复</automated>
  </verify>
  <done>窗口位置和大小在重启后正确恢复；越界窗口自动居中到主显示器；多窗口位置独立保存和恢复</done>
</task>

<task type="auto">
  <name>Task 2: 右键菜单"在新窗口中打开"</name>
  <files>context-menu-manager.js, src/preload.js, main.js, src/renderer.js</files>
  <action>
实现右键菜单"在新窗口中打开"选项（per MW-13）：

1. 在 context-menu-manager.js 的 Tab 右键菜单中添加"在新窗口中打开"菜单项：
   - 菜单标签：'在新窗口中打开'
   - 点击时发送 IPC 事件：'tab:open-in-new-window'
   - 传递 tabInfo 数据

2. 在 main.js 中添加 IPC 通道 'tab:open-in-new-window'：
   - 接收 tabId 参数
   - 调用 tabManager.getTab(tabId) 获取 Tab 信息
   - 调用 windowManager.createMainWindow(containerId) 创建新窗口
   - 调用 tabManager.createTab(containerId, url, newWindowId) 在新窗口创建 Tab
   - 通知源窗口移除 Tab UI（可选，取决于是否"移动"还是"复制"）

3. 在 src/preload.js 中暴露 openTabInNewWindow API：
   - openTabInNewWindow: (tabId) => ipcRenderer.invoke('tab:open-in-new-window', tabId)

4. 在 src/renderer.js 中处理菜单回调：
   - 监听 'context-menu:open-in-new-window' 事件
   - 调用 window.realmAPI.openTabInNewWindow(tabId)
  </action>
