## main.js — devrequests API 端点

在 main.js 的 HTTP 服务器中添加 `/api/devrequests/*` 路由处理。

**路由注册（在 realmServer 的 createServer 回调中）：**
```javascript
// 开发者模式请求数据 API
if (reqPath.startsWith('/api/devrequests/')) {
  handleDevRequestsApi(req, res, reqUrl);
  return;
}
```

**`handleDevRequestsApi` 函数实现：**

1. `GET /api/devrequests/list` — 分页查询请求记录
   - 查询参数：`containerId`（必需）、`offset`（默认 0）、`limit`（默认 50）、`method`（可选过滤）、`domain`（可选过滤）、`search`（可选 URL 搜索）
   - 返回：`{ records: [...], total: number, offset: number, limit: number }`
   - SQL 查询支持：`WHERE url LIKE '%keyword%'`、`WHERE method = 'GET'`、`ORDER BY created_at DESC`

2. `GET /api/devrequests/domains` — 获取已抓取的域名列表（去重）
   - 查询参数：`containerId`（必需）
   - 返回：`string[]` 域名数组
   - SQL：`SELECT DISTINCT ... FROM dev_requests_${containerId}`，使用 `new URL(url).hostname` 提取域名

3. `GET /api/devrequests/stats` — 获取统计信息
   - 查询参数：`containerId`（必需）
   - 返回：`{ total: number, todayCount: number, methods: { GET: n, POST: n, ... } }`

4. `POST /api/devrequests/delete` — 删除单条记录
   - 请求体：`{ containerId: string, id: number }`
   - 返回：`{ success: boolean }`

5. `POST /api/devrequests/clear` — 清空容器的所有记录
   - 请求体：`{ containerId: string }`
   - 返回：`{ success: boolean, deletedCount: number }`

**安全验证：**
- 所有 API 必须验证 `token` 查询参数（复用现有 `REALM_TOKEN` 验证模式）
- `containerId` 必须通过 `sanitizeContainerId` 白名单验证（`[a-z0-9-]`）
- 表名使用模板字符串但仅由 `sanitizeContainerId` 输出拼接，防 SQL 注入

**数据访问：**
- 复用 history-manager 的数据库连接（`db` 实例通过模块导出或直接引用）
- 或在 dev-requests-writer.js 中导出查询函数
- 容器表名：`dev_requests_${sanitizedContainerId}`

## devrequests-page.js — 请求查看页面逻辑

新建 `src/devrequests-page.js`，基于 `history-page.js` 的模式。

**状态管理：**
```javascript
const state = {
  containerId: pageParams.get('container') || 'default',
  records: [],
  total: 0,
  offset: 0,
  limit: 50,
  loading: false,
  keyword: '',
  methodFilter: '',
  domainFilter: '',
  expandedId: null,        // 当前展开的记录 ID
  activeTab: 'request-headers',  // 当前展开详情的 tab
  autoRefreshTimer: null,  // 自动刷新定时器
};
```

**核心函数：**

1. `loadRequests()` — 从 API 加载请求记录
   - 调用 `/api/devrequests/list` 获取分页数据
   - 支持 keyword、method、domain 过滤
   - 更新 state.records 和 state.total
   - 调用 `renderTable()` 和 `renderPagination()`

2. `renderTable()` — 渲染请求表格
   - 遍历 state.records
   - 每行显示：方法（彩色）、URL（截断）、状态码（彩色）、时间、大小
   - 点击行触发 `toggleExpand(record)`
   - 当前展开行高亮（accent 10% opacity）

3. `renderPagination()` — 渲染分页控件
   - 计算总页数
   - 更新上一页/下一页按钮状态
   - 更新页码信息

4. `toggleExpand(record)` — 展开/收起详情面板
   - 点击已展开的行 → 收起
   - 点击新行 → 展开该行，收起之前的
   - 展开时显示 detailPanel，渲染请求头/请求体/响应头/响应体 tab

5. `renderDetail(record, tab)` — 渲染详情面板内容
   - request-headers：JSON 格式化显示
   - request-body：JSON 格式化显示（如有）
   - response-headers：JSON 格式化显示
   - response-body：JSON 格式化显示（如有）
   - cookies：从请求头中提取 Cookie 并格式化

6. `formatMethod(method)` — 方法列样式
   - GET: success-color, POST: accent-color, PUT: warning-color, DELETE: danger-color, PATCH: purple
   - 12px, weight 600, uppercase

7. `formatStatusCode(code)` — 状态码样式
   - 2xx: success-color, 3xx: accent-color, 4xx: warning-color, 5xx: danger-color

8. `formatDuration(ms)` — 时间格式化
   - < 1s: "{N}ms"
   - >= 1s: "{N}.{N}s"
   - > 3s: 红色

9. `formatSize(bytes)` — 大小格式化
   - B / KB / MB

10. `loadDomains()` — 加载域名过滤选项
    - 调用 `/api/devrequests/domains`
    - 填充 domainFilter 下拉选项

11. `clearAll()` — 清空所有请求
    - 显示确认对话框
    - 确认后调用 `/api/devrequests/clear`
    - 清空表格，显示 toast

12. `copyDetail()` — 复制详情内容到剪贴板
    - 使用 `navigator.clipboard.writeText()`

13. `startAutoRefresh()` — 启动自动刷新（每 3 秒）
    - 仅在第一页且无过滤条件时启用
    - 轮询 `/api/devrequests/list`，有新数据时追加到表格顶部

14. `stopAutoRefresh()` — 停止自动刷新

**事件监听器：**
- searchInput input → 防抖 300ms → 重新加载
- domainFilter change → 重新加载
- methodFilter change → 重新加载
- refreshBtn click → 重新加载
- clearAllBtn click → 显示确认对话框
- confirmClearBtn click → 清空并重新加载
- prevPageBtn/nextPageBtn click → 翻页
- detail-tab click → 切换详情 tab
- copyDetailBtn click → 复制内容
