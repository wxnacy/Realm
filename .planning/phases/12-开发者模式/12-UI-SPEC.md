## Component Inventory

### 1. Settings Page — 开发者模式 (settings.html)

**Sidebar Entry:**
- Reuse `.sidebar-item[data-page="devmode"]` pattern (same as general/rules/shortcuts/about)
- Icon: code/terminal SVG icon (Feather `terminal` icon, 18x18, stroke-width 2)
- Label: "开发者模式"
- Position: after "快捷键设置", before "关于"

**Developer Mode Section Layout:**

```
+------------------------------------------------------+
| 开发者模式                                            |
+------------------------------------------------------+
| [开关组]                                              |
|   开发者模式                               [toggle]   |
|   开启后可抓取匹配域名的 API 请求数据                  |
+------------------------------------------------------+
| [数据保留设置] (disabled when toggle OFF)              |
|   抓取数据保留天数                    [select ▾]       |
|   选项: 3天 / 7天 / 14天 / 30天 / 永不删除            |
+------------------------------------------------------+
| [监控域名列表] (disabled when toggle OFF)              |
|   域名列表                                             |
|   ┌─────────────────────────────────────────────┐    |
|   │ example.com                          [×]    │    |
|   │ api.test.com                         [×]    │    |
|   └─────────────────────────────────────────────┘    |
|   ┌──────────────────────┐  ┌────────┐               |
|   │ 输入或选择域名...     │  │ 添加域名│               |
|   └──────────────────────┘  └────────┘               |
+------------------------------------------------------+
| [队列状态] (disabled when toggle OFF)                  |
|   写入队列: 42 条待写入  |  最后写入: 2 秒前           |
+------------------------------------------------------+
| [查看请求] (disabled when toggle OFF)                  |
|   → 查看抓取的请求数据 (链接到 realm://devrequests)    |
+------------------------------------------------------+
```

**Toggle Switch:**
- Reuse existing `.toggle-switch > .toggle-track + .toggle-thumb` pattern
- Default state: OFF (`.toggle-track` without `.active`)
- ON state: `.toggle-track.active` (accent color #3B82F6)
- Toggle text: inline label "开发者模式" at 14px/400, description text at 14px/text-secondary

**Disabled State:**
- When toggle is OFF, all elements below the toggle group receive `opacity: 0.4; pointer-events: none;`
- Container class: `.devmode-disabled` on the settings group wrappers
- Toggle itself is always interactive

**Domain Input:**
- Input type: `<input type="text">` with datalist for autocomplete
- Datalist populated from: browsing history domains (deduplicated)
- Input field: 100% width, height 40px, bg-tertiary, border-radius 8px (same as `.history-search`)
- Add button: `.btn .btn-primary` with text "添加域名"
- Validation: trim whitespace, reject empty, reject duplicates, basic domain format check
- On submit: clear input, prepend domain to list, show toast

**Domain List:**
- Each domain row: `.settings-item` with flex layout
- Left: domain text (14px, text-primary)
- Right: delete button (`.btn-danger-icon`, X icon 16x16)
- Delete: click shows confirmation (non-modal inline confirm or direct delete with undo toast)
- Decision: direct delete with undo toast (simpler, less friction)

**Queue Status Indicator:**
- Layout: inline text in a `.settings-item`
- Left label: "写入队列"
- Right value: "{N} 条待写入" — updates every 2 seconds
- Color coding: green (0-100), yellow (100-500), red (500+)
- Sub-text: "最后写入: {N} 秒前"

**Data Retention Select:**
- Reuse `.settings-select` pattern
- Options: 3天 / 7天 / 14天 / 30天 / 永不删除
- Default: 7天

**Link to DevRequests:**
- Styled as a text link with arrow: "→ 查看抓取的请求数据"
- Opens `realm://devrequests` in new tab
- Color: accent-color, hover: accent-hover

## Interaction Specifications

### Toggle Behavior
1. Click toggle → toggle state
2. If turning ON → save setting, enable all sub-sections (fade in 200ms)
3. If turning OFF → save setting, disable all sub-sections (fade out 200ms)
4. No confirmation dialog for toggle (non-destructive, can be re-enabled)

### Domain Addition Flow
1. User types domain in input field
2. Autocomplete dropdown appears after 2+ characters (from history domains)
3. User can select from dropdown or type custom domain
4. Press Enter or click "添加域名" button
5. Validation: trim, check empty, check duplicate, check format
6. On success: domain prepended to list, input cleared, toast shown
7. On validation error: input border turns red, error text shown below input (2s)

### Domain Removal Flow
1. User clicks × button on domain row
2. Domain row immediately removed from list
3. Toast shown: "已停止监控: {domain}" with "撤销" action
4. Undo available for 5 seconds (toast auto-dismisses after 5s)
5. On undo: domain re-added to list at original position

### Request Table Interaction
1. Click row → toggle expand/collapse detail panel
2. Only one row expanded at a time (collapse previous)
3. Sort: click column header → toggle asc/desc
4. Filter changes → reload data from SQLite, reset to page 1
5. Auto-refresh: every 3 seconds poll for new requests (append to top if on page 1)

### Queue Status Update
1. Main process emits queue count every 2 seconds via IPC
2. Settings page listens and updates display
3. Color thresholds: green (0-100), yellow (100-500), red (500+)
