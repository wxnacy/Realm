**1. 创建 `src/bookmarks-bar-menu.js`（新文件）**

实现收藏栏下拉菜单逻辑模块：

**菜单容器管理：**
- 维护当前打开的菜单引用 `_activeMenus: []`，用于关闭时清理
- `function closeAllMenus()`：移除所有活动菜单 DOM，清除所有悬停定时器
- 监听 `document.addEventListener('mousedown', ...)` 点击外部区域关闭菜单
- 监听 `document.addEventListener('keydown', ...)` ESC 键关闭所有菜单

**文件夹下拉菜单（per D-04）：**
- `async function showFolderMenu(folderEl, folderId)`：
  1. 先调用 `closeAllMenus()` 关闭已有菜单
  2. 调用 `window.realmAPI.bookmarksBar.listFavorites(folderId)` 获取子收藏项
  3. 调用 `window.realmAPI.bookmarksBar.listFolders(folderId)` 获取子文件夹
  4. 创建 `.bookmarks-dropdown` 容器，定位在 folderEl 下方（`getBoundingClientRect()` 计算位置）
  5. 渲染子收藏项（`.bookmarks-dropdown-item`，favicon + 标题，点击导航）
  6. 渲染子文件夹（`.bookmarks-dropdown-item` + 箭头图标，per D-05 绑定悬停展开）
  7. 如果子文件夹和子收藏项都有，用分隔线隔开
  8. 将菜单 DOM 添加到 `document.body`（确保 z-index 不受父元素影响）
  9. 下一帧添加 `.visible` 类触发动画

**子菜单悬停展开（per D-05）：**
- 对每个子文件夹项：
  - `mouseenter` 时启动 300ms 定时器，到时调用 `showSubmenu(folderItemEl, subfolderId)`
  - `mouseleave` 时清除定时器，启动 150ms 延迟关闭（防止鼠标移到子菜单途中关闭）
  - 子菜单 DOM（`.bookmarks-submenu`）定位在文件夹项右侧（`left: 100%`，`top: -4px` 对齐）
  - 鼠标进入子菜单时取消关闭定时器

**溢出菜单（per D-01/D-02）：**
- `function showOverflowMenu(overflowBtn, overflowItems)`：
  1. 从 bookmarks-bar.js 获取 `overflowItems` 数组（包含被隐藏的收藏项和文件夹数据）
  2. 创建 `.bookmarks-dropdown` 容器，定位在 >> 按钮下方（向左对齐，防止超出右边界）
  3. 渲染方式与文件夹下拉菜单相同：收藏项可点击导航，文件夹可悬停展开子菜单
  4. 如果溢出菜单太靠右（`rect.right + menuWidth > window.innerWidth`），改为向左展开

**菜单项导航：**
- 收藏项点击：关闭菜单后在当前标签页导航（同 bookmarks-bar.js 的导航逻辑）
- Cmd/Ctrl+Click 收藏项：新标签页打开

**位置安全：**
- 所有菜单定位时检查是否超出视口边界，必要时翻转方向
- 菜单 `position: fixed`（或 `absolute` 挂载到 body），`z-index: 9999`

**暴露全局 API：**
```javascript
window.bookmarksBarMenu = {
  showFolderMenu,
  showOverflowMenu,
  closeAllMenus,
};
```

**2. 修改 `src/renderer.js` — 右键菜单事件委托**

替换 Plan 01 中的占位右键事件处理，实现完整的三种右键菜单：

**事件委托策略：**
在 `setupEventListeners()` 中已有的 `#bookmarksBar` contextmenu 监听器中，根据 `e.target` 判断右键目标类型：

```javascript
bookmarksBar.addEventListener('contextmenu', (e) => {
  e.preventDefault();
  const bookmarkEl = e.target.closest('.bookmark-item');
  const folderEl = e.target.closest('.bookmark-folder');

  if (bookmarkEl) {
    // 收藏项右键菜单（per D-12）
    const info = {
      id: bookmarkEl.dataset.bookmarkId,
      url: bookmarkEl.dataset.bookmarkUrl,
      title: bookmarkEl.dataset.bookmarkTitle,
    };
    window.realmAPI.showBookmarksBarContextMenu({ type: 'bookmark', ...info });
  } else if (folderEl) {
    // 文件夹右键菜单（per D-13）
    const info = {
      id: folderEl.dataset.folderId,
      name: folderEl.dataset.folderName,
    };
    window.realmAPI.showBookmarksBarContextMenu({ type: 'folder', ...info });
  } else {
    // 空白区域右键菜单（per D-03）
    window.realmAPI.showBookmarksBarContextMenu({ type: 'blank' });
  }
});
```

**4. 修改 `main.js` — 右键菜单 IPC handler + Electron Menu**

在 IPC handler 注册区域新增 `show-bookmarks-bar-context-menu` 处理：

```javascript
ipcMain.on('show-bookmarks-bar-context-menu', (event, info) => {
  const mainWindow = BrowserWindow.fromWebContents(event.sender);
  if (!mainWindow) return;

  let template = [];

  if (info.type === 'bookmark') {
    // D-12: 收藏项右键菜单
    template = [
      { label: '在新标签页打开', click: () => mainWindow.webContents.send('bookmarks-bar:navigate', { url: info.url, newTab: true }) },
      { type: 'separator' },
      { label: '编辑', click: () => mainWindow.webContents.send('bookmarks-bar:edit-bookmark', { id: info.id }) },
      { type: 'separator' },
      { label: '删除', click: async () => { favoritesManager.deleteRecord(info.id); mainWindow.webContents.send('bookmarks-bar:refresh'); } },
    ];
  } else if (info.type === 'folder') {
    // D-13: 文件夹右键菜单
    template = [
      { label: '在新标签页中打开所有书签', click: () => mainWindow.webContents.send('bookmarks-bar:open-all', { folderId: info.id }) },
      { type: 'separator' },
      { label: '重命名', click: () => mainWindow.webContents.send('bookmarks-bar:rename-folder', { id: info.id, name: info.name }) },
      { label: '删除', click: async () => { favoritesManager.deleteFolder(info.id); mainWindow.webContents.send('bookmarks-bar:refresh'); } },
      { type: 'separator' },
      { label: '添加书签', click: () => mainWindow.webContents.send('bookmarks-bar:add-bookmark', { folderId: info.id }) },
      { label: '添加文件夹', click: () => mainWindow.webContents.send('bookmarks-bar:add-folder', { parentId: info.id }) },
    ];
  } else {
    // D-03/D-14: 空白区域右键菜单
    template = [
      { label: '添加书签', click: () => mainWindow.webContents.send('bookmarks-bar:add-bookmark', { folderId: 0 }) },
      { label: '添加文件夹', click: () => mainWindow.webContents.send('bookmarks-bar:add-folder', { parentId: 0 }) },
      { type: 'separator' },
      { label: '隐藏收藏栏', click: () => {
        configStore.set('bookmarksBar.visible', false);
        mainWindow.webContents.send('bookmarks-bar:visibility-changed', { visible: false });
      }},
    ];
  }

  const menu = Menu.buildFromTemplate(template);
  menu.popup({ window: mainWindow });
});
```

在文件顶部确认已引入 `Menu`（`const { Menu } = require('electron')`），复用已有的 context-menu 构建模式。

**右键菜单行为 IPC 监听：**
在 renderer.js 中监听菜单行为事件：
```javascript
window.realmAPI.onIpcMessage('bookmarks-bar:refresh', () => {
  if (window.bookmarksBar) window.bookmarksBar.load();
});
window.realmAPI.onIpcMessage('bookmarks-bar:visibility-changed', (data) => {
  const bookmarksBar = document.getElementById('bookmarksBar');
  if (bookmarksBar) bookmarksBar.style.display = data.visible ? '' : 'none';
  if (data.visible && window.bookmarksBar) window.bookmarksBar.load();
});
window.realmAPI.onIpcMessage('bookmarks-bar:navigate', (data) => {
  if (data.newTab) {
    window.open(data.url, '_blank');
  }
});
```

对于 `bookmarks-bar:add-bookmark`、`bookmarks-bar:add-folder`、`bookmarks-bar:edit-bookmark`、`bookmarks-bar:rename-folder`，调用现有的收藏夹添加/编辑 dialog 逻辑（如果有），或者直接复用 favorites-page.js 中的 dialog。如果收藏栏内没有现成的 dialog，则通过 IPC 跳转到收藏夹页面执行这些操作。
