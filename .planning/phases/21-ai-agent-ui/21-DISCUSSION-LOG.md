## 面板布局与位置

### 面板形态

| Option | Description | Selected |
|--------|-------------|----------|
| 右侧侧边栏 | 类似 VS Code 的侧边面板，固定在窗口右侧，不遮挡网页内容。宽度可拖拽调整。 | ✓ |
| 浮动窗口 | 类似 macOS Spotlight，浮动在窗口中央或角落，可拖拽移动位置。 | |
| 底部抽屉 | 类似 Chrome DevTools 的抽屉模式，从底部向上展开。 | |

**User's choice:** 右侧侧边栏（用户补充：地址栏后面的工具栏增加一个按钮，点击后从右侧打开侧边栏。不遮挡网页内容。宽度可拖拽调整。）
**Notes:** 用户明确要求工具栏按钮触发侧边栏打开

### 面板默认宽度

| Option | Description | Selected |
|--------|-------------|----------|
| 360px 默认 | 默认 360px，最小 280px，最大 600px。适合聊天消息阅读。 | ✓ |
| 420px 默认 | 默认 420px，最小 320px，最大 720px。更宽敞，适合展示代码和工具输出。 | |
| 300px 默认 | 默认 300px，最小 240px，最大 500px。紧凑设计，最大化网页显示区域。 | |

**User's choice:** 360px 默认 (推荐)

### 面板状态记忆

| Option | Description | Selected |
|--------|-------------|----------|
| 记忆宽度+开关状态 | 记住上次的宽度和开关状态，下次启动自动恢复。 | ✓ |
| 仅记忆开关状态 | 只记住开关状态，宽度每次重置为默认值。 | |
| 不记忆 | 每次启动都重置为关闭状态，不记忆任何状态。 | |

**User's choice:** 记忆宽度+开关状态 (推荐)

### 工具栏按钮位置

| Option | Description | Selected |
|--------|-------------|----------|
| 工具栏最右侧 | AI 按钮放在工具栏最右侧（刷新按钮之后），与浏览器导航按钮分开。 | |
| 地址栏右侧 | AI 按钮放在地址栏右侧、刷新按钮之前，紧邻导航区域。 | |
| Tab 栏右侧 | AI 按钮放在 Tab 栏右侧，与其他功能区分开。 | |

**User's choice:** 放在最右边，设置按钮后面（用户自定义位置）
**Notes:** 用户明确指定在设置按钮后面

### 面板头部元素

| Option | Description | Selected |
|--------|-------------|----------|
| 标题+设置+关闭 | 显示 'AI 助手' 标题 + 设置按钮（齿轮图标）+ 关闭按钮。简洁实用。 | ✓ |
| 标题+模型选择+关闭 | 显示标题 + 模型选择下拉框 + 关闭按钮。方便快速切换模型。 | |
| 标题+关闭 | 仅显示标题和关闭按钮，设置入口放在主设置页面。 | |

**User's choice:** 标题+设置+关闭 (推荐)

## 消息展示与流式渲染

### 消息样式

| Option | Description | Selected |
|--------|-------------|----------|
| 气泡对话样式 | 用户消息靠右（深色气泡），AI 消息靠左（浅色气泡）。类似 iMessage/微信风格。 | ✓ |
| 统一对话流样式 | 所有消息靠左对齐，用户消息和 AI 消息用颜色区分。类似 ChatGPT 网页版。 | |
| 卡片式布局 | 简洁的卡片式布局，每条消息是一个带边框的卡片。 | |

**User's choice:** 气泡对话样式 (推荐)

### Markdown 渲染

| Option | Description | Selected |
|--------|-------------|----------|
| 完整 Markdown + 代码高亮 | 支持 Markdown 渲染（标题、列表、粗体、斜体、链接），代码块带语法高亮。 | ✓ |
| 基本 Markdown | 仅支持基本格式（粗体、斜体、链接），不渲染代码块。 | |
| 纯文本 | 纯文本显示，不渲染任何 Markdown 格式。 | |

**User's choice:** 完整 Markdown + 代码高亮 (推荐)

### 流式渲染方式

| Option | Description | Selected |
|--------|-------------|----------|
| 逐字流式显示 | AI 回复逐字显示（类似 ChatGPT），光标闪烁指示正在生成。用户看到实时输出。 | ✓ |
| 等待完成后显示 | 等待 AI 回复完成后一次性显示。简单但用户等待体验差。 | |
| 按块流式显示 | 按段落/代码块为单位流式显示，每个块完成后再显示下一个。 | |

**User's choice:** 逐字流式显示 (推荐)

### 消息操作按钮

| Option | Description | Selected |
|--------|-------------|----------|
| 复制+重新生成 | 每条消息支持：复制内容、重新生成（AI 消息）。简洁够用。 | ✓ |
| 复制+重新生成+反馈+编辑 | 复制、重新生成、点赞/点踩反馈、编辑（用户消息）。功能丰富。 | |
| 仅复制 | 仅支持复制内容。最简洁。 | |

**User's choice:** 复制+重新生成 (推荐)

## 工具执行状态展示

### 工具状态样式

| Option | Description | Selected |
|--------|-------------|----------|
| 可折叠卡片 | 工具调用显示为可折叠卡片，点击展开查看详细参数和结果。默认折叠只显示工具名+状态图标。 | ✓ |
| 内联状态文本 | 工具调用显示为内联文本（如 '正在搜索历史记录...'），完成后消失。 | |
| 独立消息气泡 | 工具调用显示为独立的消息气泡，包含工具名、参数、结果。 | |

**User's choice:** 可折叠卡片 (推荐)

### 工具进度信息

| Option | Description | Selected |
|--------|-------------|----------|
| 名称+状态图标 | 显示工具名称 + 执行状态图标（旋转/成功/失败）+ 展开后显示参数和结果。 | ✓ |
| 名称+参数+实时输出 | 显示工具名称 + 详细参数 + 实时输出（如搜索结果列表）。 | |
| 仅名称+状态 | 仅显示工具名称和状态（执行中/完成/失败），不显示参数。 | |

**User's choice:** 名称+状态图标 (推荐)

### 工具结果展示

| Option | Description | Selected |
|--------|-------------|----------|
| 卡片内展开 | 工具结果在折叠卡片内展示，点击展开查看 JSON 或格式化结果。 | ✓ |
| 独立结果气泡 | 工具结果作为新的消息气泡显示在聊天流中。 | |
| 不显示结果 | 工具结果不直接显示，只通过 AI 的文字回复间接展示。 | |

**User's choice:** 卡片内展开 (推荐)

### 多工具并行展示

| Option | Description | Selected |
|--------|-------------|----------|
| 纵向堆叠 | 多个工具调用纵向堆叠，每个工具独立显示状态。 | ✓ |
| 合并卡片 | 多个工具调用合并为一个卡片，内部列出所有工具状态。 | |
| 仅显示当前 | 只显示当前正在执行的工具，已完成的折叠隐藏。 | |

**User's choice:** 纵向堆叠 (推荐)

## 面板交互与快捷键

### 唤起快捷键

| Option | Description | Selected |
|--------|-------------|----------|
| Cmd+Shift+A | Cmd/Ctrl + Shift + A 唤起/隐藏 AI 面板。与浏览器常用快捷键不冲突。 | |
| Cmd+. | Cmd/Ctrl + . (点号) 唤起/隐藏。更简洁但可能与其他应用冲突。 | |
| 无快捷键 | 不设全局快捷键，只能通过工具栏按钮切换。 | |

**User's choice:** cmd + ]（用户自定义快捷键）
**Notes:** 用户选择 Cmd+] 作为快捷键

### 输入框设计

| Option | Description | Selected |
|--------|-------------|----------|
| 自动扩展+Enter发送 | 多行输入框（自动扩展高度），Enter 发送，Shift+Enter 换行。底部固定。 | ✓ |
| 单行+发送按钮 | 单行输入框 + 发送按钮。简洁但不支持多行输入。 | |
| 固定高度+发送按钮 | 固定高度的多行输入框（3行），有滚动条。发送按钮在旁边。 | |

**User's choice:** 自动扩展+Enter发送 (推荐)

### 拖拽调整

| Option | Description | Selected |
|--------|-------------|----------|
| 左侧边缘拖拽 | 面板左侧边缘可拖拽调整宽度，鼠标悬停时显示调整光标。 | ✓ |
| 两侧边缘拖拽 | 面板左右两侧边缘都可拖拽调整。 | |
| 固定宽度 | 不支持拖拽调整，使用固定宽度。 | |

**User's choice:** 左侧边缘拖拽 (推荐)

### 滚动行为

| Option | Description | Selected |
|--------|-------------|----------|
| 智能自动滚动 | 新消息自动滚动到底部，用户上滚后暂停自动滚动，显示'回到底部'按钮。 | ✓ |
| 始终自动滚动 | 始终自动滚动到底部，不管用户是否在查看历史消息。 | |
| 不自动滚动 | 从不自动滚动，用户需要手动滚动查看新消息。 | |

**User's choice:** 智能自动滚动 (推荐)
