## Interaction Patterns

### 文件夹树交互（D-05, D-06, D-07）

```
点击文件夹 = 展开/收起 + 导航（一步完成，类似 Finder 侧边栏）

┌─ 文件夹树面板 (200-240px) ──────────────┐
│ 📂 所有书签                        (48) │  ← 根节点，始终可见
│   📂 开发                           (12) │  ← 展开状态
│     📂 前端                          (5) │  ← 子文件夹
│     📂 后端                          (7) │
│   📂 工作                            (8) │  ← 收起状态
│   📂 学习                           (28) │
└──────────────────────────────────────────┘

交互规则：
- 单击：展开/收起 + 导航到该文件夹
- 文件夹名右侧显示收藏数量徽标（空文件夹不显示）
- 当前选中文件夹高亮（accent 背景色）
- 展开/收起箭头使用 CSS 过渡动画（非阻塞）
```

### 面包屑导航（D-03）

```
位置：右侧内容区顶部，搜索栏下方

┌─ 内容区 ──────────────────────────────────┐
│ 🔍 搜索收藏...                             │  ← 搜索栏（全宽）
│                                            │
│ 📁 所有书签 > 开发 > 前端                  │  ← 面包屑
│                                            │
│ [收藏项列表...]                             │
└────────────────────────────────────────────┘

交互规则：
- 点击路径中的任意节点可跳转到该位置
- 根目录显示 "所有书签"
- 当前文件夹名称不可点击（纯文本）
- 路径节点之间用 ">" 分隔
```

### 右键菜单（D-09, D-10, D-11）

```
使用 Electron 原生 Menu API（与现有网页右键菜单一致）

收藏项右键菜单：
├─ 打开
├─ 在新标签页中打开
├─ 在新窗口中打开
├─ ─────────
├─ 编辑
├─ 剪切        (Cmd+X)
├─ 复制        (Cmd+C)
├─ ─────────
├─ 删除        (Delete)
└─ 属性

文件夹右键菜单：
├─ 打开（在新标签页打开所有书签）
├─ 在新窗口中打开
├─ ─────────
├─ 重命名
├─ 添加书签
├─ 添加文件夹
├─ ─────────
└─ 删除        (Delete)

空白区域右键菜单：
├─ 新建文件夹
├─ 粘贴        (Cmd+V)
└─ 按名称排序

剪切/复制/粘贴行为（D-11）：
- 使用应用内部状态剪贴板：state.clipboard = { ids: [], mode: 'cut'|'copy', sourceFolderId }
- 剪切后源项显示半透明灰色视觉提示（opacity: 0.4）
- 粘贴调用 moveFavorites API（剪切）或创建新记录（复制）
```

### 新建文件夹 UI（D-08）

```
入口：
1. 左侧面板标题栏 "+" 按钮
2. 右键菜单 "新建文件夹"
3. 空白区域右键菜单 "新建文件夹"

行为：
- 在当前文件夹下创建子文件夹
- 弹出内联输入框（文件夹树中新增一行，显示输入框）
- 输入框默认焦点，支持 Enter 确认、Escape 取消
- 文件夹名称不能为空
- 创建成功后自动选中新文件夹并导航到其中
```

## Layout Specification

```
┌─ realm://favorites ──────────────────────────────────────────────┐
│                                                                   │
│  ┌─ 文件夹树面板 ─┐  ┌─ 内容区 ───────────────────────────────┐ │
│  │ (200-240px)    │  │                                         │ │
│  │ ┌────────────┐ │  │ 🔍 搜索收藏...                         │ │
│  │ │📂 所有书签 │ │  │                                         │ │
│  │ │  + (新建)  │ │  │ 📁 所有书签 > 开发 > 前端              │ │
│  │ ├────────────┤ │  │                                         │ │
│  │ │📂 开发     │ │  │ ┌─────────────────────────────────────┐ │ │
│  │ │📂 工作     │ │  │ │ 收藏项 1                            │ │ │
│  │ │📂 学习     │ │  │ │ 收藏项 2                            │ │ │
│  │ │            │ │  │ │ 📁 文件夹（可点击进入）              │ │ │
│  │ │            │ │  │ │ 收藏项 3                            │ │ │
│  │ │            │ │  │ │ ...                                 │ │ │
│  │ └────────────┘ │  │ └─────────────────────────────────────┘ │ │
│  └────────────────┘  └─────────────────────────────────────────┘ │
│                                                                   │
└───────────────────────────────────────────────────────────────────┘

尺寸约束：
- 文件夹树面板：200-240px 固定宽度（D-01）
- 内容区：flex: 1，自适应剩余宽度
- 搜索栏：全宽，横跨左右两栏（D-02）—— 实际实现在内容区顶部
- 文件夹树项高度：32px
- 收藏项高度：48px（与现有 favorite-item 一致）
```
