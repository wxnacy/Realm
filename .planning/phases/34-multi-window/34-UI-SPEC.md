# Phase 34 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Phase Overview

Phase 34 (窗口管理基础) 的核心是架构重构——将 window-manager 从单例改为 Map、扩展 assertTrustedSender 信任模型、实现 Dock 菜单和快捷键。**本阶段不引入新 UI 组件**，新窗口复用现有 `src/index.html` 和 `src/styles/main.css`。

UI 交互面集中在三个位置：macOS Dock 右键菜单、Application Menu 新增菜单项、键盘快捷键响应。

Phase 34 涉及的文案全部在菜单和快捷键层面，无页面内空态或错误态。

| Element | Copy |
|---------|------|

## Interaction Contract

### 新建窗口流程

```
用户触发（Cmd+N / Dock 右键"新建窗口" / App Menu）
  → main.js 创建 BrowserWindow（复用 createMainWindow 逻辑）
  → 新窗口加载 src/index.html
  → 使用默认容器（D-02）
  → 第一个 Tab 显示新标签页（D-01）
  → 焦点切换到新窗口
```

### 关闭窗口流程

```
用户触发 Cmd+Shift+W
  → 关闭当前焦点窗口
  → 窗口内所有 Tab 一起销毁
  → 如果是最后一个窗口 → 应用退出（D-06）
  → 如果还有其他窗口 → 其他窗口不受影响
```

### Cmd+W 关闭 Tab 流程

```
用户触发 Cmd+W
  → 关闭当前窗口的当前 Tab
  → 如果是该窗口最后一个 Tab → 窗口自动关闭（D-04）
```

### 窗口焦点切换

```
用户点击另一个窗口
  → BrowserWindow focus 事件触发
  → 工具栏状态更新为该窗口的状态（D-07）
  → Tab 栏更新为该窗口的 Tab 列表（D-08）
  → 容器选择器更新为该窗口当前 Tab 的容器
```

## Keyboard Shortcuts

| Action | Shortcut | Behavior |
|--------|----------|----------|
| 新建窗口 | Cmd+N | 创建新窗口，使用默认容器，显示新标签页 |
| 关闭窗口 | Cmd+Shift+W | 关闭当前焦点窗口（含所有 Tab） |
| 关闭 Tab | Cmd+W | 关闭当前 Tab；最后一个 Tab 时关闭窗口 |

注意：快捷键通过 Application Menu Accelerator 注册（shortcut-manager.js 的 registerShortcuts），焦点窗口接收 shortcut:triggered IPC（D-12）。
