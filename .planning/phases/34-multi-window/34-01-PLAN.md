重构 window-manager.js（per D-10），保留现有 windowContainerMap 和所有导出函数签名不变，新增内部数据结构和方法：

1. 新增模块级变量（替换 mainWindowRef 单例）：
   - `const windows = new Map();` — winId → BrowserWindow，所有窗口的注册表
   - `const managedWindowIds = new Set();` — 仅包含 createMainWindow 创建的窗口 ID
   - 保留现有 `const windowContainerMap = new Map();` 不变
   - 删除 `let mainWindowRef = null;`

2. 修改 `createMainWindow(containerId, container)` 函数：
   - 创建 BrowserWindow 后，注册到三个数据结构：`windows.set(mainWindow.id, mainWindow)`、`managedWindowIds.add(mainWindow.id)`、`windowContainerMap.set(mainWindow.id, containerId)`（保留现有）
   - 删除 `mainWindowRef = mainWindow;` 这一行
   - `closed` 事件清理三个数据结构：`windows.delete(mainWindow.id)`、`managedWindowIds.delete(mainWindow.id)`、`windowContainerMap.delete(mainWindow.id)`（保留现有）
   - 删除 `if (mainWindowRef === mainWindow) mainWindowRef = null;` 这一行
   - 其余逻辑不变（BrowserWindow 配置、loadFile、返回值）

3. 修改 `getMainWindow()` 函数：
   - 从 windows Map 中获取第一个元素（兼容现有 30+ 处调用）
   - 实现：遍历 windows 找第一个未销毁的窗口，没有则返回 null
   - 不再依赖 mainWindowRef

4. 新增 `isManagedWindow(winId)` 函数：
   - 参数：winId (number) — BrowserWindow.id
   - 返回：boolean — managedWindowIds.has(winId)
   - 用于 Plan 02 的 assertTrustedSender 泛化

5. 新增 `broadcast(channel, ...args)` 函数：
   - 遍历 windows Map，对每个未销毁的窗口调用 `win.webContents.send(channel, ...args)`
   - 跳过 `win.isDestroyed()` 的窗口
   - 用于 Plan 03 替换 main.js 中所有 mainWindow.webContents.send() 调用

6. 更新 `module.exports`：
   - 保留现有导出：createMainWindow, getMainWindow, getCurrentContainer, switchContainer
   - 新增导出：isManagedWindow, broadcast

7. 更新文件顶部 JSDoc 注释，说明模块现在管理多窗口注册表而非单例主窗口。
