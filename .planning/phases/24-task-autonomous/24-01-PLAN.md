<task type="auto" tdd="true">
  <name>Task 1.2: executeAction CDP 方法 — 页面操作执行</name>
  <files>cdp-manager.js</files>
  <behavior>
    - 传入 webContentsId、action 类型、target 目标，返回 { success, result, pageChanges }
    - 支持 15 种操作：click, scroll, type, select, check, focus, submit, upload, drag, hover, keydown, execute_script, screenshot, wait_for_element, blur（per D-10）
    - 元素定位：文本优先 + CSS 选择器兜底（per D-09）
    - 参数格式：{ action: 'click', target: '提交按钮' }（per D-11）
    - 操作结果包含页面变化信息（URL 变化、弹窗、验证错误等）（per D-12）
    - execute_script 操作仅允许白名单 DOM API（per D-16）
    - 10 秒超时保护（复用 executeCommand 超时机制）
  </behavior>
  <action>
    在 cdp-manager.js 中新增 executeAction(webContentsId, action, target, options?) 异步方法。

    实现要点：
    1. 调用 attachForAI(webContentsId, ['Runtime', 'DOM', 'Input']) 启用所需域
    2. 元素定位：通过 Runtime.evaluate 注入脚本，优先用文本描述匹配（per D-09）：
       - 先查找文本内容包含 target 的可点击元素（button, a, [role="button"], input[type="submit"]）
       - 再查找 aria-label/title/placeholder 包含 target 的元素
       - 最后尝试 document.querySelector(target) 作为 CSS 选择器兜底
    3. 根据 action 类型执行不同操作（per D-10）：
       - click: Input.dispatchMouseEvent（mousePressed + mouseReleased）
       - scroll: Runtime.evaluate 执行 window.scrollBy 或 element.scrollIntoView
       - type: Input.insertText（需要先 focus 目标元素）
       - select: Runtime.evaluate 设置 selectedIndex + dispatchInputEvent
       - check/uncheck: Runtime.evaluate 设置 checked + dispatchInputEvent
       - focus: DOM.focus
       - submit: Runtime.evaluate 调用 form.submit() 或 button.click()
       - upload: DOM.setFileInputFiles（per D-03）
       - drag: Input.dispatchMouseEvent（dragstart → drag → dragend 三阶段）
       - hover: Input.dispatchMouseEvent（mouseMoved）
       - keydown/keyup: Input.dispatchKeyEvent
       - execute_script: Runtime.evaluate（需要先通过安全检查，per D-16）
       - screenshot: Page.captureScreenshot
       - wait_for_element: 轮询 DOM.querySelector 直到元素出现或超时
       - blur: DOM.blur
    4. execute_script 安全检查：静态分析脚本内容，禁止 eval/Function/import/require/fs/net/http/child_process（per D-16）
    5. 操作完成后收集页面变化信息：当前 URL、是否有 alert/confirm 弹窗、表单验证错误
    6. finally 块调用 detachForAI(webContentsId) 确保用完即卸

    在 module.exports 中导出 executeAction。
  </action>
  <verify>

  </done>
