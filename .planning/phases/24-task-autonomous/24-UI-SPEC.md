### New Components (Phase 24)

#### 1. Action Confirmation Card (操作确认卡片)

**Location:** AI chat panel, inline as AI message

**HTML Structure:**
```html
<div class="ai-message ai-message-ai">
  <div class="ai-message-content">
    <div class="action-confirm-card">
      <div class="action-confirm-header">
        <div class="action-confirm-icon">
          <!-- SVG icon based on action type -->
        </div>
        <div class="action-confirm-info">
          <div class="action-confirm-title">填写邮箱</div>
          <div class="action-confirm-description">test@example.com</div>
        </div>
        <div class="action-confirm-risk risk-high">
          <!-- risk-low / risk-medium / risk-high -->
          高风险
        </div>
      </div>
      <div class="action-confirm-details">
        <div class="action-confirm-detail-row">
          <span class="detail-label">目标页面</span>
          <span class="detail-value">https://example.com/login</span>
        </div>
        <div class="action-confirm-detail-row">
          <span class="detail-label">容器</span>
          <span class="detail-value">工作容器</span>
        </div>
      </div>
      <div class="action-confirm-actions">
        <button class="action-confirm-btn action-confirm-btn-cancel">取消</button>
        <button class="action-confirm-btn action-confirm-btn-confirm">确认执行</button>
      </div>
    </div>
  </div>
</div>
```

**CSS Classes:**
- `.action-confirm-card` — Outer container, bg: var(--bg-tertiary), border-radius: 8px, overflow: hidden
- `.action-confirm-header` — Flex row, gap: 12px, padding: 12px, align-items: center
- `.action-confirm-icon` — 24x24px, flex-shrink: 0, color based on action type
- `.action-confirm-info` — Flex column, gap: 2px, flex: 1
- `.action-confirm-title` — font-size: 14px, font-weight: 600, color: var(--text-primary)
- `.action-confirm-description` — font-size: 12px, color: var(--text-secondary)
- `.action-confirm-risk` — font-size: 11px, font-weight: 500, padding: 2px 8px, border-radius: 10px
  - `.risk-low` — bg: rgba(16,185,129,0.15), color: #10B981
  - `.risk-medium` — bg: rgba(245,158,11,0.15), color: #F59E0B
  - `.risk-high` — bg: rgba(239,68,68,0.15), color: #EF4444
- `.action-confirm-details` — padding: 0 12px 12px, border-top: 1px solid var(--border-color), margin-top: 4px
- `.action-confirm-detail-row` — display: flex, justify-content: space-between, padding: 6px 0, font-size: 12px
- `.detail-label` — color: var(--text-muted)
- `.detail-value` — color: var(--text-secondary), text-overflow: ellipsis, overflow: hidden, max-width: 60%
- `.action-confirm-actions` — display: flex, gap: 8px, padding: 8px 12px, border-top: 1px solid var(--border-color)
- `.action-confirm-btn` — flex: 1, height: 32px, border-radius: 6px, font-size: 13px, font-weight: 500, cursor: pointer, transition: all 0.15s
- `.action-confirm-btn-cancel` — bg: var(--bg-hover), color: var(--text-primary), hover: bg #505050
- `.action-confirm-btn-confirm` — bg: var(--accent-color), color: #ffffff, hover: bg var(--accent-hover)

**Interaction:**
- Confirm button click → send IPC `action:confirm` with actionId, card updates to "执行中..." state
- Cancel button click → send IPC `action:cancel` with actionId, card updates to "已取消" state (grayed out)
- After execution: card updates to show result (success with checkmark, or error with message)

## Interaction Patterns

### Action Confirmation Flow

```
User: "帮我填写登录表单，邮箱 test@example.com"
  ↓
AI executes fill_form (low risk → auto-execute)
  ↓
AI: "已填写邮箱字段为 test@example.com"
  ↓
User: "点击提交按钮"
  ↓
AI detects high-risk action (form submit)
  ↓
AI renders confirmation card in chat:
  ┌─────────────────────────────────┐
  │ ⚠️ 提交表单            [高风险] │
  │ 向 https://example.com 提交数据 │
  ├─────────────────────────────────┤
  │ 目标页面 │ example.com/login    │
  │ 容器     │ 工作容器             │
  ├─────────────────────────────────┤
  │ [取消]           [确认执行]      │
  └─────────────────────────────────┘
  ↓
User clicks "确认执行"
  ↓
Card updates to "执行中..." → "操作完成 ✓"
```

### Risk Level Classification

| Action | Risk Level | Confirmation |
|--------|------------|--------------|
| fill_form (input fields) | Low | No (auto-execute) |
| execute_action (click, scroll) | Low | No (auto-execute) |
| execute_action (type, select) | Low | No (auto-execute) |
| form submit | High | Yes |
| file upload | High | Yes |
| payment-related | High | Yes |

### State Transitions

**Confirmation Card States:**
1. **Pending** — Initial state, buttons enabled
2. **Executing** — After confirm click, spinner, buttons disabled
3. **Success** — Green checkmark, result message
4. **Error** — Red X, error message, retry button
5. **Cancelled** — Grayed out, "已取消" label

**CAPTCHA Waiting States:**
1. **Waiting** — Spinner active, monitoring page
2. **Completed** — "验证完成" message, auto-transition to next step
