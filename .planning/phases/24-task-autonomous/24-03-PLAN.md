<task type="auto" tdd="true">
  <name>Task 3.1: detectCaptcha CDP 方法 — CAPTCHA/2FA 页面检测</name>
  <files>cdp-manager.js</files>
  <behavior>
    - 检测 reCAPTCHA iframe（.g-recaptcha, iframe[src*="recaptcha"]）（per D-15）
    - 检测 hCaptcha（.h-captcha, iframe[src*="hcaptcha"]）（per D-15）
    - 检测 Turnstile（.cf-turnstile, iframe[src*="turnstile"]）（per D-15）
    - 检测页面关键词：验证码、机器人检测、安全验证、人机验证、CAPTCHA、verify you are human（per D-15）
    - 检测 2FA 页面特征：input[type="tel"] + 关键词（双重认证、两步验证、验证码输入）
    - 返回 { detected: boolean, type?: string, confidence: 'high'|'medium'|'low' }
    - DOM 特征 + 关键词双重验证减少误报（per D-15）
  </behavior>
  <action>
    在 cdp-manager.js 中新增 detectCaptcha(webContentsId) 异步方法。

    实现要点：
    1. 调用 attachForAI(webContentsId, ['Runtime']) 启用 Runtime 域
    2. 通过 Runtime.evaluate 注入检测脚本（per D-15）：

    检测脚本逻辑：
    a. 特征检测（高置信度）：
       - reCAPTCHA: document.querySelector('.g-recaptcha, iframe[src*="recaptcha"], .g-recaptcha-response')
       - hCaptcha: document.querySelector('.h-captcha, iframe[src*="hcaptcha"]')
       - Turnstile: document.querySelector('.cf-turnstile, iframe[src*="turnstile"]')

    b. 关键词检测（中置信度）：
       - 从 document.body.innerText 提取文本
       - 中文关键词：验证码、机器人检测、安全验证、人机验证、请完成安全验证
       - 英文关键词：CAPTCHA, verify you are human, prove you are not a robot, security check

    c. 2FA 页面检测（中置信度）：
       - 检测 input[type="tel"] + 周围文本包含"验证码"、"双重认证"、"两步验证"等
       - 检测 input[inputmode="numeric"] + maxlength=6（典型 TOTP 输入框）

    d. 双重验证逻辑：
       - 仅 DOM 特征 → detected=true, confidence='high'
       - 仅关键词 → 检查关键词数量 >= 2 才判定，confidence='medium'
       - DOM 特征 + 关键词 → detected=true, confidence='high'

    3. finally 块调用 detachForAI(webContentsId)

    在 module.exports 中导出 detectCaptcha。
  </action>
  <verify>
    <automated>
      node -e "const cm = require('./cdp-manager'); console.log(typeof cm.detectCaptcha === 'function' ? 'PASS' : 'FAIL')"
    </automated>
  </verify>
  <done>
    detectCaptcha 方法已导出，能检测 reCAPTCHA/hCaptcha/Turnstile 特征（D-15），返回 { detected, type?, confidence } 结构，支持双重验证减少误报。
  </done>
</task>

<task type="auto">
  <name>Task 3.2: CAPTCHA 检测集成 — fillForm/executeAction 执行前预检 + 暂停恢复机制</name>
  <files>ai-manager.js</files>
  <behavior>
    - fillForm/executeAction 执行前调用 detectCaptcha 进行预检
    - 检测到 CAPTCHA 时返回特殊结果，暂停当前任务
    - 返回信息包含检测类型和用户操作提示（per D-14）
    - 提供轮询等待机制：用户完成后自动检测 CAPTCHA 消失并恢复
  </behavior>
  <action>
    在 ai-manager.js 中集成 CAPTCHA 检测逻辑。

    实现要点：

    1. 在 fill_form 和 execute_action 的 execute 函数中，调用 cdpManager 方法前增加预检：
       - 调用 cdpManager.detectCaptcha(webContentsId)
       - 如果 detected === true 且 confidence === 'high' 或 'medium'：
         - 返回特殊格式结果，包含 captchaDetected: true, captchaType, message
         - message 文案："检测到{type}验证，请在页面中完成验证后重试。"（per D-14）

    2. 等待恢复机制（可选增强）：
       - 在返回 CAPTCHA 检测结果后，AI 可以选择调用一个 wait_for_captcha_completion 辅助方法
       - 该方法轮询 detectCaptcha，每 3 秒检测一次，最多等待 120 秒
       - CAPTCHA 消失后返回 { captchaCleared: true }，AI 可以继续执行原操作
       - 超时后返回 { captchaCleared: false, message: '验证码等待超时，请手动完成后重试' }

    3. CAPTCHA 检测结果格式化：
       - 包含在工具返回的 content[0].text 中
       - 附带用户操作指引（"请在页面中完成验证"）
       - 包含检测置信度信息（供 AI 判断是否重试）
  </action>
