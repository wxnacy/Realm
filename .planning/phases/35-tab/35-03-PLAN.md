  <action>
根据 UAT Issue #5 诊断结果，修复 macOS 上关闭最后窗口不退出的问题：

**main.js 修改：**

修改 `window-all-closed` 事件处理器（约 line 2694）：

```javascript
// 修改前：
app.on('window-all-closed', () => {
  console.log('[Realm] window-all-closed, quitting:', quitting, 'cookiesSaved:', cookiesSaved);
  if (process.platform !== 'darwin') {
    app.quit();
  }
});

// 修改后：
app.on('window-all-closed', () => {
  console.log('[Realm] window-all-closed, quitting:', quitting, 'cookiesSaved:', cookiesSaved);
  app.quit();
});
```

移除 `process.platform !== 'darwin'` 条件判断，让所有平台（包括 macOS）在关闭最后一个窗口时都退出应用。

**根因说明：**
- 标准 macOS 行为是关闭窗口后应用保留在 Dock
- 但 Realm 浏览器的场景不同：用户关闭的是最后一个窗口，此时 activate 事件会重建窗口并打开 realm://newtab
- 这不是用户期望的行为，应该直接退出
