## Component Inventory

本阶段新增的 UI 组件及其视觉规格：

### 1. 补全下拉框（`.autocomplete-dropdown`）

**定位方式**：`position: absolute`，锚定在 `.toolbar-center` 下方，宽度与 `.url-input` 一致。

**视觉规格**：

```
位置：toolbar-center 底部 + 4px 间距
宽度：与 .url-input 等宽（toolbar-center 内 flex:1 计算值）
最大高度：360px（6 条 × 60px/条）
背景色：var(--bg-secondary)
边框：1px solid var(--border-color)
圆角：8px（与现有 bookmarks-dropdown、env-var-suggestions 一致）
阴影：0 4px 12px rgba(0, 0, 0, 0.3)（深色）/ 0 4px 12px rgba(0, 0, 0, 0.1)（浅色）
z-index：10000（高于 bookmarks-dropdown 的 99999 以下，低于 modal）
内边距：6px 0（上下 6px，左右 0）
```

**展开/收起动画**：

```
收起态：opacity: 0; transform: scaleY(0.95); transform-origin: top; pointer-events: none
展开态：opacity: 1; transform: scaleY(1); pointer-events: auto
过渡：opacity 0.1s ease, transform 0.1s ease
```

参考现有 `.bookmarks-dropdown` 的动画模式（opacity + scale 过渡），但使用 scaleY 而非 scale 以保持宽度稳定。

### 2. 候选列表项（`.autocomplete-item`）

**布局**：左侧 favicon + 右侧两行文字（标题在上、URL 在下）+ 右侧可选来源标签

```
高度：56px（固定，包含 8px 上下内边距）
内边距：8px 12px
布局：display: flex; align-items: center; gap: 10px
圆角：4px（与 bookmarks-dropdown-item 一致）
外边距：0 4px（左右留出下拉框圆角空间）
```

**Favicon 区域**：

```
尺寸：16px × 16px
圆角：2px
flex-shrink: 0
object-fit: contain
```

Favicon 缺失时的默认图标：使用 SVG globe 图标（`<svg>` 内联），颜色 `var(--text-muted)`，尺寸 16px × 16px，背景 `var(--bg-tertiary)`，圆角 2px。与现有 `.history-item-favicon-fallback` 样式一致。

**文字区域**：

```
容器：display: flex; flex-direction: column; gap: 2px; flex: 1; min-width: 0
标题：font-size: 13px; font-weight: 500; color: var(--text-primary); overflow: hidden; text-overflow: ellipsis; white-space: nowrap
URL：font-size: 12px; color: var(--text-secondary); overflow: hidden; text-overflow: ellipsis; white-space: nowrap
```

**收藏夹标识**：收藏夹来源的条目，在 favicon 左侧显示一个 10px 的星标图标（金色 `#FBBF24`），与现有收藏按钮星标颜色一致。

**来源标签**（可选）：在 URL 右侧显示来源类型标签（"收藏" / "常用" / "历史"），font-size: 10px, color: var(--text-muted), padding: 1px 6px, border-radius: 3px, background: var(--bg-tertiary)。

**状态样式**：

```
默认态：transparent 背景
hover 态：background-color: var(--bg-hover)
键盘选中态（上下键导航）：background-color: rgba(59, 130, 246, 0.15); border-left: 2px solid var(--accent-color)
同时 hover + 选中：保持选中态样式（选中态优先级高于 hover）
```

### 3. Inline Completion（地址栏内联补全）

**实现方式**：在 `.url-input` 后方叠加一个透明的补全文本层（`.autocomplete-inline`），使用 `position: absolute` 精确对齐。

**视觉规格**：

```
位置：覆盖在 .url-input 上方，pointer-events: none
字体：与 .url-input 完全一致（font-size: 13px, font-family: inherit）
用户输入部分：透明（不可见，由底层 input 显示）
补全部分：color: var(--text-muted); background: rgba(59, 130, 246, 0.15)
```

**选中态（Chrome 行为）**：当用户按 Tab/Right 接受补全时，补全文本变为普通文本（颜色变为 `var(--text-primary)`），input 的 value 更新为完整 URL。

**更新时机**：每次 input 事件触发后（经过 100ms 防抖），如果返回了 inline suggestion，立即更新补全文本层。

## Interaction Contract

### 键盘行为

| 按键 | 行为 | 视觉反馈 |
|------|------|----------|
| 输入字符 | 100ms 防抖后查询，更新 inline + dropdown | 下拉框展开，inline 显示 |
| ArrowDown | dropdown 选中项下移（循环） | 选中项高亮（accent 蓝底） |
| ArrowUp | dropdown 选中项上移（循环） | 选中项高亮 |
| Enter | 跳转到当前选中项 URL（或 input 中的 URL） | 下拉框收起 |
| Tab | 接受 inline completion | 补全文本合并为普通文本 |
| ArrowRight（光标在末尾时） | 接受 inline completion | 同 Tab |
| Esc | 关闭下拉框，取消 inline completion | 下拉框收起，补全消失 |
| Backspace | 如果删除到无匹配，inline 消失；否则更新 | inline 和 dropdown 更新 |

### 鼠标行为

| 操作 | 行为 | 视觉反馈 |
|------|------|----------|
| 点击候选条目 | 在当前 Tab 导航到该 URL | 下拉框收起 |
| hover 候选条目 | 条目背景变为 hover 态 | `--bg-hover` 背景 |
| 点击下拉框外部 | 关闭下拉框 | 下拉框收起 |
| 点击地址栏（已有 inline） | 光标定位，inline 保持但不高亮 | 光标闪烁 |

### 状态转换

```
[空输入] --输入字符--> [查询中(100ms防抖)] --返回结果--> [显示下拉+inline]
[显示下拉] --继续输入--> [更新下拉+inline]
[显示下拉] --Esc--> [关闭下拉，清空inline]
[显示下拉] --Enter/点击条目--> [导航，关闭下拉]
[显示下拉] --Tab/Right--> [接受inline，关闭下拉]
[显示下拉] --输入无匹配--> [关闭下拉，清空inline]
[显示下拉] --地址栏失焦--> [关闭下拉，清空inline]
```
