**src/renderer.js — 新增自动补全功能：**

**1. 在 elements 对象中新增引用**（在现有 elements 定义区域）：
```
urlInputWrapper: document.querySelector('.url-input-wrapper'),
autocompleteInline: document.getElementById('autocompleteInline'),
autocompleteDropdown: document.getElementById('autocompleteDropdown'),
```

**2. 新增 state.autocomplete 状态对象**（在 state 定义区域之后）：
```
state.autocomplete = {
  query: '',
  suggestions: [],
  selectedIndex: -1,
  inlineText: '',
  isOpen: false,
  debounceTimer: null,
  cache: new Map(),
};
```

**3. 新增 initAutocomplete 函数**（在 setupEventListeners 之前）：

监听元素：
- `elements.urlInput` 的 `input` 事件 → handleAutocompleteInput
- `elements.urlInput` 的 `keydown` 事件 → handleAutocompleteKeydown
- `elements.urlInput` 的 `blur` 事件 → setTimeout 150ms 后 closeAutocomplete
- `elements.urlInput` 的 `focus` 事件 → 如果 state.autocomplete.query 非空则 openAutocomplete

在 `setupEventListeners()` 函数末尾调用 `initAutocomplete()`。

**4. handleAutocompleteInput 函数**（per D-15）：
- 获取 `elements.urlInput.value.trim()` 作为 query
- 清除 state.autocomplete.debounceTimer
- 空输入 → closeAutocomplete + return
- 设置 setTimeout 100ms（per D-15）：
  - 更新 state.autocomplete.query
  - 检查客户端缓存 getCachedSuggestions(query)
  - 缓存命中 → updateAutocompleteUI(cached)
  - 缓存未命中 → `await window.realmAPI.getAutocompleteSuggestions(query)` → cacheSuggestions → updateAutocompleteUI
  - catch 错误时 console.error

**5. handleAutocompleteKeydown 函数**（per D-08, D-12）：
- 如果 `!state.autocomplete.isOpen` 且 key 不是 'Enter' → return（不干预 Enter 导航）
- switch (e.key)：
  - 'ArrowDown' → e.preventDefault()，navigateAutocomplete(1)
  - 'ArrowUp' → e.preventDefault()，navigateAutocomplete(-1)
  - 'Enter' → 如果 selectedIndex >= 0：e.preventDefault() + selectAutocompleteItem(selectedIndex)；否则走原有 Enter 导航
  - 'Tab' → 如果 inlineText 非空：e.preventDefault() + acceptInlineCompletion（per D-08）
  - 'ArrowRight' → 如果光标在末尾且 inlineText 非空：e.preventDefault() + acceptInlineCompletion（per D-08）
  - 'Escape' → e.preventDefault() + closeAutocomplete

**6. updateAutocompleteUI(suggestions) 函数**：
- 更新 state.autocomplete.suggestions 和 selectedIndex = -1
- suggestions 为空 → closeAutocomplete + return
- 调用 updateInlineCompletion(suggestions[0]) 更新内联补全（per D-07）
- 调用 renderAutocompleteDropdown(suggestions) 渲染下拉列表（per D-10, D-11）
- 调用 openAutocomplete()

**7. updateInlineCompletion(suggestion) 函数**（per D-07）：
- 获取 query = state.autocomplete.query
- 获取 urlWithoutProtocol = suggestion.url 去除 `https?://`
- 如果 urlWithoutProtocol.toLowerCase().startsWith(query.toLowerCase())：
  - completion = urlWithoutProtocol.slice(query.length)
  - state.autocomplete.inlineText = completion
  - elements.autocompleteInline.textContent = query + completion
  - elements.autocompleteInline.style.display = 'block'
- 否则：inlineText = ''，display = 'none'

**8. renderAutocompleteDropdown(suggestions) 函数**（per D-10, D-11）：
- 清空 elements.autocompleteDropdown.innerHTML
- 遍历 suggestions.slice(0, 6)（per D-10）
- 每项创建 .autocomplete-item div：
  - favicon：img.autocomplete-item-favicon，src = item.faviconUrl，onerror 时隐藏 img 并显示 fallback SVG globe 图标
  - 文字区域 div.autocomplete-item-text：
    - div.autocomplete-item-title：textContent = item.title || item.url
    - div.autocomplete-item-url：textContent = item.url
  - 来源标签（可选）：span.autocomplete-item-badge，text 为 '收藏'/'常用'/'历史'
  - 收藏夹来源：在 favicon 前插入 10px 金色星标 SVG
  - mousedown 事件（非 click）：e.preventDefault() + selectAutocompleteItem(index) — 使用 mousedown 阻止 blur
  - mouseenter 事件：更新 selectedIndex + updateDropdownHighlight

**9. navigateAutocomplete(direction) 函数**（per D-12）：
- 计算 newIndex（循环：0 → max → 0）
- 更新 state.autocomplete.selectedIndex
- updateDropdownHighlight()
- updateInlineCompletion(suggestions[newIndex])（per D-09，键盘选择时同步更新 inline）

**10. updateDropdownHighlight() 函数**：
- 遍历 .autocomplete-item 元素，toggle 'selected' class

**11. selectAutocompleteItem(index) 函数**（per D-13）：
- 获取 suggestion
- elements.urlInput.value = suggestion.url
- closeAutocomplete()
- 调用已有的 navigateToUrl(suggestion.url) 或模拟 Enter 键触发导航

**12. acceptInlineCompletion() 函数**（per D-08）：
- elements.urlInput.value += state.autocomplete.inlineText
- 清除 inlineText，隐藏 autocompleteInline
- closeAutocomplete()
- 光标移到末尾：setSelectionRange(value.length, value.length)

**13. openAutocomplete() / closeAutocomplete() 函数**：
- open：state.autocomplete.isOpen = true，dropdown.classList.add('visible')
- close：重置 isOpen、selectedIndex、inlineText，dropdown.classList.remove('visible')，隐藏 autocompleteInline

**14. 客户端缓存函数**：
- getCachedSuggestions(keyword)：检查 cache Map，支持更短前缀的缓存子集过滤
- cacheSuggestions(keyword, suggestions)：存入 cache，超过 50 条时删除最旧条目

**重要注意事项：**
- 现有的 urlInput keydown 监听器（第 4181 行）处理 Enter 键。新的 handleAutocompleteKeydown 需要在该监听器之前注册，或者修改现有监听器：当 isOpen 且 selectedIndex >= 0 时 e.preventDefault() 并处理选择，否则走原有导航逻辑。推荐方案：在 initAutocomplete 中注册新的 keydown 监听器，在其中处理补全相关的按键；现有监听器保持不变，但需要在 Enter 分支开头检查 `state.autocomplete.isOpen && state.autocomplete.selectedIndex >= 0`，如果是则 `return`（由补全监听器处理）。
- 使用 mousedown 而非 click 处理候选条目点击，因为 blur 事件会先于 click 触发导致下拉框关闭。
