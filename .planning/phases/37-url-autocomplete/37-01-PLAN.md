**autocomplete-manager.js — 新建文件（per D-01, D-04, D-05, D-06, D-16）：**

在项目根目录创建 `autocomplete-manager.js`，文件顶部添加 JSDoc 文件描述注释。

模块结构：
1. require 三个数据源管理器：`history-manager`、`favorites-manager`、`frequent-sites-manager`
2. LRU 缓存：`const cache = new Map()` + `const CACHE_MAX_SIZE = 100`
3. 缓存清理定时器：`setInterval` 每 30 秒清理超过 60 秒的缓存条目

核心函数 `getSuggestions(keyword, limit = 6)`：
- 检查缓存（keyword.toLowerCase() 为 key），命中则直接返回
- 查询三个数据源（per D-01）：
  - `favoritesManager.searchFulltext({ keyword, limit: 10 })` — 收藏夹（全局，per D-02）
  - `frequentSitesManager.searchFrequentSites(keyword, 10)` — 常用网站（全容器，per D-02）
  - `historyManager.searchAllContainers(keyword, 20)` — 历史记录（全容器，per D-02）
- 合并去重：按 URL 去重，收藏夹条目保留优先
- 排序（per D-04, D-06）：
  - 收藏夹来源的条目排在最前
  - 其余条目按 frecency 排序（frequent-sites 已有 frecencyScore，history 按 visited_at 排序）
- 截取 top limit 条
- 缓存结果
- 返回数组，每项格式：`{ url, title, faviconUrl, source }`（source 为 'favorite' | 'frequent' | 'history'）

辅助函数 `matchesKeyword(record, keyword)`（per D-05）：
- URL 去除协议后前缀匹配
- 标题子串匹配
- 返回 boolean

导出：`module.exports = { getSuggestions }`

**ipc-handlers.js — 新增 autocomplete:query 处理器（per D-03）：**

在文件顶部 require 区域新增：`const autocompleteManager = require('./autocomplete-manager');`

在 `registerHandlers` 函数内（`// ==================== 浏览历史 ====================` 之前），新增：
```
ipcMain.handle('autocomplete:query', (event, data) => {
  assertTrustedSender(event);
  if (!data || typeof data !== 'object' || typeof data.keyword !== 'string') {
    throw new Error('无效的查询参数');
  }
  return autocompleteManager.getSuggestions(data.keyword, data.limit || 6);
});
```
