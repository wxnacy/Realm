**第三步：在 src/renderer.js 实现删除逻辑（per D-12, D-13, D-14）**

1. 添加新 elements 引用：
   - deleteConfirmModal, deleteContainerPreview
   - cancelDeleteBtn, confirmDeleteBtn

2. 扩展 state 对象：
   - deletingContainerId: null（记录待删除的容器 ID）

3. 实现 showDeleteConfirmModal(containerId)：
   - 从 state.containers 查找容器
   - 如果 !container 或 container.id === 'default'，return（per D-13）
   - state.deletingContainerId = containerId
   - 更新 deleteContainerPreview 内容（使用 textContent 防止 XSS）：
     - 创建容器颜色圆点 div（style.backgroundColor = container.color）
     - 创建容器信息 span（textContent = container.icon + ' ' + container.name）
   - deleteConfirmModal.showModal()

4. 实现 confirmDeleteContainer()：
   - const containerId = state.deletingContainerId
   - 如果 !containerId，return
   - 调用 realmAPI.deleteContainer(containerId)
   - 如果 result.success：
     - 如果 containerId === state.currentContainer（per D-14）：
       - 调用 await switchContainer('default')
     - 调用 await loadContainers() 刷新面板
     - deleteConfirmModal.close()
   - 否则：
     - 显示错误信息（console.error）
   - state.deletingContainerId = null

5. 绑定删除确认按钮事件：
   - confirmDeleteBtn.addEventListener('click', confirmDeleteContainer)
   - cancelDeleteBtn.addEventListener('click', () => { deleteConfirmModal.close(); state.deletingContainerId = null; })

6. 点击 Modal 外部关闭：
   - deleteConfirmModal.addEventListener('click', (e) => { if (e.target === deleteConfirmModal) deleteConfirmModal.close(); })

7. 更新面板容器行的删除按钮逻辑（per D-13）：
   - 在 renderContainerPanelList() 中，对于 container.id === 'default' 的容器：
     - 删除按钮添加 disabled 属性
     - 添加 title="默认容器不可删除"（tooltip）
   - 在 panelContainerList 的 click 事件委托中，检查 target.classList.contains('btn-delete')
     - 如果 target.disabled，return
     - 调用 showDeleteConfirmModal(containerId)

8. 更新 Escape 键处理：
   - 在 keydown 事件中添加 deleteConfirmModal.close()

9. 清理旧的新建容器 Modal 引用：
   - 移除对旧 newContainerModal 的引用（已被 containerModal 替代）
   - 移除旧的 addContainerBtn 引用（sidebar 中的按钮已被面板头部的按钮替代）
