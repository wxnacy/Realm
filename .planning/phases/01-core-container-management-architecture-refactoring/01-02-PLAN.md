**第一步：在 src/renderer.js 实现编辑容器 Modal**

1. 实现 showEditContainerModal(containerId)：
   - 从 state.containers 查找容器：const container = state.containers.find(c => c.id === containerId)
   - 如果 !container，return
   - state.editingContainerId = containerId
   - containerNameInput.value = container.name
   - state.selectedColor = container.color
   - state.selectedIcon = container.icon
   - containerModalTitle.textContent = '编辑容器'
   - saveContainerBtn.textContent = '保存'
   - 调用 updateColorSelection() 和 updateEmojiSelection()
   - containerModal.showModal()

2. 更新表单提交逻辑，区分新建和编辑模式：
   - 如果 state.editingContainerId 不为 null（编辑模式）：
     - 调用 realmAPI.updateContainer(state.editingContainerId, { name, color: state.selectedColor, icon: state.selectedIcon })
   - 否则（新建模式）：
     - 调用 realmAPI.createContainer({ name, color: state.selectedColor, icon: state.selectedIcon })
   - 成功后关闭 Modal、调用 loadContainers() 刷新

3. 更新面板容器行的编辑按钮事件：
   - 在 panelContainerList 的 click 事件委托中，检查 target.classList.contains('btn-edit')
   - 如果是：调用 showEditContainerModal(containerId)

4. 验证逻辑更新（编辑模式下排除自身）：
   - 名称重复检查：state.containers.some(c => c.name === name && c.id !== state.editingContainerId)
