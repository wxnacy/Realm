在 favorites-manager.js 中新增以下函数，插入位置在 batchUpdateSort 函数之后、module.exports 之前：

前置步骤：安装 cheerio 依赖
- 运行 `npm install cheerio`（RESEARCH.md 已通过 Package Legitimacy Audit，12 年历史，20M+ 周下载量）

1. **normalizeUrl(url)** — URL 规范化函数（per D-08）
   - 使用 `new URL(url)` 解析
   - 去除 hostname 的 `www.` 前缀
   - 去除 pathname 末尾斜杠（长度 > 1 时）
   - 强制使用 `https://` 协议重新拼接
   - 解析失败时返回原始 URL

2. **detectChromeBookmarksPath()** — 自动检测 Chrome 书签路径（per D-03）
   - macOS: `path.join(app.getPath('home'), 'Library', 'Application Support', 'Google', 'Chrome', 'Default', 'Bookmarks')`
   - 使用 `fs.existsSync()` 检测文件是否存在
   - 存在时返回绝对路径，不存在时返回 `null`

3. **parseChromeJson(data)** — 解析 Chrome JSON 书签（per D-05, D-06, D-09）
   - 根文件夹映射：`{ bookmark_bar: 'Chrome 书签栏', other: 'Chrome 其他', synced: 'Chrome 已同步' }`（per D-05, D-06）
   - 递归遍历 `data.roots` 下三个根节点的 `children`
   - `type === 'folder'` 节点：收集 `{ name, parentPath, dateAdded }` 到 folders 数组
   - `type === 'url'` 节点：收集 `{ title: node.name, url: node.url, dateAdded, parentPath }` 到 bookmarks 数组
   - 返回 `{ bookmarks, folders }`
   - 节点格式异常时跳过并 `console.error` 记录（Claude's Discretion）

4. **parseNetscapeHtml(html)** — 解析 Netscape HTML 书签（per IMPORT-02）
   - 使用 `require('cheerio').load(html)` 加载 HTML
   - 递归解析 `<DL>` 下的 `<DT>` 节点
   - `<A>` 标签：收集 `{ title, url, dateAdded: attr('ADD_DATE'), parentPath }`
   - `<H3>` 标签：收集文件夹 `{ name, parentPath }`，递归解析下一个 `<DL>`
   - 返回 `{ bookmarks, folders }`

5. **batchInsertBookmarks(bookmarks, folderIdMap, onProgress)** — 批量插入（per D-07, D-13）
   - 使用 `db.prepare('INSERT OR IGNORE INTO favorites (url, title, favicon_url, folder_id, sort_order) VALUES (?, ?, ?, ?, ?)')`（per D-07 重复跳过）
   - 使用 `db.transaction()` 包裹批量操作
   - 每 100 条为一批，批次间调用 `onProgress({ progress, imported, skipped, total, current })`
   - 返回 `{ imported, skipped }`
   - 使用 `normalizeUrl()` 规范化 URL 后插入（per D-08）

6. **importChromeBookmarks(filePath, onProgress, abortSignal)** — Chrome JSON 导入入口（per D-03, D-04, D-05, D-09, D-10）
   - 如果 `filePath` 为空，调用 `detectChromeBookmarksPath()`，仍为空则返回 `{ success: false, needFileSelect: true }`（per D-04）
   - 使用 `fs.readFileSync(filePath, 'utf-8')` 读取文件，`JSON.parse()` 解析
   - 调用 `parseChromeJson(data)` 解析
   - 先创建根文件夹（使用现有 `createFolder()`），记录 `folderIdMap`（parentPath → folderId）
   - 再递归创建子文件夹
   - 最后调用 `batchInsertBookmarks()` 导入书签
   - favicon 获取（per D-15, D-16）：为每个书签异步获取 `https://www.google.com/s2/favicons?domain=${DOMAIN}&sz=16`，超时 3 秒或失败时传入空字符串（降级处理），不阻塞导入流程
   - 检查 `abortSignal.aborted` 实现取消（per IMPORT-03）
   - 返回 `{ success: true, imported, skipped, foldersCreated }`

7. **importHtmlBookmarks(filePath, onProgress, abortSignal)** — HTML 书签导入入口（per D-11, D-12）
   - 使用 `fs.readFileSync(filePath, 'utf-8')` 读取文件
   - 调用 `parseNetscapeHtml(html)` 解析
   - 创建文件夹结构，批量导入书签
   - 检查 `abortSignal.aborted` 实现取消
   - 返回 `{ success: true, imported, skipped, foldersCreated, preview: { total, folderCount, topFolders } }`（preview 供 D-12 使用）

在 module.exports 中新增导出：`parseChromeJson, parseNetscapeHtml, normalizeUrl, batchInsertBookmarks, detectChromeBookmarksPath, importChromeBookmarks, importHtmlBookmarks`。
