## Interaction Flow

### Flow A: Chrome JSON 自动导入 (IMPORT-01)

```
用户点击 [导入书签]
  |
  v
主进程检测 Chrome 默认路径 (D-03)
  |
  +-- 检测到 --> 显示进度模态框 --> 解析 JSON --> 逐条导入 --> 显示结果摘要
  |
  +-- 未检测到 --> 弹出文件选择对话框 (D-04)
                     |
                     +-- 用户选择 JSON --> 显示进度模态框 --> 解析 --> 导入 --> 结果
                     |
                     +-- 用户取消 --> 关闭，无操作
```

### Flow B: HTML 书签文件导入 (IMPORT-02)

```
文件选择对话框 (用户选择 .html 文件)
  |
  v
解析 HTML 书签 (Netscape Bookmark Format)
  |
  v
显示预览确认框 (D-11, D-12): 书签数、文件夹数、顶级文件夹列表
  |
  +-- [确认导入] --> 显示进度模态框 --> 逐条导入 --> 结果摘要
  |
  +-- [取消] --> 关闭，无操作
```

### Flow C: 取消导入 (IMPORT-03)

```
进度模态框显示中
  |
  v
用户点击 [取消]
  |
  v
主进程中止导入循环
  |
  v
显示部分结果摘要 (已导入 N 条，已取消)
```

## Favicon 获取降级策略

**Source:** CONTEXT.md D-15, D-16, Claude's Discretion

| Condition | Behavior |
|-----------|----------|
| favicon URL 可用 | 异步获取，存入数据库 |
| 获取超时 (3s) | 使用默认占位图标 (var(--bg-tertiary) 背景 + 首字母) |
| 获取失败 | 同上，静默降级，不中断导入 |

默认占位图标复用现有 `.favorite-item-favicon` 样式：20x20px, border-radius 4px, bg: var(--bg-tertiary), 文字: 首字母, color: var(--text-muted), font-size 12px。
