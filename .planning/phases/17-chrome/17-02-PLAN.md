3. 新增 `handleImportClick()` 函数：
   - 调用 `window.realmAPI.detectChromePath()` 检测 Chrome 路径（per D-03）
   - 如果返回 `{ path: string }` 且非 null：直接调用 `startChromeImport(chromePath)`
   - 如果返回 null：调用 `window.realmAPI.showOpenDialog({ title: '选择书签文件', filters: [{ name: '书签文件', extensions: ['html', 'htm', 'json'] }], properties: ['openFile'] })`（per D-04）
     - 用户取消时 return
     - 用户选择文件后，判断文件扩展名：
       - `.json` → 调用 `startChromeImport(filePath)`
       - `.html` / `.htm` → 调用 `startHtmlImport(filePath)`

4. 新增 `startChromeImport(filePath)` 函数：
   - 调用 `showImportModal('正在导入 Chrome 书签...')`（per D-13）
   - 注册进度监听：`window.realmAPI.onImportProgress(updateImportProgress)`
   - 调用 `const result = await window.realmAPI.importChromeBookmarks(filePath)`
   - 完成后清理：`window.realmAPI.removeImportProgressListener()`
   - 关闭进度模态框
   - 调用 `showImportResult(result)` 显示结果摘要（per D-17）
   - 如果 `result.success` 为 true：调用 `loadFavorites()` 和 `refreshFolderTree()` 刷新数据

5. 新增 `startHtmlImport(filePath)` 函数（per D-11）：
   - 先调用解析预览 API（在 favoritesApi 中添加 `parse-html-preview` 路由，或者直接调用 `importHtmlBookmarks` 获取 preview）
   - 实际实现：调用 `const result = await window.realmAPI.importHtmlBookmarks(filePath)` 获取 preview 数据
   - 如果 result.success 且有 preview 数据：调用 `showImportPreview(result.preview)`
   - 预览确认后调用 `showImportModal('正在导入书签...')`，重新执行导入（第二次调用时传入确认参数）

6. 新增 `showImportModal(title)` 函数（per D-13, D-14）：
   - 设置 `elements.importModalTitle.textContent = title`
   - 重置进度条为 0%
   - 设置 `elements.importProgressText.textContent = '准备导入...'`
   - 清空 `elements.importCurrentFile.textContent`
   - 调用 `elements.importModal.showModal()`

7. 新增 `updateImportProgress(data)` 函数：
   - `elements.importProgressBar.style.width = data.progress + '%'`
   - `elements.importProgressText.textContent = '已导入 ' + data.imported + ' / ' + data.total + ' 条书签'`
   - `elements.importCurrentFile.textContent = data.current ? '当前处理: ' + data.current : ''`

8. 新增 `handleImportCancel()` 函数（per IMPORT-03）：
   - 调用 `await window.realmAPI.abortImport()`
   - 关闭进度模态框
   - 显示 Toast：`showToast('导入已取消')`

9. 新增 `showImportPreview(preview)` 函数（per D-11, D-12）：
   - `elements.previewTotalCount.textContent = preview.total`
   - `elements.previewFolderCount.textContent = preview.folderCount`
   - 清空 `elements.previewFolderList`，遍历 `preview.topFolders` 创建 `<li>` 元素
   - 调用 `elements.importPreviewModal.showModal()`

10. 新增 `handlePreviewConfirm()` 函数：

    - 注册进度监听并执行导入（同 startChromeImport 流程）
