   - 批量事件通道为 `ai:events-batch`（per D-08）

3. **事件格式**：每个事件包含 `{ type, timestamp, payload }` 结构

4. **修改 `init()` 方法**：在创建 Agent 实例后调用 `this._setupEventBroadcasting()`

5. **修改 `prompt()` 方法**：移除内部的 subscribe 逻辑，因为事件广播已在 `_setupEventBroadcasting()` 中统一处理

实现代码结构：
```javascript
_setupEventBroadcasting() {
  let eventBatch = [];
  let batchTimer = null;

  this.agent.subscribe((event) => {
    const enrichedEvent = {
      ...event,
      timestamp: Date.now(),
    };

    if (event.type === 'message_update' || event.type === 'tool_execution_update') {
      eventBatch.push(enrichedEvent);
      if (!batchTimer) {
        batchTimer = setTimeout(() => {
          this._sendEventsBatch(eventBatch);
          eventBatch = [];
          batchTimer = null;
        }, 16);
      }
    } else {
      this._sendEventsBatch([enrichedEvent]);
    }
  });
}

_sendEventsBatch(events) {
  const win = windowManager.getMainWindow();
  if (win && !win.isDestroyed()) {
    win.webContents.send('ai:events-batch', { events });
  }
}
```
