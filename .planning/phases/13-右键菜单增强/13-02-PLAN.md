修改 src/renderer.js，添加右键菜单的渲染进程侧逻辑：

**A. 已关闭标签栈（closedTabsStack）**

在 renderer.js 的 state 对象或模块级变量中添加 `closedTabsStack = []`（LIFO，最多 10 条）。
修改现有的 `closeTab(tabId)` 函数，在关闭标签前将 `{ containerId, url, title }` 信息 push 到 closedTabsStack，同时调用 `window.realmAPI.notifyClosedTab(info)` 通知主进程。栈满时 shift() 移除最旧条目。

**B. Tab 栏右键监听**

在 Tab 栏事件委托区域（elements.tabList 的事件监听处），添加 `contextmenu` 事件监听：
- event.preventDefault() 阻止默认菜单
- 从 event.target 向上查找最近的 Tab 元素，提取 tabId
- 收集上下文信息：tabCount（state.tabs.size）、tabIndex（该 tab 在有序列表中的位置）、isPinned（tab.pinned）、hasClosedTabs（closedTabsStack.length > 0）
- 调用 `window.realmAPI.showTabContextMenu({ tabId, tabCount, tabIndex, isPinned, hasClosedTabs })`

**C. webview context-menu 事件监听**

在 webview 创建逻辑中（创建 webview 后），为每个 webview 添加 `context-menu` 事件监听：
```javascript
webview.addEventListener('context-menu', (e) => {
  const params = e.params || e.detail || {};
  const isImage = params.mediaType === 'image' || params.hasImageContents;
  const isLink = !!params.linkURL;
  const type = isImage ? 'image' : isLink ? 'link' : 'general';
  window.realmAPI.showWebContextMenu({
    type,
    linkURL: params.linkURL || '',
    srcURL: params.srcURL || '',
    mediaType: params.mediaType || 'none',
    selectionText: params.selectionText || '',
    canGoBack: webview.canGoBack(),
    canGoForward: webview.canGoForward(),
    isLoading: webview.isLoading(),
  });
});
```
注意：e.params 是 Electron webview context-menu 事件提供的标准属性。如果 e.params 不可用，尝试从 e.detail 获取（Electron 版本差异）。

**D. 菜单动作回调处理**

在 renderer.js 初始化区域（setupEventListeners 或 initApp 附近），调用 `window.realmAPI.onContextMenuAction((channel, data) => { ... })` 注册统一回调。根据 channel 分发处理：

- `context-menu:close-tab` → 调用现有 closeTab(data.tabId)
- `context-menu:close-other-tabs` → 遍历 state.tabs，关闭除 data.tabId 外的所有 tab
- `context-menu:close-left-tabs` → 找到 data.tabId 的位置，关闭其左侧所有 tab
- `context-menu:close-right-tabs` → 找到 data.tabId 的位置，关闭其右侧所有 tab
- `context-menu:reopen-tab` → 从 closedTabsStack pop 出最后关闭的标签信息，调用 createTab(containerId, url)
- `context-menu:toggle-pin` → 切换 tab.pinned 状态，调用 window.realmAPI.updateTab(tabId, { pinned: !tab.pinned })，调用 renderTabs() 重新渲染 Tab 栏（固定标签在最左侧，宽度缩小，显示固定图标）
- `context-menu:open-in-new-tab` → 调用 createTab(state.currentContainer, data.url)
- `context-menu:open-in-bg-tab` → 调用 createTab(state.currentContainer, data.url) 但不 switchTab 到新 tab
- `context-menu:open-in-container` → 调用 createTab(data.containerId, data.url)
- `context-menu:add-to-favorites` → 调用现有收藏添加逻辑（如 window.realmAPI.favoritesAdd）
- `context-menu:toast` → 调用现有 showToast(data.message, 'success')
- `context-menu:text-action` → 获取当前活动 webview，执行 webview.executeJavaScript 执行 document.execCommand(data.action)

**E. 固定标签页 UI 渲染**

在 Tab 栏渲染逻辑中（renderTabs 或类似函数），为固定标签添加特殊处理：
- 固定标签排在 Tab 栏最左侧
- 固定标签宽度缩小（只显示 favicon + 关闭按钮，不显示标题文字）
- 固定标签添加视觉标识（如小固定图标或特殊背景色）
- 标签数据结构中 tab.pinned 字段默认 false（惰性填充，旧数据兼容）

**F. 关闭标签时维护 closedTabsStack**

在 closeTab 函数中，关闭前将当前 tab 的信息保存：
```javascript
const tab = state.tabs.get(tabId);
if (tab) {
  closedTabsStack.push({ containerId: tab.containerId, url: tab.url, title: tab.title });
  if (closedTabsStack.length > 10) closedTabsStack.shift();
  window.realmAPI.notifyClosedTab({ containerId: tab.containerId, url: tab.url, title: tab.title });
}
```
