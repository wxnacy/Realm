# Phase 13 — UI Design Contract

---

## Design System

| Property | Value |
|----------|-------|

| Preset | not applicable |
| Component library | none (system native) |

## Menu Structure Contract

### 1. Tab Context Menu

Triggered by: right-click on Tab bar element (detected via DOM event in renderer.js, forwarded to main process via IPC).

| # | Label | Accelerator (macOS) | Enabled When | Icon | Notes |
|---|-------|---------------------|--------------|------|-------|
| 1 | 关闭标签页 | Cmd+W | always | native close icon | Closes the right-clicked tab |
| 2 | 关闭其他标签页 | — | tab count > 1 | — | Closes all tabs except right-clicked |
| 3 | 关闭左侧标签页 | — | has tabs to the left | — | Closes all tabs left of right-clicked |
| 4 | 关闭右侧标签页 | — | has tabs to the right | — | Closes all tabs right of right-clicked |
| **— separator —** | | | | | |
| 5 | 重新打开已关闭标签页 | Cmd+Shift+T | closedTabs stack non-empty | — | Reopens last closed tab |
| **— separator —** | | | | | |
| 6 | 固定标签页 / 取消固定 | — | always | — | Toggle: label changes based on pinned state |

**Disabled state:** Items 2-4 use Electron's `enabled: false` to show grayed-out when not applicable (e.g., only 1 tab open).

### 5. Container Selection Submenu

Appears under: "在新容器标签页中打开" in Link Context Menu.

| Item label: `{container.emoji} {container.name}` | Emoji + name from container config |

| Click action: open link URL in new tab with specified container | Uses existing `createTab` with containerId |

## Menu Interaction Rules

### Behavior (D-19, D-22)

| Rule | Specification |
|------|---------------|
| Auto-close | Menu closes after any item click (OS default behavior) |
| Right-click dismiss | Right-clicking elsewhere dismisses the current menu |
| Keyboard navigation | Arrow keys navigate, Enter selects, Escape dismisses (OS default) |
| Item ordering | Follow Chrome browser's exact menu item order (D-22) |
| Separator grouping | Use Electron `{ type: 'separator' }` between logical groups (D-09) |
| Submenu arrow | Container selection submenu shows OS-native arrow indicator |

### Disabled State (D-08)

| Rule | Specification |
|------|---------------|
| Visual | Grayed out text, non-interactive (OS native disabled style) |
| Implementation | `{ enabled: false }` in Electron menu template |
| Cursor | OS default (no pointer change on disabled items) |

## IPC Channel Contract

New IPC channels required for menu communication between renderer and main process.

### Renderer → Main (context menu requests)

| Channel | Payload | Description |
|---------|---------|-------------|
| `show-tab-context-menu` | `{ tabId, tabCount, tabIndex, isPinned, hasClosedTabs }` | Tab bar right-click |
| `show-web-context-menu` | `{ type, linkURL, srcURL, mediaType, selectionText, canGoBack, canGoForward, isLoading }` | Web page right-click |

### Main → Renderer (menu action callbacks)

| Channel | Payload | Description |
|---------|---------|-------------|
| `context-menu:close-tab` | `{ tabId }` | Close specific tab |
| `context-menu:close-other-tabs` | `{ tabId }` | Close all except specified |
| `context-menu:close-left-tabs` | `{ tabId }` | Close tabs left of specified |
| `context-menu:close-right-tabs` | `{ tabId }` | Close tabs right of specified |
| `context-menu:reopen-tab` | `{}` | Reopen last closed tab |
| `context-menu:toggle-pin` | `{ tabId }` | Toggle tab pin state |
| `context-menu:open-in-new-tab` | `{ url }` | Open URL in new tab |
| `context-menu:open-in-bg-tab` | `{ url }` | Open URL in background tab |
| `context-menu:open-in-container` | `{ url, containerId }` | Open URL in specific container tab |
| `context-menu:save-image` | `{ url }` | Save image to disk |
| `context-menu:copy-image` | `{ url }` | Copy image to clipboard |
| `context-menu:copy-image-address` | `{ url }` | Copy image URL to clipboard |
| `context-menu:copy-link-address` | `{ url }` | Copy link URL to clipboard |
| `context-menu:navigate-back` | `{}` | Webview go back |
| `context-menu:navigate-forward` | `{}` | Webview go forward |
| `context-menu:reload` | `{}` | Webview reload |
| `context-menu:stop-loading` | `{}` | Webview stop |
| `context-menu:save-page` | `{}` | Save page as |
| `context-menu:print` | `{}` | Print page |
| `context-menu:add-to-favorites` | `{}` | Add to favorites |
| `context-menu:view-source` | `{}` | View page source |
| `context-menu:inspect-element` | `{}` | Open DevTools |
| `context-menu:text-action` | `{ action }` | Text action (cut/copy/paste/selectAll) |

## Preload API Extension

New methods to expose in `src/preload.js` via `contextBridge.exposeInMainWorld`:

```javascript
// Tab context menu
showTabContextMenu: (tabInfo) => ipcRenderer.send('show-tab-context-menu', tabInfo),

// Web context menu
showWebContextMenu: (contextInfo) => ipcRenderer.send('show-web-context-menu', contextInfo),

// Listen for menu actions
onContextMenuAction: (callback) => {
  const channels = [
    'context-menu:close-tab',
    'context-menu:close-other-tabs',
    // ... all channels listed above
  ];
  channels.forEach(channel => {
    ipcRenderer.on(channel, (event, data) => callback(channel, data));
  });
},
```
