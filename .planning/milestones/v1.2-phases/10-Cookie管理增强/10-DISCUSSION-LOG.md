## Cookie 面板布局 — 模态框 vs 全页面？

| Option | Description | Selected |
|--------|-------------|----------|
| 保持模态框（增强版） | 保持当前模态框形式，增加滚动区域和工具栏。优点：轻量、快速访问；缺点：空间有限，复杂编辑体验较差 | ✓ |
| 改为全页面（realm://cookies） | 类似历史记录页面，独立全页面显示。优点：空间充足，编辑体验好；缺点：需要离开当前页面 | |
| 双层模态框 | 主界面保持模态框，点击编辑时弹出新模态框。优点：平衡空间和便捷性；缺点：多层模态框可能混乱 | |

**User's choice:** 保持模态框（增强版）
**Notes:** 用户希望保持轻量级的模态框形式，但增加功能密度

**Notes:** 用户选择清晰的三段式布局，便于功能分区

## Cookie 列表数据量处理

| Option | Description | Selected |
|--------|-------------|----------|
| 分页显示（每页 20-30 条） | 添加分页控件，每页显示 20-30 个 Cookie。优点：性能好；缺点：需要翻页 | ✓ |
| 滚动加载（全部显示） | 显示所有 Cookie，用滚动条浏览。优点：连续浏览；缺点：Cookie 数量多时性能差 | |
| 虚拟滚动（按需渲染） | 类似虚拟滚动，只渲染可见区域。优点：性能好且连续浏览；缺点：实现复杂 | |

**User's choice:** 分页显示（每页 20-30 条）
**Notes:** 用户选择分页方式处理大量数据，平衡性能和用户体验

## 数据来源切换 — 切换控件样式？

| Option | Description | Selected |
|--------|-------------|----------|
| 标签页切换 | 两个标签页：Session（实时）和 File（持久化）。点击切换数据来源 | ✓ |
| 开关按钮（Toggle） | 单个开关按钮，在 Session 和 File 之间切换。简洁但不直观 | |
| 下拉菜单 | 下拉菜单选择数据来源。可扩展性强，但多一步操作 | |

**User's choice:** 标签页切换
**Notes:** 用户选择标签页，因为它最直观地展示两个数据源

## 数据展示方式

| Option | Description | Selected |
|--------|-------------|----------|
| 独立视图（各自显示） | Session 标签页显示实时 Cookie，File 标签页显示文件中的 Cookie。两个视图完全独立 | ✓ |
| 差异对比视图 | Session 视图为主，File 视图显示差异（新增、删除、修改的 Cookie） | |
| 快照对比 + 差异高亮 | Session 视图显示实时数据，File 视图显示上次保存的快照，用颜色标记差异 | |

**User's choice:** 独立视图（各自显示）
**Notes:** 用户选择简单直接的独立视图，避免复杂的差异对比逻辑

## 数据加载策略

| Option | Description | Selected |
|--------|-------------|----------|
| 切换时加载（懒加载） | 切换标签页时立即加载对应数据源的 Cookie。简单直接 | ✓ |
| 预加载两个数据源 | 打开模态框时同时加载两个数据源，切换标签页时直接显示。快速但初始加载慢 | |
| 首次加载 + 缓存 | 首次切换时加载，之后缓存结果。平衡性能和实时性 | |

**User's choice:** 切换时加载（懒加载）
**Notes:** 用户选择懒加载，避免不必要的资源消耗

## 域名过滤 — 交互方式？

| Option | Description | Selected |
|--------|-------------|----------|
| 自动检测当前域名 | 自动检测当前标签页的域名，显示该域名及其子域名的 Cookie | ✓ |
| 手动输入域名 | 输入框手动输入域名进行过滤。灵活但需要用户操作 | |

**User's choice:** 自动检测当前域名
**Notes:** 用户希望减少手动操作，自动检测更便捷

## 保存策略

| Option | Description | Selected |
|--------|-------------|----------|
| 保存按钮立即更新 | 点击保存按钮后立即更新 Session 和文件。简单直接 | ✓ |
| 自动保存（失焦或延迟） | 编辑后自动保存，无需点击保存按钮。快速但可能误操作 | |
| 预览 + 确认保存 | 显示预览效果，确认后保存。安全但多一步操作 | |

**User's choice:** 保存按钮立即更新
**Notes:** 用户选择明确的保存操作，避免误操作
