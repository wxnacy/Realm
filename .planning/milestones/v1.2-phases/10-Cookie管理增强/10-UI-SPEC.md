## Interaction Specification

### Source Tab Switching (D-05, D-07, D-08)

| Trigger | Action | Feedback |
|---------|--------|----------|
| Click "Session (实时)" tab | Load Session cookies via IPC, replace list content | Tab becomes active (accent bottom border), loading spinner if >200ms |
| Click "File (持久化)" tab | Load File cookies from JSON, replace list content | Tab becomes active, loading spinner if >200ms |
| Switch tab while loading | Cancel previous request, start new load | No stale data flash |

**Lazy loading (D-08):** Only fetch data for the active tab. Switching tabs triggers a fresh fetch. No pre-loading of the inactive tab.

### Domain Filter (D-09, D-10, D-11, D-12)

| Trigger | Action | Feedback |
|---------|--------|----------|
| Modal opens | Auto-detect current tab domain, default filter = "含子域名" | Filter chip pre-selected |
| Click filter toggle button | Expand/collapse filter options row | Chevron icon rotates |
| Click "仅当前域名" | Filter list to exact domain match | Chip becomes active, list refreshes |
| Click "含子域名" | Filter list to domain + subdomains | Chip becomes active, list refreshes |
| Click "全部" | Remove filter, show all cookies | Chip becomes active, list refreshes |

**Default (D-12):** "包含子域名" is pre-selected on modal open.

### Cookie List (D-04)

| Trigger | Action | Feedback |
|---------|--------|----------|
| List loads | Display first page of cookies | Items render with fade-in |
| Click page number | Navigate to that page | List scrolls to top, items update |
| Click "<" or ">" | Navigate to prev/next page | Disabled state when at first/last page |
| List empty | Show empty state | Icon + copy per copywriting contract |

**Pagination (D-04):** 25 items per page. Pagination controls centered below list. Total count displayed on the right.

**Sorting (Claude's Discretion):** Default sort by domain (A-Z), then by cookie name (A-Z) within each domain group.

### Cookie Edit (D-13, D-14, D-15, D-16)

| Trigger | Action | Feedback |
|---------|--------|----------|
| Click "编辑" on cookie row | Open edit modal with cookie data pre-filled | Modal slides in |
| Edit fields and click "保存" | Validate, call IPC to update Session + File | Modal closes, success toast "Cookie 已更新", list refreshes |
| Click "取消" or [X] | Close edit modal without saving | Modal closes, no state change |
| Validation fails (empty name) | Highlight invalid field with red border | Error message below field |
| Save fails | Show error toast | Toast: "保存失败，请重试" |

**Editable fields (D-14):** name, value, domain, path, expirationDate, secure (checkbox), httpOnly (checkbox), sameSite (select: Strict/Lax/None).

### Cookie Delete

| Trigger | Action | Feedback |
|---------|--------|----------|
| Click "删除" on cookie row | Show confirmation dialog | Dialog: "确定要删除此 Cookie 吗？此操作不可撤销。" |
| Confirm delete | Call IPC to remove from Session + File | Dialog closes, success toast "Cookie 已删除", list refreshes |
| Cancel delete | Close confirmation dialog | No state change |

### Save to File (D-15)

| Trigger | Action | Feedback |
|---------|--------|----------|
| Click "保存到文件" | Save current domain + subdomain cookies to file (merge mode) | Success toast "Cookie 已保存到文件" |
| Save fails | Show error toast | Toast: "保存失败，请重试" |

### Clear All Cookies

| Trigger | Action | Feedback |
|---------|--------|----------|
| Click "清除所有 Cookie" | Show confirmation dialog | Dialog: "确定要清除所有 Cookie 吗？此操作不可撤销。" |
| Confirm clear | Call IPC to clear all cookies from Session | Dialog closes, success toast "所有 Cookie 已清除", list refreshes to empty state |

## State Definitions

### Modal States

| State | Condition | Visual |
|-------|-----------|--------|
| Loading | Data fetch in progress | Spinner overlay on list area, skeleton rows (3x gray bars) |
| Populated | Cookies exist for current filter | Full list with pagination |
| Empty | No cookies match filter/criteria | `.cookies-empty` with icon + copy |
| Error | IPC fetch fails | Red toast notification, list shows last known state |

### Source Tab States

| State | Visual |
|-------|--------|
| Active | Text: `var(--text-primary)`, bottom border: `2px solid var(--accent-color)` |
| Inactive | Text: `var(--text-secondary)`, bottom border: none |
| Loading | Tab text + small spinner icon replacing tab label temporarily |

### Filter Chip States

| State | Visual |
|-------|--------|
| Active | Background: `var(--accent-color)`, text: white |
| Inactive | Background: `var(--bg-tertiary)`, text: `var(--text-secondary)` |
| Hover | Background: `var(--bg-hover)` (inactive) or `var(--accent-hover)` (active) |

### Pagination States

| State | Visual |
|-------|--------|
| Current page | Background: `var(--accent-color)`, text: white, border-radius: 6px |

## Accessibility

- **Keyboard navigation:** All interactive elements (tabs, filter chips, buttons, pagination) must be reachable via Tab key and activatable via Enter/Space.
- **Focus indicators:** Focus ring (`outline: 2px solid var(--accent-color)`) on all focusable elements.
- **ARIA attributes:** Source tabs use `role="tablist"` / `role="tab"` / `aria-selected`. Pagination uses `aria-label="页码导航"`.
- **Screen reader:** Cookie edit modal fields have associated `<label>` elements. Delete confirmation dialog has `role="alertdialog"`.
