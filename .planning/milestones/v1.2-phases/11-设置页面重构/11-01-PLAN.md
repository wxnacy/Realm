路由设计：
- `GET /api/rules/list` → `assignmentRules.getRules()`
- `POST /api/rules/create` → body: `{containerId, pattern}` → `assignmentRules.createRule(containerId, pattern)`
- `POST /api/rules/update` → body: `{ruleId, updates}` → `assignmentRules.updateRule(ruleId, updates)`
- `POST /api/rules/delete` → body: `{ruleId}` → `assignmentRules.deleteRule(ruleId)`
- `POST /api/rules/reorder` → body: `{orderedIds}` → `assignmentRules.reorderRules(orderedIds)`
- `GET /api/rules/export` → `assignmentRules.exportRules()`，返回 JSON 数据（不在 HTTP 端点打开文件对话框）
- `POST /api/rules/import` → body: `{rules: [...]}` → `assignmentRules.importRules(rules)`

实现模式：参照现有 `handleSettingsApi` 函数的结构：
- 入口函数签名：`async function handleRulesApi(req, res, reqUrl)`
- 开头做 token 鉴权：`if (reqUrl.searchParams.get('token') !== REALM_TOKEN) { sendJson(res, 403, { error: 'Forbidden' }); return; }`
- 用 `reqUrl.pathname.replace('/api/rules/', '')` 提取 route
- 用 if/else 匹配 route + req.method
- POST 请求用 `await readJsonBody(req)` 解析 body
- 用 `sendJson(res, 200, data)` 返回响应
- 外层 try/catch，catch 中 `console.error('[Realm] 规则 API 处理失败:', err.message)` + `sendJson(res, 400, { error: err.message })`
