# Milestone v2.1: AI CDP 增强 + Tabbrowser 功能集成

**Status:** ✅ SHIPPED 2026-08-04
**Phases:** 22-25
**Total Plans:** 18

## Overview

为 AI Agent 增加深度浏览器控制能力 — 从只能调用 5 个基础工具升级为能深度操控网页内容、引用标签页上下文、自动执行任务、生成脚本和智能整理标签页。

## Milestone Summary

**Key Decisions:**

- AI 调试器与 DevTools 共存（Electron 允许双 debugger）
- 容器校验数据源切换为 getContainersLazy() 内存权威数据
- 职责重叠工具取删除而非复用实现（navigate 移除，open_link 唯一入口）
- 截断阈值采用字符语义（102,400 字符），契约/标记/UAT 三处统一
- 确认响应单一权威通道：ai-manager 委托 main.js pendingActions 注入
- Input.insertText 前合成点击落位输入管线焦点 + readback 裁决兜底
- 脚本操作白名单独立于 execute_action（13 种安全操作）
- 标签分组策略参数化（domain/semantic/mixed，默认 semantic）

**Issues Resolved:**

- Phase 22: 22-04/22-05 两轮 gap 修复（容器校验数据源、幽灵 Tab、字符截断语义）
- Phase 24: G-24-4 确认响应通道统一、G-24-2b 输入焦点管线修复
- Phase 25: G-25-23 apply_tab_groups 回传 + 卡片渲染链路打通

**Technical Debt Incurred:**

- 13 个已诊断 debug session 未修复（从 v2.0 延续）
- 1 个 UAT 差距（Phase 18，0 个待处理场景）
