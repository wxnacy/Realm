## 面板形态与布局

### Q1: 面板形态

| Option | Description | Selected |
|--------|-------------|----------|
| 浮动弹出面板 | 覆盖在页面上方的浮动面板，点击外部关闭。类似 Chrome DevTools 的 Coverage 面板或浏览器下载弹窗。轻量、不占侧边空间。 | ✓ |
| 右侧侧边抽屉 | 类似现有 AI 面板，从右侧滑出的抽屉。宽度可调，持久显示。但与 AI 面板同时打开时可能冲突。 | |
| 底部面板 | 面板固定在浏览器窗口底部，类似 Chrome DevTools 的 Console。横向展示媒体列表，不遮挡页面内容。 | |

**User's choice:** 浮动弹出面板（推荐）

### Q2: 面板位置

| Option | Description | Selected |
|--------|-------------|----------|
| 靠近按钮弹出 | 面板从工具栏媒体按钮下方弹出，靠近按钮位置。用户视线移动距离最短，类似 Chrome 扩展弹窗。 | ✓ |
| 窗口居中 | 面板居中显示在浏览器窗口中央，类似模态框。醒目但遮挡页面内容较多。 | |

**User's choice:** 靠近按钮弹出（推荐）

### Q3: 关闭方式

| Option | Description | Selected |
|--------|-------------|----------|
| 点击外部关闭 | 点击面板外部区域自动关闭，同时保留关闭按钮。简单直观，大多数弹出面板的标准行为。 | ✓ |
| 仅按钮关闭 | 只能通过关闭按钮或再次点击工具栏按钮关闭。防止误触关闭，但需要额外操作。 | |

**User's choice:** 点击外部关闭（推荐）

### Q4: 面板尺寸

| Option | Description | Selected |
|--------|-------------|----------|
| 固定尺寸 | 宽度固定约 360px，高度自适应（最大 500px 后滚动）。简单一致，无需拖拽调整。 | ✓ |
| 可拖拽调整 | 用户可以拖拽面板边缘调整大小，类似 AI 面板。灵活但增加实现复杂度。 | |

**User's choice:** 固定尺寸（推荐）

## 媒体列表项展示

### Q5: 列表项信息

| Option | Description | Selected |
|--------|-------------|----------|
| 紧凑列表 | 类型徽标（m3u8/mp4）+ 标题或文件名 + URL 预览（截断）。最小化设计，信息密度高。 | ✓ |
| 带缩略图卡片 | 左侧缩略图 + 右侧标题/URL/类型。视觉更丰富，但媒体嗅探不一定能获取缩略图。 | |
| 详情列表 | 大字体标题 + 类型徽标 + 完整 URL。每项占更多空间，信息最完整。 | |

**User's choice:** 紧凑列表（推荐）

### Q6: 类型徽标

| Option | Description | Selected |
|--------|-------------|----------|
| 颜色编码 | 用不同颜色区分类型：m3u8=蓝、mp4=绿、flv=橙、webm=紫。直观但增加颜色认知负担。 | ✓ |
| 统一灰色文字 | 统一灰色徽标，纯文字显示类型名（m3u8、mp4 等）。简洁一致，不增加颜色。 | |

**User's choice:** 颜色编码

### Q7: 空状态

| Option | Description | Selected |
|--------|-------------|----------|
| 提示文字 | 显示一条提示文字，如"当前页面未检测到媒体资源"。简洁明了。 | ✓ |
| 图标+提示文字 | 显示一个空状态图标 + 提示文字。视觉更丰富但多一个图标资源。 | |

**User's choice:** 提示文字（推荐）

### Q8: URL 展示

| Option | Description | Selected |
|--------|-------------|----------|
| 仅文件名 | 显示文件名部分（最后一段路径），如 video.m3u8。简洁但可能丢失域名信息。 | |
| 域名+文件名 | 显示域名 + 文件名，如 example.com/video.m3u8。多一点上下文。 | ✓ |
| 完整 URL（截断） | 显示完整 URL，超长时用省略号截断。信息最全但占空间。 | |

**User's choice:** 域名+文件名

## 工具栏按钮与徽标

### Q9: 按钮图标

| Option | Description | Selected |
|--------|-------------|----------|
| 播放图标 | 使用播放三角形图标（▶），直观关联媒体/视频。与现有工具栏按钮风格一致的 SVG 图标。 | ✓ |
| 胶片图标 | 使用胶片/电影图标（🎞️），表示媒体资源。更抽象但区分度高。 | |
| 媒体图标 | 使用音乐/媒体图标（🎵），表示多媒体内容。但当前只检测视频，可能造成误解。 | |

**User's choice:** 播放图标（推荐）

### Q10: 数量徽标

| Option | Description | Selected |
|--------|-------------|----------|
| 右上角角标 | 按钮右上角显示小圆点+数字（如 3），红色背景白色文字。类似 App 角标，醒目但不遮挡图标。 | ✓ |
| 按钮右侧数字 | 按钮右侧显示数字标签（如 ▶ 3），不遮挡图标。但占额外空间。 | |
| 仅红点 | 只显示红点，不显示数字。最简洁但用户不知道具体数量。 | |

**User's choice:** 右上角角标（推荐）

### Q11: 按钮位置

| Option | Description | Selected |
|--------|-------------|----------|
| 工具栏右侧 | 放在工具栏右侧，与 AI 面板按钮相邻。功能入口集中，用户容易找到。 | ✓ |
| URL 框左侧 | 放在 URL 输入框左侧，与前进后退按钮相邻。但可能增加工具栏拥挤感。 | |

**User's choice:** 工具栏右侧（推荐）

## 交互行为细节

### Q12: 播放行为

| Option | Description | Selected |
|--------|-------------|----------|
| 新窗口播放 | 在新窗口中打开播放器（Phase 28 实现）。面板保持打开，用户可继续浏览媒体列表。 | |
| 面板内播放 | 在当前页面中内嵌播放视频。但会遮挡页面内容，且 m3u8/flv 需要额外播放器库。 | |

**User's choice:** 在新标签中打开页面播放（用户自定义）

### Q13: 复制反馈

| Option | Description | Selected |
|--------|-------------|----------|
| 图标变化 | 复制成功后按钮图标短暂变为勾选图标（✓），1.5 秒后恢复。不占额外空间，反馈明确。 | ✓ |
| 底部提示条 | 复制成功后在面板底部显示"已复制"提示条，1 秒后消失。更醒目但需要额外 UI。 | |

**User's choice:** 图标变化（推荐）

### Q14: 实时更新

| Option | Description | Selected |
|--------|-------------|----------|
| 自动更新 | 面板打开时，新检测到的媒体自动添加到列表底部，无需手动刷新。Phase 26 已实现 onMediaListUpdate 推送机制。 | ✓ |
| 手动刷新 | 面板内显示刷新按钮，用户手动点击刷新列表。但降低实时性。 | |

**User's choice:** 自动更新（推荐）
