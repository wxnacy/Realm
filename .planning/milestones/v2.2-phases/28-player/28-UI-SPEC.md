# Phase 28 — 播放器窗口 UI Design Contract

> Visual and interaction contract for the player window. Generated by gsd-ui-researcher.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (vanilla HTML/CSS/JS, Electron BrowserWindow) |
| Preset | not applicable |
| Component library | none |
| Icon library | inline SVG (player controls) |
| Font | -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif |

**Note:** 播放器窗口为独立 BrowserWindow，不复用主窗口 main.css。播放器拥有独立的 player.css 样式文件，但使用相同的 font-family 保持品牌一致。

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | 控件图标内边距、进度条手柄与轨道间距 |
| sm | 8px | 控制栏按钮间距、时间文字与进度条间距 |
| md | 16px | 控制栏内边距、控制栏与窗口底部间距 |
| lg | 24px | 控制栏左右两组与窗口边缘间距 |
| xl | 32px | 未使用 |
| 2xl | 48px | 控制栏整体高度（含进度条） |
| 3xl | 64px | 未使用 |

Exceptions:
- 进度条拖拽手柄: 12px 圆形（非 4 的倍数，交互热区需要）
- 自定义窗口标题栏按钮: 12x12px（关闭/最小化/最大化，非 4 的倍数，macOS 风格）

## Component Inventory

### 1. 播放器窗口 (BrowserWindow)

**结构:**
```
┌──────────────────────────────────────────┐
│ [● ○ ○]                    (自定义标题栏) │  ← 28px, frameless
├──────────────────────────────────────────┤
│                                          │
│                                          │
│              <video>                     │  ← 视频主体
│                                          │
│                                          │
├──────────────────────────────────────────┤
│ ░░░░░░░░████████░░░░░░░░░░░░░ 00:00    │  ← 进度条 (全宽)
├──────────────────────────────────────────┤
│ ▶  00:00 / 00:00      🔊 ━━━  1x  ⛶   │  ← 控制栏
└──────────────────────────────────────────┘
```

**窗口配置:**
- frame: false (无边框, D-04)
- 默认尺寸: 960x540 (16:9, D-19)
- minWidth: 480, minHeight: 270
- backgroundColor: #000000
- titleBarStyle: 'hidden' (macOS 红绿灯)
- resizable: true
- 全屏: 通过 BrowserWindow.setFullScreen() 切换

### 2. 自定义标题栏

**元素:**
- macOS 红绿灯按钮（关闭/最小化/最大化），12px 圆形，间距 8px
- 颜色: 关闭 #FF5F57, 最小化 #FEBC2E, 最大化 #28C840
- 悬停显示图标（✕ / ─ / ⤢），默认只显示圆点
- 窗口标题：当前视频名称（截断，max-width 50%）

**交互:**
- 点击关闭：销毁窗口 + 清理资源 (D-21)
- 点击最小化：窗口最小化
- 点击最大化：切换最大化/还原
- 标题栏区域支持拖拽移动窗口（-webkit-app-region: drag）
- 按钮区域排除拖拽（-webkit-app-region: no-drag）

### 3. 进度条

**布局:** 全宽，位于视频底部，控制栏上方

**元素:**
- 轨道: 高度 3px，悬停展开至 5px，颜色 rgba(255,255,255,0.2)
- 已播放: 高度同轨道，颜色 #3B82F6
- 缓冲: 高度同轨道，颜色 rgba(255,255,255,0.3)
- 拖拽手柄: 12px 圆形，颜色 #fff，悬停/拖拽时出现，缩放动画

**交互 (D-11, D-15):**
- 点击轨道：跳转到点击位置
- 拖拽手柄：实时预览，视频画面跟随更新
- 悬停轨道：显示时间戳预览气泡（HH:MM:SS 格式），无缩略图
- 拖拽时：进度条展开至 5px，手柄始终可见

### 4. 控制栏

**布局 (D-02):** 底部固定，左右分组

```
┌─────────────────────────────────────────────────────────┐
│  ▶/⏸   00:00 / 00:00          🔊━━  1x  ⊡  ⛶  ⊞  │
│  [左组]                        [右组]                   │
└─────────────────────────────────────────────────────────┘
```

**左组元素:**
- 播放/暂停按钮: 24x24px SVG icon
- 时间显示: "00:00 / 00:00" (HH:MM:SS, D-18)

**右组元素:**
- 音量按钮: 24x24px SVG icon（点击静音, D-12 M键）
- 音量滑块: 宽度 80px，高度 3px，悬停展开
- 倍速按钮: 显示当前倍速 "1x"，点击弹出选择菜单 (D-17)
- 画中画按钮: 24x24px SVG icon (D-14)
- 全屏按钮: 24x24px SVG icon (D-09, F键)

**背景:** 渐变遮罩，从 transparent 到 rgba(0,0,0,0.7)，高度 120px

**交互 (D-03):**
- 鼠标静止 3 秒：控制栏 + 标题栏淡出（opacity 1→0, 0.3s ease）
- 鼠标移动：淡入（opacity 0→1, 0.15s ease）
- 隐藏时：仅保留进度条细线（高度 3px，rgba(255,255,255,0.2)）
- 全屏模式下鼠标移至屏幕底部：触发显示

### 5. 倍速选择菜单

**触发:** 点击倍速按钮

**选项 (D-17):**
- 0.5x
- 1x (默认)
- 1.5x
- 2x

**样式:**
- 背景: rgba(0, 0, 0, 0.85)
- 圆角: 4px
- 每项高度: 32px，padding: 0 16px
- 当前选项: #3B82F6 高亮
- 悬停: rgba(255, 255, 255, 0.1)
- 位置: 弹出在倍速按钮上方

### 6. 播放列表控制

**元素:**
- 上一个按钮: 24x24px SVG icon
- 下一个按钮: 24x24px SVG icon

**位置:** 控制栏左组，播放/暂停按钮右侧

**交互 (D-16):**
- 点击上一个/下一个：切换到媒体列表中的相邻视频
- 列表首项时：上一个按钮 disabled (opacity 0.3)
- 列表末项时：下一个按钮 disabled (opacity 0.3)

### 7. 播放按钮覆盖层

**位置:** 视频区域正中央

**元素:** 大尺寸播放按钮（暂停状态时显示）

**交互:**
- 视频暂停时：显示（opacity 1, 0.2s fade in）
- 视频播放时：隐藏（opacity 0, 0.15s fade out）
- 点击：切换播放/暂停

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | 播放 (▶) |
| 时间显示格式 | 00:00 / 00:00 (HH:MM:SS，不足1小时不显示小时位) |
| 倍速按钮 | 当前倍速值 + "x"（如 "1x", "1.5x"） |
| 悬停时间预览 | HH:MM:SS |
| 无视频源错误 | 无法播放 — 不支持的视频格式 |
| 播放列表边界 | 首项/末项时按钮置灰，无额外提示文案 |
| 窗口标题 | 视频文件名或 URL 路径末段 |

## Animation & Transition Contract

| Element | Property | Value | Trigger |
|---------|----------|-------|---------|
| 控制栏 | opacity | 1 → 0, 0.3s ease | 鼠标静止 3s |
| 控制栏 | opacity | 0 → 1, 0.15s ease | 鼠标移动 |
| 进度条轨道 | height | 3px → 5px, 0.15s ease | 悬停/拖拽 |
| 拖拽手柄 | transform | scale(0) → scale(1), 0.15s ease | 悬停进度条 |
| 播放按钮覆盖 | opacity | 0 → 1, 0.2s ease | 视频暂停 |
| 播放按钮覆盖 | opacity | 1 → 0, 0.15s ease | 视频播放 |
| 标题栏 | opacity | 1 → 0, 0.3s ease | 鼠标静止 3s（同控制栏） |
| 倍速菜单 | opacity + transform | 0 → 1, translateY(4px) → 0, 0.15s | 点击倍速按钮 |
