   - 更新 state.mediaPlayer
   - 调用 updateMediaPlayerUI(enabled) 更新 toggle 状态
   - 调用 renderWhitelistTags() 渲染白名单标签

5. 新增 saveMediaPlayerEnabled 函数（per D-04 即时生效）：
   - 调用 settingsApi('update', { method: 'POST', body: JSON.stringify({ 'mediaPlayer.enabled': enabled }) })
   - 更新 state.mediaPlayer.enabled
   - 调用 updateMediaPlayerUI(enabled)
   - 显示 toast：启用时"多媒体功能已启用"，禁用时"多媒体功能已禁用"

6. 新增 updateMediaPlayerUI 函数（复用 updateDevModeUI 模式）：
   - toggle 元素添加/移除 .active class
   - mediaPlayerSection 添加/移除 .disabled class

7. 新增 addWhitelistDomain 函数（per D-02/D-05/D-06/D-07）：
   - 验证输入非空，格式合法（/[^\w.-]/ 检查），不重复
   - 调用 settingsApi('update', { body: JSON.stringify({ 'mediaPlayer.whitelist': newList }) })
   - 更新 state.mediaPlayer.whitelist
   - 调用 renderWhitelistTags()
   - 清空输入框，显示 toast

8. 新增 removeWhitelistDomain 函数：
   - 从 state.mediaPlayer.whitelist 过滤掉目标域名
   - 调用 settingsApi('update') 保存
   - 调用 renderWhitelistTags()

9. 新增 renderWhitelistTags 函数（per D-05 标签式 UI）：
   - 白名单为空时：显示 whitelistHint，隐藏 whitelistTags
   - 白名单非空时：隐藏 whitelistHint，为每个域名创建 whitelist-tag 元素
   - 每个 tag 包含域名文本（textContent）和删除按钮（whitelist-tag-remove）
   - 删除按钮绑定 click 事件调用 removeWhitelistDomain
   - 使用 DOM 构建 + textContent（防 XSS，WR-13）

10. setupEventListeners 函数新增多媒体设置事件：

    - addWhitelistDomainBtn click → addWhitelistDomain(whitelistDomainInput.value)
    - whitelistDomainInput keydown Enter → addWhitelistDomain(whitelistDomainInput.value)

11. loadSettings 函数中，从返回的 settings 中读取 mediaPlayer 字段并更新 state.mediaPlayer
