# Phase 44 — UI Design Contract

> Visual and interaction contract for 播放器视频缓存与本地媒体库. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope of UI surfaces (from 44-CONTEXT.md `<domain>`):**

1. **播放器窗口**（`player.html` + `player.css`）— 工具栏录制按钮、录制红点、抽屉列表（缓存库 + 观看历史）、「已缓存部分可看」降级提示、关窗确认
2. **`realm://tasks` 任务页**（新内部页面）— 进行中/已完成/失败已中断三区，与 downloads/history 同构
3. **设置页多媒体分区**（`settings.html` + `settings-page.js`）— 缓存目录/容量配置 + 「任务列表」入口按钮
4. **主窗口角标**（`index.html` + `renderer.js`）— 活跃任务被动提醒，点击跳任务页

## Design System

| Property | Value |
|----------|-------|

| Preset | not applicable |
| Component library | none — 手写 CSS，复用现有 token 体系 |

**双 token 体系约定（关键）：** 本阶段 UI 分布在两套既有样式层上，禁止跨层混用：

| Surface | 样式层 | Token 前缀 | 明暗 |
|---------|--------|-----------|------|
| 播放器窗口（抽屉/红点/工具栏） | `player.css`（独立，不引用 main.css） | `--player-*` | 恒暗 |
| `realm://tasks` + 设置页 + 主窗口角标 | `styles/main.css` | `--bg-*` / `--text-*` / `--accent-color` 等 | 跟随主题（默认暗色） |

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 | 1.5 |
| Secondary / 时间戳 / 元信息 | 13px | 400 | 1.5 |
| Heading（分区标题、抽屉标题） | 16px | 600 | 1.2 |
| Display（任务页页面标题） | 20px | 600 | 1.2 |

- 字重只用 400 + 600 两档（player.css 现行惯例：控制按钮 600、时间显示 400）
- **徽标档例外（UI 评审定档）**：状态徽标/胶囊内的短文本可用 12px、纯数字胶囊（`min-width:16px` 容器内）可用 10px——徽标是受限容器内的微排版，套用正文档会溢出或撑破形状；正文类元素（如抽屉「转换为 MP4」CTA）一律不低于 13px。已按此收敛 `player.css` 的 CTA 字号（12→13px），`.task-badge`（12px）/`.media-task-badge`（10px）保留。
- 时间/时长/大小一律 `font-variant-numeric: tabular-nums`（沿用 `.time-display` 现值），录制红点旁的已录时长同此
- 抽屉条目标题单行截断：`white-space: nowrap; overflow: hidden; text-overflow: ellipsis`（沿用 `.title-bar-text` 惯例）

## Color

### 播放器窗口（player.css token，恒暗）

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#000000`（`--player-bg`） | 视频画布、抽屉面板底色 |
| Secondary (30%) | `rgba(0, 0, 0, 0.85)`（沿用 speed-menu 弹层色） | 抽屉面板、进度预览、弹层背景；`rgba(255,255,255,0.1)` hover 态 |
| Accent (10%) | `#3B82F6`（`--player-accent`） | 见下方 reserved list |
| Destructive | `#EF4444` | 录制红点、停止录制按钮、抽屉条目删除按钮 hover |
| Success | `#22c55e` | 复制成功反馈（现值沿用）；转封装完成态提示 |

### `realm://tasks` + 设置页 + 主窗口角标（main.css token，跟随主题）

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--bg-primary)`（暗色 `#1a1a1a`） | 页面背景 |
| Secondary (30%) | `var(--bg-secondary)`（暗色 `#2a2a2a`） | 任务卡片、设置分区卡片、角标底 |
| Accent (10%) | `var(--accent-color)`（`#3B82F6`） | 见下方 reserved list |
| Destructive | `var(--danger-color)`（`#EF4444`） | 停止/取消按钮、失败原因文本 |
| Warning | `var(--warning-color)`（`#F59E0B`） | 「已中断」任务状态标记 |
| Success | `var(--success-color)`（`#10B981`） | 「已完成」状态标记、进度满格 |

**Accent reserved for（穷举，禁止用于其他元素）：**
- 播放进度条已播部分（`.progress-played` 现值）
- 音量滑块填充（现值）
- 抽屉条目续播进度条填充
- 「继续后台录制」确认框主按钮、「转换为 MP4」CTA 按钮
- 任务页进行中状态标记 + 进度条填充
- 设置页「任务列表」入口按钮（链接式 accent）
- 主窗口任务角标

**录制红点语义：** `#EF4444` + CSS `@keyframes` 闪烁（opacity 脉动约 1s 循环），可点击（停止录制），hover 显示 tooltip「已录 12:34 · 156MB」格式文案。红点是** destructive 色**不是 accent 色——不要画成蓝色。

## Interaction States（状态覆盖）

| 状态 | 元素 | 行为 |
|------|------|------|
| Loading | 抽屉条目续播中 / 任务页进行中 | 进度条填充动画；抽屉条目完整度 < 100% 显示百分比而非骨架屏 |
| Streaming / 增量缓存 | 播放中未缓存完整视频（D-10） | 播放到哪补到哪，进度条 buffered 段（`rgba(255,255,255,0.3)` 现值）即缓存覆盖范围的可视化 |
| Disabled | 抽屉条目「转换为 MP4」（分片不齐，D-17） | 隐藏按钮（非置灰）；录制中断条目例外可见（D-22） |
| 录制与播放解耦（D-20） | 红点 vs 播放器 | 播放/暂停/刷新/切视频不影响红点与任务页；切走后红点消失但任务页仍 running |

## Project Conventions（executor 必读约束）

1. **realm://tasks 页 CSP**：`style-src 'self'` 无 unsafe-inline —— 元素初始隐藏必须走 CSS 类；JS 显隐用 `el.style.display`（CSSOM）给具体值；**不要**在 markup 写内联 style。
2. **弹框居中约定（AGENTS.md）**：主窗口/播放器窗口一律原生 `<dialog>` + `showModal()`，类规则显式 `margin: auto`（全局 `* { margin: 0 }` 会清掉 UA 居中），遮罩用 `::backdrop`；禁止全屏 div 遮罩类套在 dialog 上；禁止 width/height:100% 撑满方案。
3. **主窗口不 fetch HTTP**：任务页（realm:// 同源）走 `/api/tasks/*` + token；主窗口角标数据走 preload `realmAPI.*` IPC，不得直接 fetch。
4. **新导航入口**：角标跳转、设置页「任务列表」入口打开 `realm://tasks` 收敛到 renderer `openUrl()`，并更新 `docs/product/navigation-entry-points.md`。
5. **播放器窗口样式独立性**：抽屉/红点样式加进 `player.css`（该文件不引用 main.css），新增 token 以 `--player-` 前缀声明在 `:root`。
6. **进度/时长数字**：一律 `tabular-nums`，避免跳动。
