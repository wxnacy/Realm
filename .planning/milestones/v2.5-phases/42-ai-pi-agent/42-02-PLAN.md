在 renderer.js 中添加对话管理逻辑：

1. 新增状态变量：
```javascript
// 对话管理状态
state.conversations = [];
state.currentConversationId = null;
state.convDropdownOpen = false;
```

2. 新增元素引用（在 elements 对象中）：
```javascript
aiHistoryBtn: document.getElementById('aiHistoryBtn'),

```

3. 新增函数：

loadConversations() — 从主进程加载对话列表：
- 调用 window.realmAPI.conversationAPI.getConversations()
- 更新 state.conversations
- 调用 renderConvList()

renderConvList() — 渲染对话列表到 #aiConvList：
- 空列表时显示「暂无对话」+ 引导文案（UI-SPEC E1 empty）
- 按 updated_at 降序排列
- 当前对话添加 .active 类
- 对话标题截断为 30 字符 + ellipsis（UI-SPEC E1 long-text）
- 每个对话项显示：标题 + 时间 + 消息数
- 绑定 click 事件 → switchConversation(id)
- 绑定 contextmenu 事件 → showConvContextMenu(e, id, title)

toggleConvDropdown() — 切换下拉面板显示/隐藏：
- 点击 #aiHistoryBtn 触发
- 面板打开时按钮添加 active 类
- 点击面板外部关闭

switchConversation(conversationId) — 切换对话：
- 调用 window.realmAPI.conversationAPI.switchConversation(conversationId)
- 更新 state.currentConversationId
- 重新渲染对话列表（高亮新对话）
- 关闭下拉面板
- 清空消息列表
- 加载目标对话的消息并渲染

showConvContextMenu(e, conversationId, title) — 显示右键菜单：
- 在鼠标位置显示 .context-menu（复用现有样式）
- 菜单项：重命名、删除（红色）
- 点击重命名 → renameConversation(conversationId)
- 点击删除 → showDeleteConfirm(conversationId, title)
- 点击外部关闭菜单

renameConversation(conversationId) — 重命名对话：
- 将对话标题替换为 input 输入框
- 回车或失焦时调用 window.realmAPI.conversationAPI.renameConversation()
- 更新 state.conversations
- 重新渲染对话列表

showDeleteConfirm(conversationId, title) — 显示删除确认：
- 更新 #aiConvDeleteMsg 文本为「确定要删除「{title}」吗？此操作不可撤销。」
- 显示 #aiConvDeleteDialog
- 绑定取消按钮 → 关闭对话框
- 绑定删除按钮 → deleteConversation(conversationId)

deleteConversation(conversationId) — 删除对话：
- 调用 window.realmAPI.conversationAPI.deleteConversation(conversationId)
- 如果删除的是当前对话，自动创建新对话
- 关闭对话框
- 重新加载对话列表

4. 修改 toggleAIPanel()：
- 打开面板时自动创建新对话（per D-06）
- 调用 loadConversations() 加载对话列表

5. 在 setupEventListeners() 中绑定事件：
- #aiHistoryBtn click → toggleConvDropdown()
- #aiConvDeleteCancel click → 关闭对话框
- #aiConvDeleteConfirm click → 删除对话
- document click → 点击外部关闭下拉面板和右键菜单

6. 新对话按钮 #aiNewChatBtn 修改：
