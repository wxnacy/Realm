    在 media-remuxer.js 新增并导出纯函数 rebaseFmp4SegmentTfdt(buf, baselines)（命名可微调，导出供测试）：buf 为分片 Buffer，baselines 为调用方持有的 Map（track_ID → 基线值，v1 用 BigInt 防 64 位精度溢出，v0 用 Number）。实现轻量 box walker（G-45-2 missing 第 1/2 项）：

    1. 顶层 box 遍历：每 box 读 8 字节头（size32 + type）；size==1 读 64 位 largesize；size==0 视为到 buffer 末尾。每步边界校验：size >= 8 且 offset+size &lt;= buf.length，违反即停止该层遍历（不 throw——远端字节不可信，T-45-04），循环次数受 buffer 长度约束不依赖声明 size 累加（T-45-05）。
    2. type=='moof' 递归进子 box；子 box 中 type=='traf' 再递归；traf 内定位 'tfhd' 与 'tfdt'，其余子 box 跳过。
    3. tfhd：version(1B)+flags(3B) 之后紧跟 4 字节 track_ID（固定偏移，与 flags 可选字段无关——flags 只影响 track_ID 之后的可选字段，本 walker 不读它们）。
    4. tfdt：version 字节决定值宽——v0 读/写 4 字节 UInt32BE，v1 读/写 8 字节（BigInt 读 readBigUInt64BE）。同 traf 的 tfdt 与该 traf tfhd 的 track_ID 配对。
    5. 基线语义：baselines 无该 track_ID 记录 → 记录当前值为基线（该 tfdt 改写为 0）；已有记录 → 改写为 当前值 − 基线。改写只写值域原位字节，不动 size/version/flags（等长改写，新值 &lt;= 原值同宽必容下）。当前值 &lt; 基线的异常形态（分片乱序/时钟回拨）保守处理：不改写该 tfdt，原样保留。
    6. 返回改写的 tfdt 计数（供测试断言与诊断日志），buffer 原地修改。
