   - 确认批量删除 `#confirmBatchDeleteBtn`：调用 `window.realmAPI.historyDeleteBatch(state.containerId, [...state.selectedIds])` → 移除 DOM 节点 → 清空选中集 → 更新操作栏 → 显示 Toast
   - 滚动加载：`#historyContent` 或 `window` 的 `scroll` 事件 → 检测是否滚动到底部 → 调用 `loadMore()`
   - 取消按钮和关闭弹窗事件

   **数据加载 `loadHistory()`：**
   - 设置 `state.offset = 0`，`state.hasMore = true`
   - 如果 `state.keyword` 有值：调用 `window.realmAPI.historySearch({containerId: state.containerId, keyword: state.keyword, offset: 0, limit: state.limit})`
   - 否则：调用 `window.realmAPI.historyList({containerId: state.containerId, offset: 0, limit: state.limit})`
   - 结果赋值 `state.records`，设置 `state.hasMore = results.length === state.limit`
   - 调用 `renderHistory(state.records)`

   **加载更多 `loadMore()`：**
   - 如果 `state.loading || !state.hasMore` return
   - `state.loading = true`，`state.offset += state.limit`
   - 调用对应 list/search API（offset 为 state.offset）
   - 追加到 `state.records`，设置 `state.hasMore`
   - 调用 `renderHistory(state.records)` 或 `appendRecords(newRecords)`

   **渲染函数 `renderHistory(records)`：**
   - 清空 `#historyContent`
   - 如果 records 为空：渲染空状态（per UI-SPEC Component 8）— `.history-empty` 包含图标、标题「暂无浏览记录」、正文「在浏览器中访问网页后，历史记录会显示在这里」

   - 如果搜索无结果（keyword 有值但 records 为空）：显示「未找到匹配的历史记录」

   - 「本周」：本周一 00:00:00 到昨天 00:00:00
   - 「本月」：本月 1 日 00:00:00 到本周一 00:00:00

   - 删除按钮 click 事件：调用 `window.realmAPI.historyDelete(state.containerId, record.id)` → 移除 DOM 节点 → 如果该组为空则移除整个组
