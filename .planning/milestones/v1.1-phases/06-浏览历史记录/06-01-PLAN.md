3. **创建 history-manager.js**（项目根目录，遵循 cookie-manager.js 模块化模式）：
   - 模块顶部 JSDoc 注释说明功能
   - 使用 `require('better-sqlite3')` 和 `require('electron').app`
   - 数据库路径：`path.join(app.getPath('userData'), 'history.db')`
   - `initDatabase()` 函数：创建 Database 实例，设置 `journal_mode = WAL` 和 `synchronous = NORMAL`
   - `sanitizeContainerId(containerId)` 函数：白名单验证容器 ID，仅允许 `[a-z0-9-]` 字符（防 SQL 注入，per RESEARCH Pitfall 3），验证失败抛出 Error
   - `ensureTable(containerId)` 函数：调用 sanitizeContainerId 后创建 `history_{containerId}` 表，字段：`id INTEGER PRIMARY KEY AUTOINCREMENT, url TEXT NOT NULL, title TEXT NOT NULL DEFAULT '', favicon_url TEXT DEFAULT '', visited_at INTEGER NOT NULL, created_at INTEGER NOT NULL DEFAULT (strftime('%s','now')*1000)`；创建索引 `idx_history_{containerId}_visited_at ON history_{containerId} (visited_at DESC)` 和 `idx_history_{containerId}_url ON history_{containerId} (url)`
   - `addRecord(containerId, {url, title, faviconUrl, visitedAt})` 函数：ensureTable → INSERT → enforceLimit
   - `enforceLimit(containerId)` 函数：COUNT(*) > 10000 时 DELETE 最旧的 excess 条（per D-19 FIFO，per D-20 无感知）
   - `searchRecords(containerId, {keyword, offset, limit})` 函数：WHERE url LIKE '%keyword%' OR title LIKE '%keyword%' ORDER BY visited_at DESC LIMIT offset,limit；keyword 通过参数绑定（非拼接）
   - `listRecords(containerId, {offset, limit})` 函数：SELECT * ORDER BY visited_at DESC LIMIT offset,limit
   - `deleteRecord(containerId, id)` 函数：DELETE WHERE id = ?
   - `deleteRecords(containerId, ids)` 函数：DELETE WHERE id IN (?,?,?)（动态构建占位符）
   - `clearRecords(containerId)` 函数：DELETE FROM history_{containerId}（清空全部）
   - `getCount(containerId)` 函数：SELECT COUNT(*)
   - `dropTable(containerId)` 函数：DROP TABLE IF EXISTS history_{containerId}（供容器删除时调用）
   - 导出所有公开函数供 ipc-handlers.js 使用
   - 数据库连接在模块加载时通过 initDatabase() 初始化（与 cookie-manager 模式一致）

4. **在 main.js 注册 realm:// 协议**（per D-03，per RESEARCH Pattern 2）：
   - 在 main.js 顶部（`require` 区域之后、`app.whenReady()` 之前）添加 `protocol.registerSchemesAsPrivileged`，注册 `realm` scheme，privileges: `{ standard: true, secure: true, supportFetchAPI: true }`
   - 这行代码必须在模块顶层执行（不在 whenReady 回调内），否则 Electron 启动时报 scheme 未注册
   - 在 `app.whenReady().then()` 回调中添加 `protocol.handle('realm', handler)`：
     - 解析 `request.url` 的 hostname
     - `hostname === 'history'` 时返回 `net.fetch(pathToFileURL(path.join(__dirname, 'src/history.html')).toString())`
     - 其他 hostname 返回 `new Response('Not Found', { status: 404 })`
   - 引入 `const { protocol, net } = require('electron')` 和 `const { pathToFileURL } = require('url')`

5. **在 main.js 的 whenReady 中初始化 history-manager**：
   - 添加 `const historyManager = require('./history-manager')`
   - 在 `cookieManager.loadAllCookies()` 之后调用 `historyManager.initDatabase()`

6. **在 ipc-handlers.js 添加 history:* IPC 处理器**（per D-22 记录内容）：
   - 引入 `const historyManager = require('./history-manager')`
   - `history:add`：接收 `{containerId, url, title, faviconUrl, visitedAt}`，调用 `historyManager.addRecord()`；URL 过滤（per D-23）：如果 url 为空、`about:blank`、以 `realm://` 开头则直接返回 `{skipped: true}`
   - `history:search`：接收 `{containerId, keyword, offset, limit}`，调用 `historyManager.searchRecords()`
   - `history:list`：接收 `{containerId, offset, limit}`，调用 `historyManager.listRecords()`
   - `history:delete`：接收 `{containerId, id}`，调用 `historyManager.deleteRecord()`
   - `history:delete-batch`：接收 `{containerId, ids}`，调用 `historyManager.deleteRecords()`
   - `history:clear`：接收 `{containerId}`，调用 `historyManager.clearRecords()`
   - `history:count`：接收 `{containerId}`，调用 `historyManager.getCount()`
   - 每个处理器入口调用 `assertTrustedSender(event)` 验证调用方身份
   - 每个处理器对 containerId 做 typeof string 检查

7. **在 preload.js 暴露 history API**（在现有 `// ==================== 快捷键 ====================` 之前添加新区域 `// ==================== 浏览历史 ====================`）：
   - `historyAdd: (data) => ipcRenderer.invoke('history:add', data)`
   - `historySearch: (data) => ipcRenderer.invoke('history:search', data)`
   - `historyList: (data) => ipcRenderer.invoke('history:list', data)`
   - `historyDelete: (containerId, id) => ipcRenderer.invoke('history:delete', {containerId, id})`
   - `historyDeleteBatch: (containerId, ids) => ipcRenderer.invoke('history:delete-batch', {containerId, ids})`
   - `historyClear: (containerId) => ipcRenderer.invoke('history:clear', {containerId})`
   - `historyCount: (containerId) => ipcRenderer.invoke('history:count', {containerId})`
