## Existing UI Components — Parameter Cleanup Required

This phase does NOT introduce new UI components. The following existing files require parameter cleanup to remove container awareness.

### 1. `src/favorites-page.js` — Remove Container State and Parameters

**Current behavior:** Reads `containerId` from URL query parameter (`?container=work`) and passes it to all API calls.

**Required changes:**

| Location | Current | Target |
|----------|---------|--------|
| `state.containerId` | `pageParams.get('container') \|\| 'default'` | Remove entirely |
| `favoritesApi('list', ...)` | `{ containerId: state.containerId, offset, limit }` | `{ offset, limit }` |
| `favoritesApi('search', ...)` | `{ containerId: state.containerId, keyword, ... }` | `{ keyword, ... }` |
| `favoritesApi('update', ...)` | `body: JSON.stringify({ containerId: state.containerId, id, title })` | `body: JSON.stringify({ id, title })` |
| `favoritesApi('delete-batch', ...)` | `body: JSON.stringify({ containerId: state.containerId, ids })` | `body: JSON.stringify({ ids })` |
| `loadFavorites()` | All calls pass `containerId` query param | Remove `containerId` from all query objects |
| `loadMore()` | All calls pass `containerId` query param | Remove `containerId` from all query objects |
| `handleBatchDelete()` | Passes `containerId` in body | Remove `containerId` from body |
| `startInlineEdit()` | Passes `containerId` in update body | Remove `containerId` from body |

**Visual/interaction result:** Zero visual change. The favorites list page shows all favorites globally instead of per-container — same layout, same interactions.

### 2. `src/renderer.js` — Remove Container Dependency from Star Button

**Current behavior:** `checkBookmarkStatus(url, containerId)` and `saveBookmark()`/`removeBookmark()` all pass `containerId` to IPC calls.

**Required changes:**

| Location | Current | Target |
|----------|---------|--------|
| `checkBookmarkStatus(url, containerId)` | Takes `containerId` param, passes to `favoritesCheck(containerId, url)` | Remove `containerId` param, call `favoritesCheck(url)` |
| `saveBookmark()` | `const containerId = state.currentContainer;` then passes to `favoritesUpdate(containerId, ...)` and `favoritesAdd({ containerId, ... })` | Remove `containerId` variable and parameter |
| `removeBookmark()` | `const containerId = state.currentContainer;` then passes to `favoritesDelete(containerId, bookmarkId)` | Remove `containerId` variable and parameter |
| All call sites of `checkBookmarkStatus(url, tab.containerId)` | Passes `tab.containerId` | Change to `checkBookmarkStatus(url)` |

**Visual/interaction result:** Zero visual change. The star button detects bookmark status based on global URL match instead of per-container URL match — same filled/outline behavior, same edit panel.

### 3. `main.js` — API Endpoints Remove ContainerId

**Current behavior:** All `/api/favorites/*` endpoints read `containerId` from query params or POST body and pass to `favoritesManager` methods.

**Required changes:**

| Endpoint | Current | Target |
|----------|---------|--------|
| `GET /api/favorites/list` | `favoritesManager.listRecords(containerId, { offset, limit })` | `favoritesManager.listRecords({ offset, limit })` |
| `GET /api/favorites/search` | `favoritesManager.searchRecords(containerId, { keyword, offset, limit })` | `favoritesManager.searchRecords({ keyword, offset, limit })` |
| `GET /api/favorites/check` | `favoritesManager.checkUrl(containerId, url)` | `favoritesManager.checkUrl(url)` |
| `POST /api/favorites/add` | `favoritesManager.addRecord(containerId, { url, title, faviconUrl })` | `favoritesManager.addRecord({ url, title, faviconUrl })` |
| `POST /api/favorites/update` | `favoritesManager.updateRecord(containerId, id, { title })` | `favoritesManager.updateRecord(id, { title })` |
| `POST /api/favorites/delete` | `favoritesManager.deleteRecord(containerId, id)` | `favoritesManager.deleteRecord(id)` |
| `POST /api/favorites/delete-batch` | `favoritesManager.deleteRecords(containerId, ids)` | `favoritesManager.deleteRecords(ids)` |
