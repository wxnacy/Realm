  <name>Task 1: 创建 src/newtab-page.js 新标签页逻辑</name>
  <files>src/newtab-page.js</files>
  <action>
创建 src/newtab-page.js，实现常用网站网格展示逻辑。

参考 src/history-page.js 的模式：
1. 从 URL 查询参数获取 token 和 containerId
2. 定义 API 调用函数
3. DOM 元素引用
4. 初始化函数

核心实现：

1. 状态管理：
   - apiToken: 从 URL 查询参数获取
   - containerId: 从 URL 查询参数获取
   - sites: [] // 常用网站数据

2. API 调用函数 frequentSitesApi(route, options, query)：
   - 参考 historyApi 函数模式
   - 调用 /api/frequent-sites/{route}

3. DOM 元素引用：
   - frequentSitesGrid: .frequent-sites-grid
   - frequentEmpty: .frequent-empty
   - newTabSearch: .new-tab-search

4. 渲染函数 renderSites(sites)：
   - 如果 sites.length === 0，显示 frequentEmpty，隐藏 frequentSitesGrid
   - 否则，隐藏 frequentEmpty，显示 frequentSitesGrid
   - 清空 frequentSitesGrid.innerHTML
   - 遍历 sites，为每个站点创建卡片：
     ```javascript
     const card = document.createElement('a');
     card.className = 'frequent-site-card';
     card.href = site.url;
     card.target = '_self'; // 在当前 webview 导航
     
     // favicon
     const favicon = document.createElement('img');
     favicon.className = 'frequent-site-favicon';
     favicon.src = `https://www.google.com/s2/favicons?domain=${site.domain}&sz=48`;
     favicon.alt = site.title || site.domain;
     favicon.onerror = () => {
       // 降级为首字母
       favicon.style.display = 'none';
       fallback.style.display = 'flex';
     };
     
     const fallback = document.createElement('div');
     fallback.className = 'frequent-site-favicon-fallback';
     fallback.textContent = (site.domain || '?')[0].toUpperCase();
     fallback.style.display = 'none';
     
     // 标题
     const title = document.createElement('div');
     title.className = 'frequent-site-title';
     title.textContent = site.title || site.domain;
     
     card.appendChild(favicon);
     card.appendChild(fallback);
     card.appendChild(title);
     frequentSitesGrid.appendChild(card);
     ```

5. 搜索框功能：
   - 监听 newTabSearch 的 keydown 事件
   - Enter 键时：
     - 如果输入是 URL（以 http:// 或 https:// 开头），直接导航
     - 否则，构造搜索 URL（如 https://www.google.com/search?q=xxx）
     - 使用 window.location.href = url 导航

6. 初始化函数 init()：
   - 调用 frequentSitesApi('list', {}, { limit: 12 })
   - 调用 renderSites(data)

7. 页面加载完成后调用 init()

注意事项：
- 卡片点击使用 <a> 标签，target="_self" 在当前 webview 导航
- favicon 使用 Google Favicon 服务，onerror 时降级为首字母
- 搜索框 Enter 导航使用 window.location.href
- 使用 textContent 而非 innerHTML 防止 XSS

  <name>Task 2: 创建 src/settings-page.js 设置页面逻辑</name>
  <files>src/settings-page.js</files>
  <action>
创建 src/settings-page.js，实现设置页面交互逻辑。

参考 src/history-page.js 的模式：
1. 从 URL 查询参数获取 token
2. 定义 API 调用函数
3. DOM 元素引用
4. 初始化函数

核心实现：

1. 状态管理：
   - apiToken: 从 URL 查询参数获取
   - settings: {} // 当前设置值

2. API 调用函数 settingsApi(route, options, query)：
   - 参考 historyApi 函数模式
   - 调用 /api/settings/{route}

3. DOM 元素引用：
   - defaultBrowserStatus: .settings-status (默认浏览器状态)
   - setDefaultBrowserBtn: .btn-primary (设为默认浏览器按钮)
   - retentionDaysSelect: #retentionDays
   - defaultContainerSelect: #defaultContainer
   - toast: #toast

4. 加载设置函数 loadSettings()：
   - 调用 settingsApi('get')
   - 更新 retentionDaysSelect.value
   - 更新 defaultContainerSelect.value
   - 检测是否为默认浏览器（调用 /api/settings/is-default-browser）
   - 更新 defaultBrowserStatus 和按钮状态
   - 加载容器列表（调用 /api/containers/list）动态生成 defaultContainerSelect 选项

5. 保存设置函数 saveSettings(key, value)：
   - 调用 settingsApi('update', { method: 'POST', body: { [key]: value } })
   - 显示 toast "设置已保存"
   - 2 秒后隐藏 toast

6. 默认浏览器引导：
   - setDefaultBrowserBtn 点击事件：
     - 调用 /api/settings/set-default-browser (POST)
     - 更新 UI 状态
     - 显示成功提示

7. 历史记录保留天数：
   - retentionDaysSelect change 事件：
     - 调用 saveSettings('historyRetentionDays', parseInt(value))
     - 0 表示永不删除

8. 默认容器：
   - defaultContainerSelect change 事件：
     - 调用 saveSettings('defaultContainer', value)
     - 特殊值 'last-used' 表示使用上次打开的容器
   - 动态生成容器选项：
     - 调用 /api/containers/list 获取容器列表
     - 清空 defaultContainerSelect，添加 "使用上次打开的容器" 选项
     - 遍历容器列表，为每个容器创建 option 元素
     - 设置当前选中值为 settings.defaultContainer

9. Toast 显示函数 showToast(message)：
   - toast.textContent = message
   - toast.classList.add('show')
   - setTimeout(() => toast.classList.remove('show'), 2000)

10. 初始化函数 init()：
    - 调用 loadSettings()
    - 绑定事件监听器

11. 页面加载完成后调用 init()

注意事项：
- 设置变更立即保存，无需确认按钮
- 默认浏览器检测需要主进程支持（/api/settings/is-default-browser）
- 使用 textContent 防止 XSS
- Toast 动画参考现有的 toast 样式

   // 设置按钮：打开设置页面
   if (elements.settingsBtn) {
     elements.settingsBtn.addEventListener('click', () => {
       const containerId = state.currentContainer;
       // 检查是否已有设置页面 Tab
       let existingTabId = null;
       state.tabs.forEach((tab, tabId) => {
         if (tab.url === 'realm://settings' && tab.containerId === containerId) {
           existingTabId = tabId;
         }
       });
       if (existingTabId) {
         switchTab(existingTabId);
       } else {
         createTab(containerId, 'realm://settings');
       }
     });
   }
