  <name>Task 1: 创建 frequent-sites-manager.js 模块</name>
  <files>frequent-sites-manager.js</files>
  <action>
创建 frequent-sites-manager.js 模块，实现 frecency 算法计算常用网站。

核心功能：
1. 复用 history-manager.js 的数据库连接（延迟加载 better-sqlite3）
2. 实现 getFrequentSites(limit) 函数，返回按 frecency 排序的网站列表
3. frecency 算法：frequency * recency_weight
   - 最近 7 天内访问：权重 10x
   - 最近 30 天内访问：权重 5x
   - 最近 90 天内访问：权重 1x
4. 域名聚合：合并同一域名下的所有页面，返回访问次数最多的页面作为代表
5. 查询所有容器的历史记录表（不按容器隔离，D-13/D-14）

SQL 查询逻辑（参考 08-RESEARCH.md）：
- 遍历所有 history_* 表
- 使用 SUBSTR 和 INSTR 提取域名（去除协议和路径）
- GROUP BY 域名，计算 frecency_score
- ORDER BY frecency_score DESC
- LIMIT 默认 12（6x2 网格）

返回格式：
```javascript
[
  {
    domain: 'example.com',
    url: 'https://example.com/page',
    title: '页面标题',
    faviconUrl: 'https://example.com/favicon.ico',
    visitCount: 42,
    frecencyScore: 156
  }
]
```

参考 history-manager.js 的模式：
- initDatabase() 函数（延迟加载 better-sqlite3）
- sanitizeContainerId() 函数（安全验证）
- 使用 db.prepare().all() 执行查询

注意事项：
- 必须处理表不存在的情况（history_* 表可能不存在）
- favicon_url 为空时，返回空字符串（前端使用 Google Favicon 服务降级）
- 使用 try-catch 包装数据库操作，错误时返回空数组
  </action>

  <name>Task 3: 添加 open-url 协议处理（SETT-03）</name>
  <files>main.js</files>
  <action>
在 main.js 中添加 open-url 事件处理，确保外部链接在当前容器的 Tab 中打开。

1. 在 app.on('ready') 之后添加协议处理：
   ```javascript
   // 处理外部链接通过 realm:// 协议打开
   app.on('open-url', (event, url) => {
     event.preventDefault();
     // 获取当前活动窗口
     const focusedWindow = BrowserWindow.getFocusedWindow();
     if (focusedWindow) {
       // 发送 URL 到渲染进程，在当前容器的新 Tab 中打开
       focusedWindow.webContents.send('open-external-url', url);
     }
   });
   ```

2. 在 src/preload.js 中添加 IPC 监听器：
   ```javascript
   // 监听外部链接打开事件
   ipcRenderer.on('open-external-url', (event, url) => {
     // 触发自定义事件，让 renderer.js 处理
     window.dispatchEvent(new CustomEvent('realm-open-url', { detail: { url } }));
   });
   ```

3. 在 src/renderer.js 中添加事件监听器（在 setupEventListeners 函数中）：
   ```javascript
   // 监听外部链接打开事件
   window.addEventListener('realm-open-url', (event) => {
     const url = event.detail.url;
     if (url) {
       // 在当前容器的新 Tab 中打开
       createTab(state.currentContainer, url);
     }
   });
   ```

注意事项：
- open-url 事件只在 macOS 上有效，Windows 使用 process.argv
- 需要在 app.on('ready') 之前调用 app.setAsDefaultProtocolClient('realm')
- 外部链接应该在当前活动窗口的当前容器中打开
