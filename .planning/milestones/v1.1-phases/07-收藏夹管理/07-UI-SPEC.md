## Interaction Patterns

### 1. Bookmark Star Button (Toolbar)

**States:**

| State | Visual | Behavior |
|-------|--------|----------|
| Unbookmarked | Outline star icon, color: --text-secondary (#a0a0a0) | Click: open edit panel |
| Bookmarked | Filled star icon, color: #FBBF24 (gold) | Click: remove bookmark immediately (no confirmation) |
| Hover (unbookmarked) | Outline star, color: --text-primary (#f0f0f0) | Same click behavior |
| Hover (bookmarked) | Filled star, color: #FBBF24 with subtle scale(1.1) | Same click behavior |

**Placement:** Toolbar right section, before history button. Adjacent to URL input.

**Size:** 18x18 SVG icon inside 32x32 btn-icon container (matching existing toolbar buttons).

### 2. Bookmark Edit Panel

**Trigger:** Click star on an unbookmarked page.

**Layout:**
```
+----------------------------------+
|  收藏此页面                       |
|                                  |
|  标题                             |
|  [________________________]      |
|                                  |
|  网址 (read-only)                 |
|  https://example.com/page        |
|                                  |
|  [取消]            [保存]         |
+----------------------------------+
```

**Dimensions:** Width 320px, border-radius 12px, padding 16px, background --bg-secondary.

**Behavior:**
- Title input: pre-filled with page title, editable, auto-focus on open
- URL: read-only, --text-muted color, font-size 13px
- Save: saves bookmark, closes panel, star turns gold, shows "已收藏" toast
- Cancel: closes panel without saving
- Click outside: close panel without saving
- Press Escape: close panel without saving

**Position:** Fixed position, anchored below the star button, right-aligned. z-index 1001 (above panels).

### 3. Favorites List Page (realm://favorites)

**Access:** Click folder icon button in toolbar.

**Layout (mirrors history page):**
```
+------------------------------------------+
|  收藏夹              [无清空按钮,有批量删除] |
|  [搜索收藏..._________________________]   |
|  [ ] 已选择 0 项  [删除选中项] [全选]      |
|                                          |
|  [ ] favicon  页面标题                    |
|                https://example.com  时间  |
|  [ ] favicon  页面标题                    |
|                https://example.com  时间  |
|  ...                                     |
+------------------------------------------+
```

**Max width:** 800px, centered (matching .history-page).

### 4. Inline Title Edit

**Trigger:** Click on a favorite item's title text.

**Behavior:**
- Title text becomes an editable input field
- Same font-size (14px), same width, border --accent-color on focus
- Press Enter or click elsewhere to save
- Press Escape to cancel edit
- On save: update database, re-render title text
- On cancel: revert to original title

### 5. Search

**Behavior:**
- Input debounced at 300ms
- Matches against title AND URL fields
- Matched text highlighted with .favorites-highlight (background rgba(59,130,246,0.3))
- Empty search shows all favorites
- No results shows "没有找到匹配的收藏" empty state

### 6. Batch Delete

**Behavior (mirrors history page exactly):**
- Checkboxes appear on each item
- Actions bar shows when any item is checked
- Select all checkbox in actions bar
- "删除选中项" button shows confirmation dialog
- Confirmation dialog: modal with warning text

## Accessibility Notes

- Bookmark star button: `title` attribute changes between "收藏" and "取消收藏" based on state
- Edit panel: title input has associated `<label>` element
- Favorites page search: input has `aria-label="搜索收藏"`
- All interactive elements are keyboard-focusable (tab order)
- Delete confirmation modal: focus trapped inside dialog
- Toast notifications: role="status" for screen reader announcement
