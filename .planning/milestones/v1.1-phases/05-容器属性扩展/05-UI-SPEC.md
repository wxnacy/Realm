## Component Inventory

本阶段不引入新组件，仅扩展现有容器编辑 Modal 的表单字段。

### 修改的文件

| 文件 | 修改内容 |
|------|---------|
| `src/index.html` | 在容器编辑 Modal 中添加邮箱、手机号、备注三个表单字段 |
| `src/renderer.js` | 更新 openEditModal()、saveContainer()、renderContainerModal() 函数处理新属性 |
| `src/main.js` | DEFAULT_CONTAINERS 添加 phone、email、notes 默认值；updateContainer() 处理新属性 |
| `src/styles/main.css` | 添加 textarea 样式（复用 .form-group input 样式 + 多行适配） |

### 表单字段规格

| 字段 | 类型 | placeholder | maxlength | 验证规则 |
|------|------|-------------|-----------|---------|
| 邮箱 | `<input type="email">` | 例如：user@example.com | 100 | 可选；填写时检查 @ 格式 |
| 手机号 | `<input type="tel">` | 例如：13800138000 | 11 | 可选；填写时检查11位数字 |
| 备注 | `<textarea>` | 可选填写备注信息... | 500 | 可选；最大500字符 |

### 表单布局规则

1. 扩展属性字段位于现有属性（名称、颜色、图标）下方
2. 用一条分隔线（`<hr>` 或 border-top）区分基础属性和扩展属性区域
3. 每个字段独占一行，与现有 .form-group 风格一致
4. 备注 textarea 高度约 80px（约 4 行），支持换行
5. 错误提示复用 .error-message 样式，仅在用户填写后格式不对时显示

### 数据兼容性

- 新增属性默认值为空字符串：`phone: ''`, `email: ''`, `notes: ''`
- 读取时惰性填充：每次加载容器数据时检查缺失字段并补全
- 空字符串不触发验证
