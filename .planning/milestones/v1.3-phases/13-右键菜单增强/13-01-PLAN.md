新建 context-menu-manager.js 模块，按 D-01 使用 Electron 原生 Menu API，按 D-02 在主进程统一管理菜单逻辑。

模块结构和导出：

1. **closedTabsStack** — 模块内部维护的已关闭标签栈（LIFO，最多 10 条）。每条记录包含 `{ containerId, url, title }`。导出 `pushClosedTab(info)` 和 `hasClosedTabs()` 方法供外部调用。

2. **buildTabMenu(tabInfo, mainWindow)** — 构建标签页右键菜单（per D-07, D-08, D-09, D-10）
   - tabInfo 参数: `{ tabId, tabCount, tabIndex, isPinned, hasClosedTabs }`
   - 菜单项顺序（按 UI-SPEC.md Tab Context Menu）：
     - "关闭标签页" — accelerator: CmdOrCtrl+W, click: hostWebContents.send('context-menu:close-tab', { tabId })
     - "关闭其他标签页" — enabled: tabCount > 1, click: send('context-menu:close-other-tabs', { tabId })
     - "关闭左侧标签页" — enabled: tabIndex > 0, click: send('context-menu:close-left-tabs', { tabId })
     - "关闭右侧标签页" — enabled: tabIndex < tabCount - 1, click: send('context-menu:close-right-tabs', { tabId })
     - separator
     - "重新打开已关闭标签页" — accelerator: CmdOrCtrl+Shift+T, enabled: hasClosedTabs, click: send('context-menu:reopen-tab', {})
     - separator
     - 固定/取消固定标签页 — label 根据 isPinned 动态切换, click: send('context-menu:toggle-pin', { tabId })

3. **buildWebMenu(contextInfo, mainWindow)** — 构建网页右键菜单（per D-11, D-12, D-13~D-16, D-17, D-18）
   - contextInfo 参数: `{ type, linkURL, srcURL, mediaType, selectionText, canGoBack, canGoForward, isLoading, guestContentsId, containers }`
   - type 值: 'image' | 'link' | 'general'（按 D-11 动态选择）

   **图片菜单（type === 'image'，per D-17 + UI-SPEC.md Image Context Menu）：**
   - "在新标签页中打开图片" — click: send('context-menu:open-in-new-tab', { url: contextInfo.srcURL })
   - "将图片另存为…" — click: webContents.saveAs() on guest
   - "复制图片" — click: 下载图片 → nativeImage.createFromBuffer() → clipboard.writeImage() → send('context-menu:toast', { message: '已复制' })
   - "复制图片地址" — click: clipboard.writeText(srcURL) → send('context-menu:toast', { message: '已复制' })
   - separator
   - 然后追加通用页面菜单项（见下方）

   **链接菜单（type === 'link'，per D-18 + UI-SPEC.md Link Context Menu）：**
   - "在新标签页中打开链接" — click: send('context-menu:open-in-new-tab', { url: contextInfo.linkURL })
   - "在后台标签页中打开" — click: send('context-menu:open-in-bg-tab', { url: contextInfo.linkURL })
   - separator
   - "在新容器标签页中打开" — submenu: 遍历 containers 数组，每项 label 为 `${container.icon} ${container.name}`，click: send('context-menu:open-in-container', { url: linkURL, containerId: container.id })
   - separator
   - "复制链接地址" — click: clipboard.writeText(linkURL) → send('context-menu:toast', { message: '已复制' })
   - separator
   - 然后追加通用页面菜单项

   **通用菜单（type === 'general' 或追加到图片/链接菜单后，per D-12~D-16 + UI-SPEC.md Web Page Context Menu General）：**

   导航分组：
   - "后退" — accelerator: CmdOrCtrl+[, enabled: canGoBack, click: webContents.goBack() on guest
   - "前进" — accelerator: CmdOrCtrl+], enabled: canGoForward, click: webContents.goForward() on guest
   - "刷新" — accelerator: CmdOrCtrl+R, click: webContents.reload() on guest
   - "停止加载" — enabled: isLoading, click: webContents.stop() on guest
   - separator

   页面操作分组：
   - "另存为…" — accelerator: CmdOrCtrl+S, click: webContents.saveAs() on guest
   - "打印…" — accelerator: CmdOrCtrl+P, click: webContents.print() on guest
   - "添加到收藏夹" — accelerator: CmdOrCtrl+D, click: send('context-menu:add-to-favorites', {})
   - separator

   开发者工具分组：
   - "查看页面源代码" — accelerator: CmdOrCtrl+U, click: send('context-menu:open-in-new-tab', { url: `view-source:${pageURL}` })
   - "检查元素" — accelerator: CmdOrCtrl+Shift+C, click: webContents.openDevTools({ mode: 'detach' }) on guest
   - separator

   文本编辑分组（per D-16）：
   - "剪切" — accelerator: CmdOrCtrl+X, enabled: editFlags.canCut, click: send('context-menu:text-action', { action: 'cut' })
   - "复制" — accelerator: CmdOrCtrl+C, enabled: editFlags.canCopy, click: send('context-menu:text-action', { action: 'copy' })
   - "粘贴" — accelerator: CmdOrCtrl+V, enabled: editFlags.canPaste, click: send('context-menu:text-action', { action: 'paste' })
   - "全选" — accelerator: CmdOrCtrl+A, click: send('context-menu:text-action', { action: 'selectAll' })

4. **getGuestWebContents(guestContentsId)** — 辅助函数，使用 webContents.fromId(guestContentsId) 获取 webview guest 的 webContents 对象。

5. **复制图片实现细节**：使用 Electron net 模块或 Node.js https/fetch 下载图片 URL，用 nativeImage.createFromBuffer() 创建图片对象，再用 clipboard.writeImage() 写入剪贴板。需要处理 data: URL（直接 base64 解码）。下载失败时仅发送 toast '复制失败'，不抛异常。

所有菜单使用 Menu.buildFromTemplate(template) 构建，menu.popup({ window: mainWindow }) 弹出（per D-04，自动在鼠标位置显示）。
菜单项 click 回调中，hostWebContents 通过 mainWindow.webContents 获取。

修改 main.js，按 D-02 主进程统一管理菜单逻辑：

1. **文件顶部导入**：在现有 require 区域添加 `const contextMenuManager = require('./context-menu-manager');`

2. **注册 IPC 监听器**（在 main.js 的 IPC 区域，使用 ipcMain.on 而非 ipcMain.handle，因为菜单请求是单向通知无需返回值）：

   - `ipcMain.on('show-tab-context-menu', (event, tabInfo) => { ... })`
     获取 BrowserWindow.fromWebContents(event.sender)，调用 contextMenuManager.buildTabMenu(tabInfo, mainWindow)

   - `ipcMain.on('show-web-context-menu', (event, contextInfo) => { ... })`
     获取 BrowserWindow.fromWebContents(event.sender)，将 contextInfo 扩展为包含 containers 列表（调用 containerManager 获取）和 guestContentsId（从 activeWebviewContentsId 获取），然后调用 contextMenuManager.buildWebMenu(contextInfo, mainWindow)

   - `ipcMain.on('context-menu:closed-tab', (event, tabInfo) => { ... })`
     调用 contextMenuManager.pushClosedTab(tabInfo) 将关闭的标签信息压入已关闭栈

3. **webview context-menu 事件监听**：不需要在 main.js 中添加 webview 的 context-menu 事件监听，因为 webview 的 context-menu 事件在渲染进程的 webview 元素上触发（通过 DOM 事件），由 Plan 2 的 renderer.js 处理并发送 IPC。
