## Components

### C-01: 保存凭据提示横幅 (`credential-save-banner`)

**Location:** Fixed position, 工具栏正下方。与工具栏同宽，锚定在 `.toolbar` 的 bottom edge。

**Structure:**
```html
<div class="credential-save-banner hidden" id="credentialSaveBanner">
  <!-- 左侧：Key 图标 + 提示文案 -->
  <div class="credential-save-info">
    <svg class="credential-save-icon" width="18" height="18" viewBox="0 0 24 24"
         fill="none" stroke="currentColor" stroke-width="2">
      <path d="M21 2l-2 2m-7.61 7.61a5.5 5.5 0 1 1-7.778 7.778 5.5 5.5 0 0 1 7.777-7.777zm0 0L15.5 7.5m0 0l3 3L22 7l-3-3m-3.5 3.5L19 4"/>
    </svg>
    <span class="credential-save-text">
      是否为 <strong class="credential-save-domain">{domain}</strong> 保存密码？
    </span>
  </div>

  <!-- 右侧：操作按钮 -->
  <div class="credential-save-actions">
    <button class="credential-save-btn credential-save-btn-save" id="credentialSaveBtn" title="保存密码">
      保存
    </button>
    <button class="credential-save-btn credential-save-btn-never" id="credentialNeverBtn" title="永不再询问此网站">
      永不
    </button>
    <button class="credential-save-btn credential-save-btn-later" id="credentialLaterBtn" title="稍后决定（10 秒后自动关闭）">
      暂不
    </button>
  </div>
</div>
```

**Behavior (D-05, D-06, D-07, D-08):**
- 表单提交检测到登录凭据后，横幅从工具栏下方滑入（`transform: translateY(-100%)` → `translateY(0)`，300ms ease-out）
- 10 秒无操作后自动消失（等同于"暂不"），有倒计时不显示，静默消失
- 点击横幅外部区域：等同于"暂不"
- ESC 键：等同于"暂不"
- "保存"：调用 `window.realmAPI.credentialAPI.saveCredential({username, password, domain})`，按钮变绿色 ✓ 后消失（D-04）
- "永不"：调用 `window.realmAPI.credentialAPI.neverSave(domain)`，记录到凭据存储的永不保存列表（D-07），横幅立即消失
- "暂不"：横幅立即消失，不保存任何记录

**Sizing:** Height 44px, padding 0 16px. Border-radius 0（与工具栏齐平，无圆角）。Bottom border 1px solid `--border-color`. z-index 9997（低于下载面板 9998，但高于 webview）。

**Animation:**
- 出现：`transform: translateY(-100%) → translateY(0)`, `opacity: 0 → 1`, 300ms ease-out
- 消失：`transform: translateY(0) → translateY(-100%)`, `opacity: 1 → 0`, 200ms ease-in
- "保存"按钮点击反馈：背景色过渡到 `--success-color`，文字变为 ✓，持续 500ms 后消失

**States:**
1. **Hidden:** 默认状态，`.hidden` class，`display: none`
2. **Visible:** 滑入显示，按钮可点击
3. **Saving:** "保存"按钮变为绿色 ✓，其他按钮 disabled，500ms 后消失
4. **Auto-dismiss:** 10 秒到时，滑出消失

### C-02: 凭据填充状态指示（无独立组件）

**设计决策 (D-11):** 自动填充不提供额外视觉反馈。字段直接填好，用户看到的是预填的用户名和密码。

**实现方式：** webview preload 脚本在页面加载完成后，通过 DOM 操作将存储的凭据值填入 input 字段。无横幅、无 toast、无高亮。

**Edge case — 填充失败：** 如果凭据解密失败或存储为空，静默跳过（不显示错误）。

## Interaction Specifications

### Banner 出现条件 (D-01, D-02, D-03, D-04)

1. webview preload 脚本检测到登录表单提交（`form submit` 事件）
2. 提取 `input[type=text/email]` 和 `input[type=password]` 的 value
3. 通过 IPC 发送到主进程：`{ username, password, domain, containerId }`
4. 主进程检查：
   - 该域名是否在"永不保存"列表中 → 跳过
   - 该域名是否已有相同凭据 → 跳过（避免重复提示）
5. 通过 IPC 通知渲染进程显示横幅

### Banner 关闭方式

| 方式 | 行为 |
|------|------|
| 点击"保存" | 加密存储凭据 → 横幅消失 |
| 点击"永不" | 记录域名到永不列表 → 横幅消失 |
| 点击"暂不" | 横幅消失，无存储操作 |
| 10 秒超时 | 等同于"暂不" |
| ESC 键 | 等同于"暂不" |
| 点击横幅外部 | 等同于"暂不" |

### 自动填充触发 (D-09, D-12)

1. 页面加载完成（`did-finish-load` 事件）
2. 主进程查询当前容器 + 当前域名的凭据
3. 如果找到凭据且未被"永不保存"，通过 IPC 发送到 webview preload
4. preload 脚本查找页面中的登录表单，填入 username 和 password
5. 每次导航/刷新都触发（D-12）

### autofill/fillForm 互斥 (D-13, D-14, D-15, D-16)

1. fillForm（AI 填表）开始执行时，主进程设置 `autofillDisabled = true`
2. fillForm 执行期间，所有 autofill 检测暂停
3. fillForm 完成后，主进程重置 `autofillDisabled = false`
4. 下次页面导航时 autofill 恢复正常

## Accessibility

- Banner: `role="alert"`, `aria-live="polite"`（非紧急提示）
- 保存按钮: `aria-label="为 {domain} 保存密码"`
- 永不按钮: `aria-label="永不再询问 {domain} 的密码保存"`
- 暂不按钮: `aria-label="暂不决定"`
- Banner 出现时：焦点不自动转移（用户可能正在浏览页面，不应打断）

- **Cookie 管理：** 凭据存储独立于 Cookie，使用独立的 SQLite 表 + safeStorage 加密

- **AI fillForm：** 互斥机制通过主进程状态标志实现，preload 脚本检查标志后决定是否执行 autofill
