## Component Inventory

### 1. Window Top Color Bar (NEW)

**Purpose:** Visual indicator showing which container the active tab belongs to

**Location:** Top edge of the BrowserWindow, above the tab bar

**Spec:**
- Height: 3px
- Width: 100% of window width
- Background: current active tab's container color
- Position: absolute, top: 0, left: 0, z-index: 10000
- Transition: background-color 0.2s ease
- Default container: hide the color bar entirely (display: none)

**CSS Class:** `.window-color-bar`

```css
.window-color-bar {
  position: absolute;
  top: 0;
  left: 0;
  right: 0;
  height: 3px;
  z-index: 10000;
  transition: background-color 0.2s ease;
  pointer-events: none;
}

.window-color-bar.hidden {
  display: none;
}
```

**Behavior:**
- Created in each BrowserWindow's renderer
- Updated when active tab changes (switchTab, createTab, closeTab)
- Updated when tab's container changes
- Color source: `getContainerColor(activeTab.containerId)`

### 3. Window Title Format (NEW)

**Purpose:** Show container name and page title in window title bar

**Format:** `{containerName} - {pageTitle}`

**Examples:**
- "工作 - Google"
- "个人 - GitHub"
- "新标签页" (when on new tab page, no container prefix)

**Implementation:**
- Set via `document.title = ...` in renderer.js
- Updated on: tab switch, page title change, container switch
- IPC channel: renderer sends title to main process via `window:set-title`

**Behavior:**
- Active tab's container name + page title
- New tab page: just "新标签页" (no container prefix)
- Default container: just show page title without container prefix

---

### 4. Window Close Confirmation Dialog (NEW)

**Purpose:** Warn user about active tasks before closing window

**Trigger:** Window close button clicked, Cmd+Shift+W, or Cmd+W on last tab

**Spec:**
- Type: Native dialog (dialog.showMessageBox)
- Window type: modal (parented to closing window)
- Buttons: ["关闭", "取消"] (Close, Cancel)
- Default button: Cancel (safe default)
- Cancel label: "取消"
- No-icon style (or warning icon)

**Message format:**
```
Title: "确认关闭"
Message: "该窗口有 {N} 个活跃任务：\n{taskList}"
Detail: "关闭窗口将中断这些任务。确定要关闭吗？"
```

**Task list format:**
- Downloads: "• {filename} (下载中...)"
- Media: "• {mediaType} 播放中 ({domain})"

**Behavior:**
- No active tasks: close immediately, no dialog
- Has active tasks: show dialog
  - "关闭" clicked: proceed with close (D-16: destroy tabs then window)
  - "取消" clicked: abort close, window stays open

## Interaction Flows

### Flow 1: Active Tab Changes

```
1. User clicks tab in tab bar
   │
   ▼
2. renderer.js: switchTab(tabId)
   ├── Update state.activeTabId
   ├── Show corresponding webview
   ├── Update tab bar active state
   │
   ├── Update window color bar:
   │   ├── Get container color for new active tab
   │   ├── If default container → hide color bar
   │   └── Else → show color bar with container color
   │
   └── Update window title:
       ├── Get container name + page title
       ├── Format: "{containerName} - {pageTitle}"
       └── Send to main process via IPC
```

### Flow 2: Window Close with Active Tasks

```
1. User clicks close button (or Cmd+Shift+W)
   │
   ▼
2. main.js: win.on('close', (e) => ...)
   ├── e.preventDefault() //阻止默认关闭
   │
   ├── Check active tasks:
   │   ├── Get active downloads from downloadManager
   │   ├── Get active media from mediaSniffer
   │   └── Combine into task list
   │
   ├── If no tasks:
   │   └── Proceed with close (destroy tabs, then window)
   │
   └── If has tasks:
       ├── Show dialog.showMessageBox({
       │     type: 'warning',
       │     buttons: ['关闭', '取消'],
       │     defaultId: 1, // Cancel is safe default
       │     title: '确认关闭',
       │     message: `该窗口有 ${tasks.length} 个活跃任务：`,
       │     detail: taskList + '\n关闭窗口将中断这些任务。确定要关闭吗？'
       │   })
       │
       ├── If result.response === 0 (关闭):
       │   └── Proceed with close
       │
       └── If result.response === 1 (取消):
           └── Abort close, window stays open
```

### Flow 3: Tab Close Cascades to Window Close

```
1. User clicks tab close button
   │
   ▼
2. renderer.js: closeTab(tabId)
   ├── Remove tab from DOM
   ├── Remove tab from state.tabs
   ├── Notify main process: tabManager.closeTab(tabId)
   │
   ├── Check: are there remaining tabs in this window?
   │   ├── Yes → switch to adjacent tab
   │   └── No → close window
   │       └── Send IPC: windowManager.closeWindow(windowId)
   │
   └── Main process handles window close (see Flow 2)
```
