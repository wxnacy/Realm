实现窗口顶部 3px 容器颜色条（per D-19, D-20, D-21）：

**src/styles/main.css 修改：**

1. 新增 .window-color-bar 样式（per UI-SPEC）：
```css
.window-color-bar {
  position: absolute;
  top: 0;
  left: 0;
  right: 0;
  height: 3px;
  z-index: 10000;
  transition: background-color 0.2s ease;
  pointer-events: none;
}

.window-color-bar.hidden {
  display: none;
}
```

**src/renderer.js 修改：**

1. 新增 updateWindowColorBar() 函数：
   - 查找或创建 .window-color-bar DOM 元素
   - 获取当前活动 Tab 的容器颜色
   - 如果容器有颜色（非默认容器）：
     - 移除 hidden 类
     - 设置 backgroundColor 为容器颜色
   - 如果容器无颜色（默认容器）：
     - 添加 hidden 类（per D-21）

2. 在 DOM 初始化时创建 color bar 元素：
   - document.body.prepend(colorBar) 确保在最顶层

3. 在以下场景调用 updateWindowColorBar()：
   - switchTab() 切换 Tab 时
   - 容器切换时（container-switched 事件）
   - Tab 创建/关闭时

4. 修改 switchTab() 函数：
   - 在切换 Tab 后调用 updateWindowTitle() 和 updateWindowColorBar()

5. 修改 container-switched 事件处理：
   - 容器切换后调用 updateWindowTitle() 和 updateWindowColorBar()
