# Phase 31-03: 下载管理器 — Gap Closure

## 背景

VERIFICATION.md 发现两个关键缺陷（CR-01、CR-02），导致 realm://downloads 独立页面功能不完整。

## 缺陷清单

### CR-01: 缺失 HTTP API 路由（Blocker）

**现象：** downloads-page.js 调用了 6 个不存在的 HTTP API 路由
- `POST /api/downloads/pause` — 暂停下载
- `POST /api/downloads/resume` — 恢复下载
- `POST /api/downloads/cancel` — 取消下载
- `POST /api/downloads/open` — 打开文件
- `POST /api/downloads/show-in-folder` — Finder 显示

**根因：** Phase 31-02 的 downloads-page.js 直接调用 HTTP API，但 main.js 的 handleDownloadsApi 只实现了 list/delete/clear 三个路由。

**修复：** 在 main.js 的 handleDownloadsApi 中添加 5 个路由，委托给 download-manager.js 已有方法。

### CR-02: API 响应格式不匹配（Blocker）

**现象：** downloads-page.js 第 154 行检查 `data.success` 并读取 `data.downloads`，但 main.js 第 1259 行返回裸数组。

**修复方向（二选一）：**
- A) 修改 main.js，将 list 路由返回格式改为 `{success: true, downloads: [...]}`
- B) 修改 downloads-page.js，直接使用裸数组

**推荐 A：** 统一所有 API 路由的响应格式为 `{success: true, ...}`，与 downloads-page.js 和 delete/clear 路由的现有约定一致。

## 执行任务

### Task 1: 修改 main.js — 统一 list 路由响应格式 + 新增 5 个路由

**文件：** `main.js`

**改动 1 — CR-02 修复：** 将 list 路由的返回值从裸数组改为 `{success: true, downloads: [...]}` 格式：

```javascript
// 第 1259 行，原：
sendJson(res, 200, downloadManager.getAllDownloads(limit, offset));

// 改为：
const downloads = downloadManager.getAllDownloads(limit, offset);
sendJson(res, 200, { success: true, downloads });
```

**改动 2 — CR-01 修复：** 在 `sendJson(res, 404, ...)` 之前添加 5 个路由：

```javascript
// POST /api/downloads/pause — 暂停下载
if (route === 'pause' && req.method === 'POST') {
  const { downloadId } = await readJsonBody(req);
  sendJson(res, 200, { success: downloadManager.pauseDownload(downloadId) });
  return;
}

// POST /api/downloads/resume — 恢复下载
if (route === 'resume' && req.method === 'POST') {
  const { downloadId } = await readJsonBody(req);
  sendJson(res, 200, { success: downloadManager.resumeDownload(downloadId) });
  return;
}

// POST /api/downloads/cancel — 取消下载
if (route === 'cancel' && req.method === 'POST') {
  const { downloadId } = await readJsonBody(req);
  sendJson(res, 200, { success: downloadManager.cancelDownload(downloadId) });
  return;
}

// POST /api/downloads/open — 打开文件
if (route === 'open' && req.method === 'POST') {
  const { filePath } = await readJsonBody(req);
  await downloadManager.openFile(filePath);
  sendJson(res, 200, { success: true });
  return;
}

// POST /api/downloads/show-in-folder — Finder 显示
if (route === 'show-in-folder' && req.method === 'POST') {
  const { filePath } = await readJsonBody(req);
  downloadManager.showInFolder(filePath);
  sendJson(res, 200, { success: true });
  return;
}
```

**验证点：**
- [ ] list 路由返回 `{success: true, downloads: [...]}`
- [ ] pause/resume/cancel 路由返回 `{success: boolean}` 格式（与 apiAction 的 `data.success` 检查匹配）
- [ ] open/show-in-folder 路由返回 `{success: true}`
- [ ] 未知路由仍返回 404
