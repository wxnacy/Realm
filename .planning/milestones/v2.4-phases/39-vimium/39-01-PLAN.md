该模块导出：

**2. 扩展 shortcut-manager.js — 添加 Vim 快捷键识别层**

在 `attachInputListener` 的 `contents.on('before-input-event')` 回调中，在现有 `findMatchingAction` 之前添加 Vim 快捷键处理逻辑（per D-07, D-08）：

优先级顺序：
1. `input.type !== 'keyDown'` → 忽略
2. `input.meta || input.control || input.alt`（CmdOrCtrl 修饰键）→ 走现有 Accelerator 匹配（D-08）
3. 检查是否为 realm:// 内部页面 → 跳过 Vim
4. 检查焦点状态（主进程维护的 focusInInput Map）→ 在输入框中则跳过（D-07）
5. VimEnabled 检查 → 未启用则跳过
6. 将 input.key 传递给 VimStateMachine.processKey() → 返回命令名
7. 如果返回命令名 → `event.preventDefault()` + `focusedWindow.webContents.send('vim:triggered', command)`
8. 如果返回 null（等待双键序列）→ `event.preventDefault()`（吞掉按键）

新增导出：
- `setVimFocusState(webContentsId, isInInput)`: 由 renderer 通过 IPC 调用，更新焦点状态 Map
- `vimFocusStates: Map<number, boolean>`: 存储每个 webContents 的输入框焦点状态

新增 IPC 通道（在 shortcut-manager.js 中注册）：
- `ipcMain.handle('vim:set-focus-state', (event, isInInput) => ...)`: renderer 报告焦点状态
- `ipcMain.handle('vim:get-enabled', (event) => ...)`: 读取 vimium.enabled 设置

```
function initVimShortcuts() {
  // 监听 webview 的焦点状态变化
  // 在 webview 创建时（createWebview 或类似位置）添加 ipc-message 监听：
  // webview.addEventListener('ipc-message', (e) => {
  //   if (e.channel === 'vim:focus-state') {
  //     window.realmAPI.setVimFocusState(e.args[0]);
  //   }
  // });

  window.realmAPI.onVimTriggered((command) => {
    switch (command) {
      // 滚动命令 — 通过 webview.executeJavaScript 注入
      case 'scrollDown': injectScroll('down'); break;
      case 'scrollUp': injectScroll('up'); break;
      case 'scrollLeft': injectScroll('left'); break;
      case 'scrollRight': injectScroll('right'); break;
      case 'scrollHalfPageDown': injectScroll('halfDown'); break;
      case 'scrollHalfPageUp': injectScroll('halfUp'); break;
      case 'scrollToTop': injectScroll('top'); break;
      case 'scrollToBottom': injectScroll('bottom'); break;
      // 标签管理
      case 'closeTab': closeTab(state.activeTabId); break;
      case 'restoreTab': reopenClosedTab(); break;
      case 'newTab': createTab(state.currentContainer); break;
      case 'nextTab': switchToAdjacentTab(1); break;
      case 'prevTab': switchToAdjacentTab(-1); break;
      case 'firstTab': switchToTabByIndex(0); break;
      case 'lastTab': switchToTabByIndex(-1); break;
      case 'visitPrevTab': visitPrevTab(); break;
      // 浏览导航
      case 'goBack': { const wv = state.webviews.get(state.activeTabId); if (wv && wv.canGoBack()) wv.goBack(); break; }
      case 'goForward': { const wv = state.webviews.get(state.activeTabId); if (wv && wv.canGoForward()) wv.goForward(); break; }
      case 'reload': { const wv = state.webviews.get(state.activeTabId); if (wv) wv.reload(); break; }
      case 'hardReload': { const wv = state.webviews.get(state.activeTabId); if (wv) wv.reloadIgnoringCache(); break; }
    }
  });
}
```

新增辅助函数：
- `injectScroll(direction)`: 获取当前 activeTab 的 webview，调用 `webview.executeJavaScript(...)` 注入滚动命令。滚动参数：j/k 100px, h/l 100px, d/u `window.innerHeight/2`, gg/G 使用 `window.scrollTo`
- `switchToAdjacentTab(offset)`: 基于 state.activeTabId 在 tabs Map 中找相邻 tab，循环切换
- `switchToTabByIndex(index)`: index=0 切换到第一个 tab，index=-1 切换到最后一个
- `visitPrevTab()`: 维护 `state.tabHistoryStack`（数组），每次 switchTab 时 push 旧 tabId，`^` 命令 pop 并切换。栈上限 50

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| webview guest → renderer | webview-preload 通过 sendToHost 发送焦点状态，renderer 信任此数据 |
| renderer → main process | renderer 通过 IPC 设置焦点状态，主进程需要验证来源 |
| main process → renderer | vim:triggered 事件从主进程发送到焦点窗口的 renderer |
