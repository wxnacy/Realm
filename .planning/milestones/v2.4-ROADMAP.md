# Milestone v2.4: 多窗口支持

**Status:** ✅ SHIPPED 2026-08-16
**Phases:** 34-36
**Total Plans:** 9

## Overview

支持多窗口操作，提升多任务处理效率。用户可以创建和管理多个独立窗口，在窗口间拖拽移动 Tab，窗口位置和大小跨重启保持不变。

## Phases

### Phase 34: 窗口管理基础

**Goal**: 用户可以通过多种方式创建和管理多个窗口，每个窗口作为独立的浏览上下文
**Depends on**: Nothing (first v2.4 phase)
**Plans**: 4 plans

Plans:

- [x] 34-01: window-manager Map 重构 + shortcut-manager 焦点派发
- [x] 34-02: assertTrustedSender 泛化 + IPC 信任模型扩展
- [x] 34-03: Dock 菜单 + activate 事件 + 广播替换
- [x] 34-04: Gap Fix - UAT Shortcuts

**Details:**
- windowManager 从单例 mainWindowRef 改为 Map<windowId, BrowserWindow> + Set<windowId>
- shortcut-manager 快捷键派发到焦点窗口 BrowserWindow.getFocusedWindow()
- broadcast() 替代 mainWindow.webContents.send()
- assertTrustedSender 扩展为 managedWindowIds 集合

### Phase 35: Tab 窗口关联

**Goal**: 每个 Tab 明确归属到一个窗口，窗口生命周期与 Tab 生命周期正确联动
**Depends on**: Phase 34
**Plans**: 3 plans

Plans:

- [x] 35-01: Tab 管理重构 + 窗口关闭级联
- [x] 35-02: 窗口标题栏 + 容器颜色条
- [x] 35-03: UAT Gap Fixes

**Details:**
- Tab 对象新增 windowId 字段
- 窗口关闭自动销毁该窗口所有 Tab
- 标题栏显示当前活动 Tab 所属容器名称
- 修复关闭最后窗口不退出的问题

### Phase 36: Tab 拖拽与跨窗口移动

**Goal**: 用户可以通过拖拽在窗口内排序 Tab、将 Tab 拖出创建新窗口、将 Tab 拖到另一个窗口移动
**Depends on**: Phase 35
**Plans**: 3 plans

Plans:

- [x] 36-01: 窗口位置持久化 + 右键菜单
- [x] 36-02: 窗口内 Tab 拖拽排序
- [x] 36-03: 跨窗口 Tab 拖拽

**Details:**
- 窗口内拖拽排序实时显示插入位置指示器
- 拖拽 Tab 出标签栏创建新窗口
- 跨窗口拖拽移动 Tab（DragCoordinator + floating drag preview）
- 右键菜单"在新窗口中打开"
- 窗口位置和大小 electron-store 持久化，重启后恢复
