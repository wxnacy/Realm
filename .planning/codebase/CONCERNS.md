# 代码库问题与风险

**分析日期:** 2026-07-23

## 技术债务

**核心功能缺失 - Webview 未实现:**
- 问题: 浏览器核心功能（网页加载、导航、前进后退）完全缺失，仅有 UI 外壳
- 文件: `src/renderer.js:258-259`
- 影响: 应用无法作为浏览器使用，仅为容器管理演示
- 修复方案: 实现 `<webview>` 或 `<BrowserView>` 集成，绑定导航按钮事件

**容器 ID 生成逻辑脆弱:**
- 问题: 容器 ID 通过 `name.toLowerCase().replace(/[^a-z0-9]/g, '-')` 生成，存在碰撞风险
- 文件: `main.js:163`
- 影响: 两个同名容器（如 "Work" 和 "work"）会生成相同 ID，导致数据覆盖
- 修复方案: 使用 UUID 或添加时间戳后缀，同时检查 ID 唯一性

**无错误处理机制:**
- 问题: IPC 处理器和渲染进程函数缺少 try-catch，错误会导致静默失败
- 文件: `main.js:134-245`, `src/renderer.js:50-294`
- 影响: 用户无法感知操作失败原因，调试困难
- 修复方案: 添加统一错误处理，通过 IPC 返回错误信息给渲染进程

**配置存储无版本管理:**
- 问题: `electron-store` 配置无 schema 版本，未来升级可能导致数据不兼容
- 文件: `main.js:13`
- 影响: 应用更新后可能无法读取旧配置
- 修复方案: 添加配置版本号和迁移逻辑

## 已知缺陷

**容器 ID 碰撞:**
- 症状: 创建名为 "My Container" 和 "my-container" 的容器会互相覆盖
- 文件: `main.js:163-184`
- 触发条件: 创建名称经转换后相同的容器
- 临时方案: 手动确保容器名称不冲突

**容器切换不刷新页面:**
- 症状: 切换容器后，当前页面仍在旧 Session 中显示
- 文件: `main.js:102-127`
- 触发条件: 点击切换容器
- 临时方案: 无，需要实现 webview 重载逻辑

**窗口关闭后映射残留:**
- 症状: 窗口关闭时 `windowContainerMap` 清理依赖 `closed` 事件
- 文件: `main.js:91-93`
- 触发条件: 快速关闭窗口或应用崩溃
- 临时方案: 重启应用

## 安全风险

**XSS 风险 - Cookie 值未转义:**
- 风险: Cookie 名称和值直接插入 HTML，可能包含恶意脚本
- 文件: `src/renderer.js:194-202`
- 当前缓解: 无
- 建议: 使用 `textContent` 或 HTML 转义函数

**缺少内容安全策略 (CSP):**
- 风险: 无 CSP 头，可能加载外部脚本或执行内联代码
- 文件: `src/index.html`
- 当前缓解: `contextIsolation: true` 已启用
- 建议: 添加 `<meta http-equiv="Content-Security-Policy">` 限制资源来源

**IPC 通道无输入验证:**
- 风险: 恶意渲染进程可传递任意参数给 IPC 处理器
- 文件: `main.js:134-245`
- 当前缓解: `contextIsolation: true` 限制了直接访问
- 建议: 对所有 IPC 入参进行类型和格式验证

**未启用沙箱模式:**
- 风险: 渲染进程可访问 Node.js API（虽已禁用 nodeIntegration）
- 文件: `main.js:70-76`
- 当前缓解: `nodeIntegration: false`
- 建议: 添加 `sandbox: true` 增强隔离

## 性能瓶颈

**启动时初始化所有容器 Session:**
- 问题: 应用启动时遍历并初始化所有容器的 Session
- 文件: `main.js:35-49`
- 原因: 同步初始化所有 Session partition
- 改进方案: 延迟加载，仅在首次使用时初始化 Session

**容器列表全量重渲染:**
- 问题: 每次切换容器都重新生成整个列表 HTML
- 文件: `src/renderer.js:79-100`
- 原因: 使用 innerHTML 全量替换
- 改进方案: 仅更新变化的 DOM 节点，或使用虚拟滚动

**Cookie 列表无分页:**
- 问题: 大量 Cookie 时一次性渲染所有数据
- 文件: `src/renderer.js:186-203`
- 原因: 无分页或虚拟滚动
- 改进方案: 添加分页或懒加载

## 脆弱区域

**容器 ID 生成:**
- 文件: `main.js:163`
- 脆弱原因: 仅通过正则转换名称，无唯一性检查
- 安全修改: 添加 ID 冲突检测，失败时追加随机后缀
- 测试覆盖: 无

**IPC 通信层:**
- 文件: `main.js:134-245`, `src/preload.js:13-81`
- 脆弱原因: 无统一错误处理，单个处理器失败不影响其他
- 安全修改: 添加 try-catch 包装，返回统一错误格式
- 测试覆盖: 无

**DOM 操作:**
- 文件: `src/renderer.js:79-100, 194-202`
- 脆弱原因: innerHTML 直接插入用户数据，无转义
- 安全修改: 使用 DOM API 或模板引擎，转义特殊字符
- 测试覆盖: 无

**事件监听器管理:**
- 文件: `src/renderer.js:94-99, 219-291`
- 脆弱原因: 每次渲染列表都添加新监听器，无清理机制
- 安全修改: 使用事件委托或在替换内容前移除旧监听器
- 测试覆盖: 无

## 扩展性限制

**单窗口架构:**
- 当前容量: 仅支持一个主窗口
- 限制: 无法同时查看多个容器
- 扩展方案: 实现多窗口管理器，每个窗口绑定独立容器

**无容器数据迁移:**
- 当前容量: 容器删除即清除所有数据
- 限制: 无法备份或迁移容器数据
- 扩展方案: 实现容器数据导出/导入功能

**配置存储无加密:**
- 当前容量: 配置以明文 JSON 存储
- 限制: 敏感配置（如未来 API 密钥）无保护
- 扩展方案: 使用 electron-store 加密插件或系统钥匙串
